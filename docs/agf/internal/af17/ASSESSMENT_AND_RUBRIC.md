# AF-17 — Assessment & Rubric

## Exercice

Le candidat décrit l'architecture réelle du client agent de cette
Academy (un client, une persona), cite AF-16 par référence, explique
la frontière de marché avec `CVLNAgentfactory`, puis refuse une
proposition de décrire une architecture multi-persona hypothétique
comme actuelle.

## Compétences évaluées

| ID | Compétence |
|---|---|
| C1 | Décrire fidèlement l'architecture réelle étroite (un client, une persona). |
| C2 | Refuser toute taxonomie de types d'agents inventée. |
| C3 | Maintenir la frontière de marché avec `CVLNAgentfactory` et réutiliser AF-16 par référence. |

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Décrit une taxonomie de types d'agents inexistante. |
| 1 | Évite l'invention, description incomplète. |
| 2 | Description correcte (un client, une persona), référence à AF-16 implicite. |
| 3 | Description complète, référence à AF-16 explicite et correcte. |
| 4 | Niveau 3 + frontière marché (`CVLNAgentfactory`) explicite + refus correct d'une proposition hypothétique multi-persona. |

**Règle éliminatoire :** décrire une taxonomie de types d'agents
inexistante, ou redéfinir AF-16 au lieu de le citer.

**Seuil de passage :** ≥2.5/4.
