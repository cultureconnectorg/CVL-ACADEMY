# AF-17 — Banque N2 (cas appliqués)

## Cas 1 — Description de l'architecture réelle

Le candidat décrit l'architecture agent de cette Academy sans inventer
de taxonomie de types d'agents, en citant AF-16 par référence pour le
grounding du client/persona.

**Critère éliminatoire :** décrire plusieurs types/rôles d'agents
inexistants dans le code réel.

## Cas 2 — Frontière de marché

Le candidat doit expliquer pourquoi le cycle de vie ADL de
`CVLNAgentfactory` ne peut jamais être présenté comme la forme réelle
de cette Academy.

**Critère éliminatoire :** affirmer que l'Academy suit un cycle de vie
ADL.
