`READY_FOR_FREK_PROOF = FALSE` (non applicable à ce domaine).

## Chaîne de preuve

Description architecturale annotée (client unique, persona unique) +
refus de taxonomie inventée + note de frontière marché → correcteur →
(jury si 2.0–2.5) → `AF17.SKILL.CLIENT_ARCHITECTURE.L1` (réservé).

## Ce qui compte comme preuve

Une description fidèle de l'architecture réelle étroite, citant AF-16
par référence, distinguant explicitement le contexte de marché
(`CVLNAgentfactory`) de la forme réelle opérée par cette Academy.

## Ce qui NE compte PAS comme preuve

Toute taxonomie de types d'agents inventée ; toute affirmation d'un
cycle de vie ADL opéré par l'Academy ; toute redéfinition du grounding
d'AF-16 au lieu de le citer.

- Réservation d'ID : `AF17.SKILL.CLIENT_ARCHITECTURE.L1` — réservé,
  non émis.
- Prérequis : AF-16, réutilisé par référence.
