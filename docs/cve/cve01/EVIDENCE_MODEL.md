# CVE-01 — Evidence Model

## Chaîne de preuve

M1 glossaire annoté (7 symboles) → M2 note écrite sur H0/clôture → M3
carte système + note de statut chantier → correcteur → (jury si
2.0–2.5) → `CVE01.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Le glossaire M1 couvrant exactement les 7 symboles (`i,t,c,a,x̂,MD_c,
θ`) ; la note M2 citant H0 mot pour mot et le principe de clôture ; la
carte M3 nommant les 4 couches dans l'ordre avec §2 et §6
correctement positionnés hors du compte des 4, et le statut chantier
honnête (1 fait, 2/3 non faits).

## Ce qui NE compte PAS comme preuve

Un symbole dont le sens est inventé, une couche supplémentaire
inventée, ou toute affirmation que chantier 2/3 a été réalisé.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE01.SKILL.*`) est en jeu.

## Réservation Skill ID

`CVE01.SKILL.NOTATION_LITERACY`, `CVE01.SKILL.H0_CLOSURE_DISCIPLINE`,
`CVE01.SKILL.ARCHITECTURE_MAP` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
