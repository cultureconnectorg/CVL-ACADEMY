# CVE-02 — Assessment & Rubric

Structure identique à `docs/gmd/gmd21/ASSESSMENT_AND_RUBRIC.md` (N1
40% / N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Trust Score + Filtre de Validation (§1.1), formule exacte et rôle anti-fraude |
| C2 | Les 5 composantes brutes/dérivées (§1.2), distinction raw vs. derived pour `L` |
| C3 | Statut ouvert de la transformation de saturation (§2.1) — jamais présenté comme tranché |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente une valeur fixe pour `τ_fraude`, traite `L` comme brut, ou affirme qu'un choix de transformation a été fait |
| 1 | Formule approximative, poids non cités exactement |
| 2 | Formules correctes mais sans distinguer brut/dérivé ou sans citer le statut ouvert de §2.1 |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §1.1/§1.2/§2.1 précisément, avec exemple numérique correct |

## Règle éliminatoire

Toute capacité inventée (seuil fixe, transformation tranchée,
composante brute pour `L`) entraîne un 0 automatique — non
proportionnel à la qualité de la copie.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
