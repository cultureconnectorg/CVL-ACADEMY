# CVE-02 — Evidence Model

## Chaîne de preuve

M1 exemple numérique du Trust Score → M2 tableau des 5 composantes →
M3 note sur le statut ouvert de la transformation → M4 note de
handoff vers Layer 2 → correcteur → (jury si 2.0–2.5) →
`CVE02.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

L'exemple M1 vérifiable contre §1.1 (poids, seuil, filtre) ; le
tableau M2 citant §1.2 section par composante, avec `L` correctement
distingué comme dérivé ; la note M3 citant explicitement §2.1 comme
un choix non tranché, jamais présenté comme réglé.

## Ce qui NE compte PAS comme preuve

Une valeur inventée pour `τ_fraude`, un choix de transformation
affirmé comme définitif, ou toute affirmation qui traite les 5
composantes comme uniformément brutes.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE02.SKILL.*`) est en jeu — jamais une autorité pour fixer
des paramètres CVE réels.

`CVE02.SKILL.TRUST_SCORE_LITERACY`, `CVE02.SKILL.RAW_COMPONENTS`,
`CVE02.SKILL.SATURATION_STATUS_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
