# CVE-04 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Formule CES exacte (§3.1), les 6 composantes agrégées |
| C2 | Contrainte de normalisation des poids, et pourquoi elle compte |
| C3 | Discipline de renvoi — jamais re-dériver N (§3.2) ou CHL_integrated (§3.3) ni ρ_c (CVE-05) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente une composante supplémentaire, valide des poids non normalisés |
| 1 | Formule approximative, composantes non toutes citées |
| 2 | Formule correcte mais re-dérive N/CHL/ρ au lieu d'y renvoyer |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §3.1 précisément avec renvois corrects vers §3.2/§3.3/CVE-05 |

## Règle éliminatoire

Toute composante inventée ou poids non normalisés validés entraîne un
0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
