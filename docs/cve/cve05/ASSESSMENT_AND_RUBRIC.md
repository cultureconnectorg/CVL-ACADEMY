# CVE-05 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Domaine et rôle économique de `ρ_c` (§3.1) |
| C2 | Les 3 cas spéciaux (somme pondérée / Cobb-Douglas / Leontief), interprétation correcte |
| C3 | Discipline de statut d'hypothèse — H2 jamais présentée comme validée |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Valide une valeur de ρ_c hors domaine, inverse l'interprétation Leontief, ou affirme H2 validée |
| 1 | Domaine ou cas spéciaux imprécis |
| 2 | Domaine et cas spéciaux corrects mais statut H2 non mentionné |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §3.1 précisément avec les 3 cas et le statut H2 explicite |

## Règle éliminatoire

Toute valeur hors domaine validée, interprétation Leontief inversée,
ou H2 présentée comme validée entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
