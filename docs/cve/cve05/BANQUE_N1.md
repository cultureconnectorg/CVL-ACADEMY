## M1 — ρ parameter literacy

1. What range does `ρ_c` occupy? (`ρ_c ∈ (-∞, 1]`)
2. What does `ρ_c` represent, economically, in this formula
   specifically? (Substitution elasticity — how freely one component
   can compensate for a weakness in another inside the CES
   aggregation)
3. Is `ρ_c` a universal constant across the whole methodology, or
   cycle-specific? (Cycle-specific, calibrated empirically per cycle)

## M2 — special-cases literacy

4. What happens as `ρ_c → 1`? (Weighted sum — perfect
   substitutability)
5. What happens as `ρ_c → 0`? (Cobb-Douglas form,
   `CVI_i,c = Π_a x̂_i,c,a^{w_a,c}`)
6. What happens as `ρ_c → -∞`? (Leontief form,
   `CVI_i,c = min_a(x̂_i,c,a)` — total complementarity)
7. In the Leontief case, what determines a work's `CVI_i,c`? (Its
   single weakest component — no strength elsewhere can compensate)

## M3 — hypothesis-status discipline

8. State Hypothesis H2 precisely. (`ρ` is constant within a cycle,
   re-estimated between cycles within the same bounds as the weights,
   per §5.3)
9. Has H2 been validated empirically, per the document itself? (No —
   it is a hypothesis stated for chantier 2 testing, never presented
   as an established fact)
