# CVE-05 — Evidence Model

## Chaîne de preuve

M1 note sur le domaine/rôle de ρ_c → M2 tableau des 3 cas spéciaux →
M3 note de statut d'hypothèse → correcteur → (jury si 2.0–2.5) →
`CVE05.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

La note M1 citant `ρ_c ∈ (-∞, 1]` ; le tableau M2 avec les 3 formes
correctement associées à leur limite ; la note M3 distinguant
"hypothèse énoncée" de "hypothèse validée" pour H2.

## Ce qui NE compte PAS comme preuve

Une valeur de `ρ_c` hors domaine validée, une interprétation Leontief
inversée, ou H2 présentée comme un fait établi.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE05.SKILL.*`) est en jeu.

## Réservation Skill ID

`CVE05.SKILL.RHO_PARAMETER_LITERACY`, `CVE05.SKILL.SPECIAL_CASES`,
`CVE05.SKILL.HYPOTHESIS_STATUS_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
