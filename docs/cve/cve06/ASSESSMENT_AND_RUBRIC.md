# CVE-06 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Concept général de valeur de Shapley (marché, hors KORA), correctement labellisé comme externe |
| C2 | Vérification d'absence dans le spec KORA figé — **éliminatoire** |
| C3 | Analyse honnête de l'écart de formalisation, jamais une formule inventée |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Présente une formule Shapley comme méthodologie KORA réelle, ou affirme le terme présent dans le document |
| 1 | Concept général imprécis, ou vérification d'absence non faite |
| 2 | Concept et vérification corrects mais analyse d'écart absente ou confuse |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Distingue clairement concept général / absence vérifiée / écart honnête |

## Règle éliminatoire

Toute formule Shapley présentée comme méthodologie KORA réelle, ou
toute affirmation que le terme apparaît dans le document, entraîne un
0 automatique — **c'est la compétence la plus importante de cette
formation**.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
