# CVE-06 — Evidence Model

## Chaîne de preuve

M1 note sur le concept général (labellisée externe) → M2 note de
vérification d'absence → M3 note d'écart honnête → correcteur →
(jury si 2.0–2.5) → `CVE06.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

La note M1 correctement labellisée "concept de marché, hors KORA" ;
la note M2 citant la méthode de vérification (recherche plein texte)
et son résultat (absence confirmée) ; la note M3 citant `C_i,c` comme
mécanisme réel actuel et énonçant honnêtement ce qu'une future
formalisation exigerait.

## Ce qui NE compte PAS comme preuve

Une formule de Shapley présentée comme méthodologie KORA réelle, ou
toute affirmation que le terme figure dans le document.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE06.SKILL.*`) est en jeu. Aucune éligibilité mission — ce
concept n'a aucune implémentation KORA réelle à opérer.
