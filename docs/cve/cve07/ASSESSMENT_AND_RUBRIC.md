# CVE-07 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Formule d'entropie `H_k(i,c)` et interprétation correcte haute/basse |
| C2 | Les 6 axes exacts + les 2 points de calibration `ν_k` nommés |
| C3 | Facteur de vélocité `φ(i,c)` et sa borne |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente un 7e axe, une valeur intermédiaire de ν_k, ou inverse l'interprétation de l'entropie |
| 1 | Formule approximative, axes ou bornes imprécis |
| 2 | Formules correctes mais interprétation entropie ou bornes ν_k floues |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §3.2 précisément avec exemple numérique correct |

## Règle éliminatoire

Tout axe inventé, valeur ν_k intermédiaire inventée, ou interprétation
d'entropie inversée entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
