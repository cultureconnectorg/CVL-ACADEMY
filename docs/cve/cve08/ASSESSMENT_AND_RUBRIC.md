# CVE-08 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Les 2 apparitions réelles de VCF (§3.3, §6), citées et annotées |
| C2 | Vérification de l'écart de formalisation — **éliminatoire** |
| C3 | Discipline d'hypothèse de travail — label `HYPOTHESIS, NOT SPEC` obligatoire |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Présente une équation VCF inventée comme spec réelle, ou affirme VCF=CVI comme un fait du document |
| 1 | Citations imprécises, écart non vérifié |
| 2 | Citations et écart corrects mais hypothèse de travail non labellisée |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §3.3/§6 précisément, écart honnête, hypothèse correctement labellisée |

## Règle éliminatoire

Toute équation VCF inventée présentée comme spec réelle entraîne un 0
automatique. Une hypothèse correctement labellisée n'est jamais une
violation.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
