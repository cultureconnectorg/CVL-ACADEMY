# CVE-09 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Formule `UVC_i,c` exacte (§5), discipline "part proportionnelle, jamais absolue" |
| C2 | Formule `value_UVC,c` et dérivation reliant les deux formules |
| C3 | Contrainte de budget fixe (§6 C1) et son implication interprétative |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Présente UVC comme valeur absolue, ou valide une violation de C1 |
| 1 | Formules approximatives |
| 2 | Formules correctes mais dérivation ou implication C1 absente |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §5/§6 C1 précisément avec exemple numérique correct |

## Règle éliminatoire

Toute interprétation de UVC comme valeur absolue, ou validation d'une
violation de C1, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
