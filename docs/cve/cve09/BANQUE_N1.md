## M1 — UVC formula literacy

1. Write the `UVC_i,c` formula exactly. (`UVC_i,c = ( CVI_i,c /
   Σ_j CVI_j,c ) · MD_c`)
2. Is `UVC_i,c` an absolute valuation or a proportional share? (A
   proportional share of the cycle's total CVI, scaled by `MD_c`)

## M2 — unit-value literacy

3. Write the unit-value formula exactly. (`value_UVC,c = MD_c /
   Σ_i CVI_i,c`)
4. Show algebraically that multiplying `value_UVC,c` by a work's own
   `CVI_i,c` recovers `UVC_i,c`. (`(MD_c / Σ_i CVI_i,c) · CVI_i,c =
   (CVI_i,c / Σ_j CVI_j,c) · MD_c` — the same quantity, derived two
   ways)

## M3 — fixed-budget constraint

5. State constraint C1 exactly. (§6: `Σ_i UVC_i,c = MD_c` — fixed
   budget)
6. Why does C1 matter for interpreting a single work's allocation? (A
   work's `UVC_i,c` is always relative to the whole cycle's catalog —
   never an absolute score; one work's larger share necessarily comes
   at the relative expense of others within the fixed pool)
