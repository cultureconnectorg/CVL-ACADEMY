# CVE-10 — Evidence Model

## Chaîne de preuve

M1 note sur ce que le spec définit/laisse ouvert pour `MD_c` → M2
explication écrite avec illustration numérique de la somme nulle →
M3 renvoi explicite vers CVE-09 → correcteur → (jury si 2.0–2.5) →
`CVE10.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

La note M1 distinguant clairement distribution (définie) et fixation
monétaire (non définie) ; l'illustration M2 montrant la somme nulle ;
le renvoi M3 vers CVE-09 sans re-dérivation.

## Ce qui NE compte PAS comme preuve

Un mécanisme de fixation de `MD_c` inventé, ou une proposition
violant C1 validée sans être signalée.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE10.SKILL.*`) est en jeu.

## Réservation Skill ID

`CVE10.SKILL.MD_C_SCOPE_DISCIPLINE`,
`CVE10.SKILL.ZERO_SUM_DISCIPLINE`,
`CVE10.SKILL.CROSS_REFERENCE_TO_CVE09` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
