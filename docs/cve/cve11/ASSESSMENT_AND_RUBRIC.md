# CVE-11 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Explication créateur de l'UVC, fondée sur la formule réelle (renvoi CVE-09) |
| C2 | Garantie de neutralité culturelle (§6 C5), précisément scopée |
| C3 | Discipline de périmètre — jamais de montant précis promis |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Promet un montant € précis, ou affirme que C5 garantit un CVI égal |
| 1 | Explication imprécise ou C5 mal citée |
| 2 | Explication correcte mais scope de C5 flou |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite §5/§6 C5 précisément, distingue clairement les deux garanties |

## Règle éliminatoire

Toute promesse de montant € précis, ou toute affirmation que C5
garantit un CVI égal, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
