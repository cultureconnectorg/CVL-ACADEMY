# CVE-11 — Evidence Model

## Chaîne de preuve

M1 script d'explication créateur → M2 note distinguant les deux
garanties de C5 → M3 note de discipline de périmètre → correcteur →
(jury si 2.0–2.5) → `CVE11.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Le script M1 fondé sur la formule réelle (renvoi à CVE-09) ; la note
M2 distinguant "UVC espéré égal à CVI égal" de "CVI égal garanti" ; la
note M3 refusant toute promesse de montant précis.

## Ce qui NE compte PAS comme preuve

Une promesse de montant € précis, ou une affirmation que C5 garantit
un CVI égal.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE11.SKILL.*`) est en jeu.

## Réservation Skill ID

`CVE11.SKILL.CREATOR_FACING_EXPLANATION`,
`CVE11.SKILL.NEUTRALITY_GUARANTEE_SCOPE`,
`CVE11.SKILL.PAYOUT_PROMISE_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
