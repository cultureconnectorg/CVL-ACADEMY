## Repo truth

Same §5 formulas as CVE-09/10, viewed from the angle of what a real
creator/contributor would need to understand about their own `UVC_i,c`
and `value_UVC,c` — plus §6's cultural-neutrality constraint (C5:
`E[UVC_i | CVI_i = v, culture_i = A] = E[UVC_i | CVI_i = v,
culture_i = B] ∀A,B`), directly relevant to a creator's trust in the
system's fairness.

## Prerequisites

CVE-09 — this formation applies the formula to the creator-facing
explanation question, it does not re-derive it.

## Objectives

1. Explain, in creator-facing terms, how their own `CVI_i,c` (built
   from the components taught in CVE-02/04/05/07) determines their
   `UVC_i,c` share.
2. Explain constraint C5 (cultural neutrality) precisely and correctly
   state what it guarantees (equal expected UVC for equal CVI,
   regardless of culture) and what it does NOT guarantee (equal CVI
   itself, which depends on real engagement/attribution/circulation
   signals).
3. Never promise a creator a specific monetary outcome — the spec
   itself defines only the proportional-allocation mechanism, not a
   real monetary value for `MD_c`.
