# CVE-12 — Banque N2 (cas appliqués)

## Cas N2-1 — Mesure de centralité de graphe inventée

Un stagiaire propose de calculer une "centralité d'intermédiarité"
(betweenness centrality) pour mesurer l'économie de réseau d'une
œuvre. Corrige.

**Critères de notation:** cite l'absence de toute mesure de
centralité de graphe dans le document — seuls l'entropie, le
coefficient de nouveauté, et le facteur de vélocité existent (§3.2).
Élimination si le candidat présente une formule de centralité comme
faisant partie de la méthodologie KORA.

## Cas N2-2 — Mauvais axe classé comme réseau

Un collègue classe l'axe `style` comme un axe d'économie de réseau.
Corrige.

**Critères de notation:** cite les 3 axes réels d'économie de réseau
(`territory, diaspora, collaboration`) — `style` mesure une dimension
de goût individuel, pas une structure sociale/géographique/
collaborative. Élimination si le candidat maintient `style` comme axe
réseau.

## Cas N2-3 — Re-dérivation de l'entropie

Un candidat re-dérive en détail la formule d'entropie `H_k` dans sa
réponse CVE-12. Corrige le périmètre.

**Critères de notation:** rappelle que le mécanisme d'entropie est
enseigné en profondeur dans CVE-07 et doit être cité par référence
ici. Pas d'élimination (pas une invention), mais note réduite pour
duplication.
