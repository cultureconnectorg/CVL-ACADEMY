# CVE-12 — Evidence Model

## Chaîne de preuve

M1 note de spécialisation des 3 axes → M2 note d'interprétation
appliquée de la vélocité → M3 note de discipline de périmètre →
correcteur → (jury si 2.0–2.5) → `CVE12.SKILL.*` (réservé, non lié au
runtime).

## Ce qui compte comme preuve

La note M1 citant exactement `territory, diaspora, collaboration` et
leur justification ; la note M2 sur `φ(i,c)` comme signal de
croissance réseau ; la note M3 confirmant l'absence de mesure de
centralité de graphe.

## Ce qui NE compte PAS comme preuve

Une mesure de centralité de graphe inventée, ou un axe mal classé
comme réseau.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE12.SKILL.*`) est en jeu.

`CVE12.SKILL.NETWORK_AXIS_SPECIALIZATION`,
`CVE12.SKILL.VELOCITY_AS_NETWORK_GROWTH`,
`CVE12.SKILL.SCOPE_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
