# CVE-12 — Guide Candidat

## Avant de commencer

Prérequis : `CVE-07` (le mécanisme Nebula Score, pas re-dérivé ici).

## Ce que tu dois savoir faire

Nommer et justifier les 3 axes réseau exacts (`territory, diaspora,
collaboration`), expliquer `φ(i,c)` comme signal de croissance
réseau, et savoir qu'aucune mesure de centralité de graphe n'existe
dans le document.

## Comment réviser

1. Relis `KORA_CVE_Specification_Mathematique_v1.0.md` §3.2
   toi-même (déjà couvert en CVE-07).
2. Fais les 5 questions de `BANQUE_N1.md`.
3. Traite les 3 cas de `BANQUE_N2.md`.

## Piège le plus fréquent

Classer `style` comme axe réseau — c'est un axe de goût individuel,
pas une structure sociale/géographique/collaborative.

## Règle absolue

N'invente jamais une mesure de centralité de graphe présentée comme
méthodologie KORA — élimination automatique.
