# CVE-13 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Statut de chantier précis (1 fait, 2/3 non faits) |
| C2 | Inventaire complet des hypothèses nommées (H1, H2, H3 + paramètres §6 C7) |
| C3 | Discipline méthodologique — jamais un résultat simulé présenté comme réel |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Présente un résultat de simulation/chantier 2 comme réel |
| 1 | Statut ou hypothèses imprécis |
| 2 | Statut et hypothèses corrects mais méthodologie non décrite |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite le statut, H1/H2/H3, et une méthodologie de validation honnête |

## Règle éliminatoire

Toute présentation d'un résultat simulé ou empirique comme si le
chantier 2 avait eu lieu entraîne un 0 automatique — **c'est la
compétence la plus importante de cette formation.**

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
