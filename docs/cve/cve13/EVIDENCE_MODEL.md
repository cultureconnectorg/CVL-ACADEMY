# CVE-13 — Evidence Model

## Chaîne de preuve

M1 note de statut chantier → M2 tableau complet des hypothèses → M3
esquisse méthodologique explicitement non-réalisée → correcteur →
(jury si 2.0–2.5) → `CVE13.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

La note M1 citant la ligne de statut exacte du document ; le tableau
M2 listant H1/H2/H3 + les paramètres §6 C7 avec section et contenu
exacts ; l'esquisse M3 citant H0 et explicitement labellisée
"non-réalisée."

## Ce qui NE compte PAS comme preuve

Tout résultat de simulation ou de chantier 2/3 présenté comme réel.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE13.SKILL.*`) est en jeu. Aucune éligibilité mission —
aucune infrastructure de simulation réelle n'existe à opérer.

## Réservation Skill ID

`CVE13.SKILL.CHANTIER_STATUS_LITERACY`,
`CVE13.SKILL.HYPOTHESIS_INVENTORY`,
`CVE13.SKILL.SIMULATION_METHODOLOGY_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
