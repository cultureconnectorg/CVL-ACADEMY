# CVE-14 — Banque N2 (cas appliqués)

## Cas N2-1 — Score interne non reproductible validé

Un manager propose d'inclure un "score de qualité éditoriale" fixé en
interne, non recalculable par un tiers, dans le modèle CVE. Corrige.

**Critères de notation:** cite H0 exactement et le principe de
clôture — toute quantité non reproductible par un tiers à partir des
logs bruts est exclue du modèle, sans exception pour une expertise
interne. Élimination si le candidat valide l'inclusion.

## Cas N2-2 — C6 traité comme une idée indépendante de H0

Un stagiaire présente C6 comme "une nouvelle exigence d'audit,
distincte de H0." Corrige.

**Critères de notation:** explique que C6 est le mécanisme
d'application de H0 au niveau de la Loi Fondamentale (§6) — même
principe de reproductibilité, formulé comme contrainte formelle, pas
une exigence séparée. Élimination si le candidat maintient qu'il
s'agit de deux principes distincts.

## Cas N2-3 — Audit de VCF demandé aujourd'hui

Un auditeur externe demande de vérifier la reproductibilité de VCF
(§3.3, §6) selon C6. Corrige.

**Critères de notation:** explique honnêtement que VCF n'a aucune
équation définissante dans le document (CVE-08,
`FORMALIZATION_PENDING`) — on ne peut pas auditer la reproductibilité
d'une quantité qui n'est pas formellement définie. Élimination si le
candidat invente une méthode d'audit pour VCF sans signaler ce gap.
