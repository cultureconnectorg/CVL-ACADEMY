# CVE-15 — Assessment & Rubric

Structure identique à `../cve02/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Les 8 contraintes C1→C8, chacune notée individuellement (jamais "6/8 = suffisant") |
| C2 | Pare-feu prévision/allocation (C8), lien avec §4 |
| C3 | Discipline de publication de gouvernance (C7) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Valide un ajustement silencieux de θ, ou valide l'usage de Ŷ dans l'allocation |
| 1 | Contraintes incomplètes ou confuses |
| 2 | Contraintes correctes mais lien §4/§6 C8 ou discipline C7 absente |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite les 8 contraintes précisément, chacune individuellement notée |

## Règle éliminatoire

Toute validation d'un ajustement silencieux de `θ`, ou toute
utilisation validée de `Ŷ` dans l'allocation, entraîne un 0
automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination. Chaque
contrainte C1→C8 est notée individuellement — un candidat qui en
maîtrise 6/8 n'est pas "globalement correct."
