# CVE-15 — Evidence Model

## Chaîne de preuve

M1 tableau annoté complet des 8 contraintes → M2 note sur le pare-feu
prévision/allocation → M3 note sur la discipline de publication →
correcteur → (jury si 2.0–2.5) → `CVE15.SKILL.*` (réservé, non lié au
runtime).

## Ce qui compte comme preuve

Le tableau M1 listant C1→C8 avec formulation exacte et sens en clair ;
la note M2 citant §4 et §6 C8 ; la note M3 citant les trois exigences
de C7 (publié, justifié, archivé).

## Ce qui NE compte PAS comme preuve

Un ajustement silencieux de `θ` validé, ou une utilisation de `Ŷ`
dans l'allocation validée.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`CVE15.SKILL.*`) est en jeu. Aucune éligibilité mission —
aucun candidat n'est jamais autorisé à fixer des paramètres `θ` réels
via cette certification.
