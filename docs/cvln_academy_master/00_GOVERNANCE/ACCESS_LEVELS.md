# CVLN Academy Master — Access Levels

```
SOURCE: CVLN_Academy_Cartographie_2D_Master.xlsx, sheet "Access_Levels" (7 rows)
STATUS: DECIDED (adopted as-is — a governance contract, not a content claim)
```

| Niveau | Nom | Définition |
|---|---|---|
| L0 | AWARENESS | Comprend l'architecture. Aucun pouvoir. |
| L1 | OBSERVER | Peut consulter état, preuves, événements autorisés. |
| L2 | OPERATOR | Peut exécuter certaines opérations définies. |
| L3 | SUPERVISOR | Peut superviser agents/missions et traiter certaines exceptions. |
| L4 | CONTROLLER | Peut interrompre, isoler, approuver certaines actions sensibles. |
| L5 | ADMINISTRATOR | Administration technique limitée au domaine autorisé. |
| L6 | EXECUTIVE_AUTHORITY | Autorité humaine de gouvernance — **jamais attribuée automatiquement par Academy.** |

## Règle absolue

`L6` n'est jamais accordé par une certification, un score, ou une
complétion de parcours. Aucun document produit par ce chantier n'attribue
`L6` à un rôle sur la seule base d'une réussite Academy. Voir
`AUTHORIZATION_MODEL.md`.
