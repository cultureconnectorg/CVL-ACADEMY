# FMS-07 — Evidence Model

## Chaîne de preuve

M1 session-lifecycle annoté → M2 tableau des modèles réels → M3+M4
distinctions écrites (FMS-14 vs FMS-05, FMS-16 fusion vs séparation)
→ correcteur → (jury si 2.0–2.5) → `FMS07.SKILL.*` (réservé, non lié
au runtime).

## Ce qui compte comme preuve

Le traitement M1 vérifiable contre le vrai énumération de statut de
`fms-os/fms` ; les fiches M2 vérifiables contre `BookingCreate`/
`ServiceCreate` ; les distinctions M3/M4 écrites noir sur blanc,
jamais implicites.

## Ce qui NE compte PAS comme preuve

Un statut ou un champ de modèle inventé, ou une affirmation confondant
la coordination studio-projet (FMS-14) avec la coordination carrière
(FMS-05).

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`FMS07.SKILL.*`) est en jeu.
