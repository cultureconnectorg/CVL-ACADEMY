# FMS-08 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Chaîne de signal approfondie, au-delà de FMS-03/M06 |
| C2 | Bibliothèque de technique micro appliquée, jamais une réponse universelle |
| C3 | Session de tracking sous contrainte réelle (FMS-03/M11 étendu) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Affirme une configuration micro universelle, ou valide la certification sans prérequis FMS-03 |
| 1 | Plan de chaîne de signal ou technique micro imprécis |
| 2 | Plan correct mais rationale/journal de décisions absent |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Plan complet, rationale documentée, décisions justifiées par source |

## Règle éliminatoire

Toute affirmation d'une configuration micro universelle, ou toute
validation d'une certification sans le prérequis FMS-03, entraîne un
0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
