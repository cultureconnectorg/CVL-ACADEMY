# FMS-08 — Banque N2 (cas appliqués)

## Cas N2-1 — Re-dérivation de M06

Un candidat réécrit en détail le contenu du module FMS-03/M06 dans sa
copie FMS-08. Corrige.

**Critères de notation:** rappelle que M06 est cité par référence,
jamais reproduit — le prérequis FMS-03 suppose déjà cette compétence
acquise et vérifiée par cette certification. Pas d'élimination
automatique (pas une invention), mais note fortement réduite pour
duplication de contenu.

## Cas N2-2 — Réponse "correcte" universelle inventée

Un stagiaire affirme qu'il existe "une seule bonne configuration de
placement de micro pour la voix, applicable dans tous les cas."
Corrige.

**Critères de notation:** rappelle que la bibliothèque de technique
micro est un ensemble de motifs de placement par type de source, avec
justification, jamais une réponse universelle unique — la pratique
réelle d'ingénierie du son varie selon le contexte. Élimination si le
candidat maintient qu'une seule configuration est toujours correcte.

## Cas N2-3 — Certification FMS-08 sans prérequis FMS-03

Un collègue propose de délivrer la certification FMS-08 à un candidat
qui n'a jamais obtenu la certification FMS-03. Corrige.

**Critères de notation:** cite le prérequis réel — la compétence
M06/M11 doit déjà être vérifiée via l'enregistrement de certification
FMS-03, jamais re-testée ici. Élimination si le candidat valide la
délivrance sans ce prérequis.
