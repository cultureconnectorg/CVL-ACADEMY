# FMS-08 — Evidence Model

## Chaîne de preuve

M1 plan de chaîne de signal → M2 bibliothèque de placement micro
appliquée → M3 journal de décisions de session → correcteur → (jury
si 2.0–2.5) → `FMS08.SPEC.*` (réservé, distinct de `FMS03.SKILL.*`).

## Ce qui compte comme preuve

Le plan M1 citant FMS-03/M06 sans le reproduire ; la bibliothèque M2
appliquée à un type de source précis avec rationale ; le journal M3
documentant des décisions réelles sous contrainte.

## Ce qui NE compte PAS comme preuve

Une reproduction de M06, une configuration micro universelle
affirmée, ou une certification délivrée sans le prérequis FMS-03.

`READY_FOR_FREK_PROOF = FALSE`. Éligibilité mission (missions
d'ingénieur du son freelance) accordée sur cette spécialisation
seule, indépendamment de la certification FMS-03 (qui reste un
prérequis, jamais un substitut).

## Réservation Skill ID

`FMS08.SPEC.SIGNAL_CHAIN_DEPTH`, `FMS08.SPEC.MIC_TECHNIQUE_LIBRARY`,
`FMS08.SPEC.SESSION_UNDER_PRESSURE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
