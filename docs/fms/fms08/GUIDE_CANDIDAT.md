# FMS-08 — Guide Candidat

## Avant de commencer

Prérequis : certification FMS-03 (compétence M06/M11 déjà vérifiée).

## Ce que tu dois savoir faire

Construire une chaîne de signal approfondie, appliquer la
bibliothèque de technique micro à un type de source précis avec
rationale, et documenter une session de tracking sous contrainte
réelle.

## Comment réviser

1. Relis FMS-03/M06,M11 (déjà acquis, cité ici par référence).
2. Fais les 6 questions de `BANQUE_N1.md`.
3. Traite les 3 cas de `BANQUE_N2.md`.

## Piège le plus fréquent

Affirmer qu'il existe une seule configuration de placement micro
universellement correcte — la pratique réelle varie selon la source
et le contexte.

## Règle absolue

N'affirme jamais de configuration universelle, et ne prétends jamais
détenir cette certification sans le prérequis FMS-03 — élimination
automatique.
