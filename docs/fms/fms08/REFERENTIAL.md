## Repo truth this formation is built on

## Prerequisites

Candidate must already hold the FMS-03 certification (M06/M11
competency verified via that certification record, not re-tested
here).

## Objectives

Recording Engineer (signal chain, mic technique, tracking sessions)
is a distinct professional specialization from Music Producer
(creative direction of a project) — many working producers are not
skilled recording engineers and vice versa. This specialization builds
the depth a Producer-level pass does not require:

- Signal-chain literacy beyond generalist production (preamp/converter
  gain staging, monitoring chain, session file/format discipline).
- Mic technique library (placement patterns by source — vocal,
  acoustic, drum kit, ensemble — and why each choice was made).
- Session-under-real-constraints competency: running a tracking
  session live, under time/budget pressure, without stopping to
  re-derive signal-chain decisions (this is what M11's "sous pression"
  framing already gestures at, extended here to a dedicated
  specialization standard).

## Modules

1. **Signal-chain depth** — beyond FMS-03/M06's encadré framing:
   gain-staging discipline end-to-end, monitoring chain literacy.
2. **Mic technique library** — placement patterns and rationale by
   source type, built as a reference library the candidate can apply,
   not memorize case-by-case.
3. **Tracking session under real constraints** — anchored on FMS-03/M11
   ("sous pression"), extended to a full dedicated Recording Engineer
   assessment scenario (live session, real time/budget pressure,
   documented decisions).

## Assessment

A recorded or documented tracking-session review: candidate is given
a session brief (source type, constraint set) and must produce a
signal-chain/mic-placement plan plus a rationale log — graded against
real audio-engineering practice, never against an invented "correct
answer" this corpus fabricates.
