# FMS-09 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Traduction de mix multi-style, au-delà de FMS-03/M07,M12 |
| C2 | Discipline de mastering-pour-diffusion (loudness/format/livraison) |
| C3 | Pratique freelance — frontière mix/master, cycle de révision |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Confond mix final et master comme un seul livrable |
| 1 | Décisions de mix/mastering imprécises, cibles absentes |
| 2 | Livrable correct mais journal de décisions ou cibles loudness absents |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Livrable + journal complet, cibles loudness/format documentées |

## Règle éliminatoire

Toute confusion persistante entre mix final et master comme un seul
livrable entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
