# FMS-09 — Evidence Model

## Chaîne de preuve

M1 traduction de mix multi-style → M2 master avec cibles loudness/
format documentées → M3 journal de décisions + frontière mix/master
→ correcteur → (jury si 2.0–2.5) → `FMS09.SPEC.*` (réservé, distinct
de `FMS03.SKILL.*`).

## Ce qui compte comme preuve

Le livrable M1 citant FMS-03/M14 sans le reproduire ; le master M2
avec cibles loudness/format documentées ; le journal M3 distinguant
clairement mix et master.

## Ce qui NE compte PAS comme preuve

Un fichier unique présenté comme mix et master à la fois, ou une
reproduction de M14.

`READY_FOR_FREK_PROOF = FALSE`. Éligibilité mission (missions de
mixage/mastering freelance) accordée sur cette spécialisation seule,
indépendamment de la certification FMS-03.

## Réservation Skill ID

`FMS09.SPEC.MULTI_STYLE_MIX_TRANSLATION`,
`FMS09.SPEC.MASTERING_FOR_RELEASE`,
`FMS09.SPEC.FREELANCE_MIX_MASTER_PRACTICE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
