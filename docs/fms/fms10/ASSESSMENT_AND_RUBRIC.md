# FMS-10 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Plan de pré-production audiovisuelle complet (shot list, planning, équipe/équipement) |
| C2 | Fondamentaux d'exécution (caméra, éclairage, capture son sur plateau) |
| C3 | Discipline de frontière — jamais de mixage/mastering enseigné, jamais de capacité plateforme CVLN inventée |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente une capacité de plateforme CVLN, ou réutilise un plan de session musicale non adapté |
| 1 | Plan de pré-production incomplet |
| 2 | Plan complet mais empiète sur le territoire FMS-03/FMS-09 |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Plan complet du tournage à la livraison, frontière FMS-03/09 respectée |

## Règle éliminatoire

Toute capacité de plateforme CVLN inventée, ou toute affirmation
qu'un plan de session musicale suffit tel quel, entraîne un 0
automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
