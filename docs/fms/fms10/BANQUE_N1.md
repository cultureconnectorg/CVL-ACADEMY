# FMS-10 — Banque N1 (formative, M1→M3)


## M1 — pre-production for audiovisual

1. Name 3 elements a pre-production plan for an audiovisual shoot
   must cover. (Shot list, schedule, crew/equipment needs)
2. How does this differ from a music-session plan (FMS-03 territory)?
   (A music-session plan does not need a shot list or on-camera crew
   planning — audiovisual pre-production is a distinct discipline)

## M2 — production execution

3. Name the 3 core production-execution fundamentals this module
   covers. (Camera, lighting, on-set sound capture)

## M3 — post-production & delivery boundary

4. What exactly does FMS-10 teach about audio in post-production?
   (Audio *capture* on set only)
5. What does FMS-10 explicitly never teach, and whose territory is
   it? (Audio mixing/mastering of the captured audio — FMS-03/FMS-09
   territory)
6. Why does this boundary matter? (Prevents duplicate curriculum and
   keeps each specialization's assessment scoped to what it actually
   certifies)
