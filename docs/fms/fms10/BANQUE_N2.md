# FMS-10 — Banque N2 (cas appliqués)

## Cas N2-1 — Mixage audio enseigné dans FMS-10

Un candidat inclut un plan détaillé de mixage/mastering de l'audio
capté dans son livrable FMS-10. Corrige le périmètre.

**Critères de notation:** rappelle la frontière explicite du
référentiel — FMS-10 enseigne la capture audio sur le plateau, jamais
le mixage/mastering, territoire de FMS-03/FMS-09. Pas d'élimination
automatique (pas une invention de capacité), mais note réduite pour
hors-périmètre — le candidat doit renvoyer vers FMS-09, pas
développer le contenu lui-même.

## Cas N2-2 — Plan de tournage confondu avec plan de session musicale

Un stagiaire réutilise un plan de session musicale FMS-03 comme plan
de pré-production audiovisuelle, sans adaptation. Corrige.

**Critères de notation:** cite les éléments réels distincts requis
(shot list, planning, besoins équipe/équipement) — un plan de session
musicale ne couvre pas ces éléments. Élimination si le candidat
maintient qu'un plan de session musicale suffit tel quel pour un
tournage audiovisuel.

## Cas N2-3 — Capacité de plateforme CVLN inventée

Un collègue affirme que "CVLN opère un studio audiovisuel de
production en interne, accessible via cette certification." Corrige.

**Critères de notation:** rappelle qu'aucune plateforme/studio
audiovisuel CVLN n'existe — cette formation enseigne une pratique de
marché standard, jamais une capacité CVLN opérationnelle. Élimination
si le candidat maintient l'affirmation.
