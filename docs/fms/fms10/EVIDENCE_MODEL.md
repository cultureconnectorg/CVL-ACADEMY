# FMS-10 — Evidence Model

## Chaîne de preuve

M1 plan de pré-production → M2 note d'exécution (caméra/éclairage/
son) → M3 note de post-production avec frontière FMS-03/09 explicite
→ correcteur → (jury si 2.0–2.5) → `FMS10.SKILL.*` (réservé, non lié
au runtime).

## Ce qui compte comme preuve

Le plan M1 complet (shot list, planning, équipe/équipement) ; la note
M2 sur les fondamentaux d'exécution ; la note M3 renvoyant
explicitement vers FMS-09 pour le mixage/mastering, jamais développé
ici.

## Ce qui NE compte PAS comme preuve

Un plan de mixage/mastering développé dans ce livrable, une capacité
de plateforme CVLN inventée, ou un plan de session musicale non
adapté.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.

## Réservation Skill ID

`FMS10.SKILL.PREPRODUCTION_PLANNING`,
`FMS10.SKILL.PRODUCTION_EXECUTION`,
`FMS10.SKILL.POSTPRODUCTION_BOUNDARY_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
