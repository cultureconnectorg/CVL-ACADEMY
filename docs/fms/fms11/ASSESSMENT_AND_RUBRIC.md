# FMS-11 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Direction créative cross-média, au-delà de FMS-04/M04,M09 |
| C2 | Briefing et gestion de spécialistes créatifs |
| C3 | Discipline de frontière — jamais FMS-10/FMS-12 assumées ou enseignées ici |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Assume la compétence FMS-12 sans preuve, ou reproduit M04/M09 verbatim |
| 1 | Package cross-média incomplet |
| 2 | Package correct mais empiète sur FMS-10/FMS-12 |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Package cross-média + document de briefing, frontières respectées |

## Règle éliminatoire

Toute affirmation que la compétence FMS-12 est automatiquement
incluse dans FMS-11 sans preuve directe entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
