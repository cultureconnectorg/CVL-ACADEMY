# FMS-11 — Evidence Model

## Chaîne de preuve

M1 note de fondation (citée, non reproduite) → M2 package de
direction créative cross-média → M3 document de briefing de
spécialistes → correcteur → (jury si 2.0–2.5) → `FMS11.SKILL.*`
(réservé, distinct de `FMS04.SKILL.*`).

## Ce qui compte comme preuve

Le package M2 couvrant marque + vidéo + visuels de campagne ; le
document M3 de briefing de spécialistes ; l'absence de toute
affirmation de compétence FMS-10/FMS-12 sans preuve.

## Ce qui NE compte PAS comme preuve

Une compétence FMS-12 assumée sans preuve de portfolio, une technique
caméra/montage enseignée ici, ou M04/M09 reproduits verbatim.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.
