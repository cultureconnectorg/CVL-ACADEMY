# FMS-12 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Staging/blocking/run-of-show, fondamentaux réels |
| C2 | Direction de cue lumière/visuel, coordination technique live |
| C3 | Discipline de frontière FMS-11 + pratique de contingence réelle |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Assume la compétence FMS-11 automatiquement, ou invente une capacité de plateforme CVLN |
| 1 | Plan de staging/cue incomplet |
| 2 | Plan correct mais section de contingence absente |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Plan complet + contingence documentée, frontière FMS-11 respectée |

## Règle éliminatoire

Toute affirmation qu'une compétence FMS-11 implique automatiquement
une compétence FMS-12 (ou l'inverse), ou toute capacité de plateforme
CVLN inventée, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
