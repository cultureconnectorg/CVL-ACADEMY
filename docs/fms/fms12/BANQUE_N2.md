# FMS-12 — Banque N2 (cas appliqués)

## Cas N2-1 — Compétence FMS-11 assumée automatiquement

Un candidat affirme qu'un titulaire FMS-11 (direction créative marque/
vidéo) "peut évidemment diriger un show live sans formation
supplémentaire." Corrige.

**Critères de notation:** cite la frontière explicite — jamais
assumée automatiquement dans un sens ou dans l'autre sans preuve de
portfolio directe. Élimination si le candidat maintient l'équivalence
automatique.

## Cas N2-2 — Plan de contingence absent

Un stagiaire produit un plan de staging/éclairage sans aucune section
de gestion de risque/contingence pour l'événement live. Corrige.

**Critères de notation:** rappelle que la pratique de contingence
d'événement live est une compétence distincte requise — un plan sans
cette section est incomplet. Pas d'élimination automatique (pas une
invention), mais note fortement réduite.

## Cas N2-3 — Capacité de plateforme CVLN inventée

Un collègue affirme que "CVLN opère une régie technique live en
interne, accessible via cette certification." Corrige.

**Critères de notation:** rappelle qu'aucune régie technique live
CVLN n'existe — cette formation enseigne une pratique de marché
standard. Élimination si le candidat maintient l'affirmation.
