# FMS-12 — Evidence Model

## Chaîne de preuve

M1 plan de staging/blocking → M2 plan de cue lumière/visuel → M3
section de contingence + note de frontière FMS-11 → correcteur →
(jury si 2.0–2.5) → `FMS12.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Le plan M1/M2 complet ; la section M3 de gestion de risque réelle et
la note explicite de non-équivalence avec FMS-11.

## Ce qui NE compte PAS comme preuve

Une compétence FMS-11 assumée automatiquement, un plan sans section
de contingence, ou une capacité de plateforme CVLN inventée.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.

## Réservation Skill ID

`FMS12.SKILL.STAGE_BLOCKING`, `FMS12.SKILL.CUE_DIRECTION`,
`FMS12.SKILL.LIVE_CONTINGENCY_PRACTICE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
