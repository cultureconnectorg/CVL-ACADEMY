# FMS-13 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Identification et évaluation de talent, critères documentés |
| C2 | Pratique de sourcing/outreach réelle |
| C3 | Littératie de passation vers FMS-01, jamais de dérive vers son territoire |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Évaluation sans critère documenté, ou capacité de plateforme scouting CVLN inventée |
| 1 | Évaluation/sourcing incomplet |
| 2 | Évaluation correcte mais empiète sur le territoire FMS-01 |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Évaluation + package de passation complets, frontière FMS-01 respectée |

## Règle éliminatoire

Toute évaluation sans critère documenté, ou toute capacité de
plateforme scouting CVLN inventée, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
