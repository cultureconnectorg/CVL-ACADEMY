# FMS-13 — Evidence Model

## Chaîne de preuve

M1 évaluation documentée d'un artiste → M2 note de pratique de
sourcing/outreach → M3 package de passation vers FMS-01 → correcteur
→ (jury si 2.0–2.5) → `FMS13.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

L'évaluation M1 fondée sur des critères documentés ; la note M2 de
sourcing réel ; le package M3 de passation, sans empiéter sur le
développement artistique lui-même.

## Ce qui NE compte PAS comme preuve

Une évaluation esthétique non argumentée, un empiétement sur le
territoire FMS-01, ou une capacité de plateforme scouting CVLN
inventée.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.

## Réservation Skill ID

`FMS13.SKILL.TALENT_EVALUATION`, `FMS13.SKILL.SOURCING_OUTREACH`,
`FMS13.SKILL.SIGNING_HANDOFF_DISCIPLINE` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
