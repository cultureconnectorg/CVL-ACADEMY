# FMS-15 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Qualification de lead sur les champs réels de `LeadCreate` |
| C2 | Gestion du cycle client réel (6 statuts), transitions justifiées |
| C3 | Discipline de reporting — `INSUFFICIENT_DATA` jamais remplacé par un chiffre inventé |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente un chiffre pour un KPI `INSUFFICIENT_DATA`, ou saute des statuts sans justification |
| 1 | Qualification ou progression imprécise |
| 2 | Qualification correcte mais reporting ou justification de statut absente |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Qualification + progression + reporting honnête, tous fondés sur le modèle réel |

## Règle éliminatoire

Toute invention de chiffre pour un KPI `INSUFFICIENT_DATA`, ou tout
saut de statut sans justification documentée, entraîne un 0
automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
