# FMS-18 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Littératie KPI command-center, distinction chiffre réel/`INSUFFICIENT_DATA` |
| C2 | Opérations d'intégration écosystème, jamais de connexion affirmée à tort |
| C3 | Discipline d'audit-log + anti-contamination Command Center CVLN/fms-os |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Affirme qu'une intégration `NOT_CONNECTED` est connectée, ou fusionne les deux Command Center |
| 1 | Rapport opérationnel imprécis |
| 2 | Rapport correct mais discipline d'audit-log ou anti-contamination absente |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Rapport complet, statuts réels honnêtes, distinction Command Center explicite |

## Règle éliminatoire

Toute intégration `NOT_CONNECTED` affirmée connectée, ou toute fusion
des deux systèmes "Command Center", entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
