# FMS-18 — Banque N2 (cas appliqués)

## Cas N2-1 — Intégration affirmée connectée à tort

Un candidat affirme que "l'intégration KORA est connectée et
opérationnelle" dans son rapport, sans vérifier le registre réel.
Corrige.

**Critères de notation:** cite le registre réel `ECOSYSTEM_
INTEGRATIONS` — les 7 adaptateurs sont tous `"status":
"NOT_CONNECTED"` dans le code actuel. Élimination si le candidat
maintient qu'une intégration est connectée sans preuve du registre
réel.

## Cas N2-2 — Confusion entre deux "Command Center"

Un stagiaire confond le `/os/command-center` de `fms-os/fms` avec le
"Command Center"/"CVL Brain" de l'écosystème CVLN référencé ailleurs
dans ce Master Package. Corrige.

**Critères de notation:** cite la garde anti-contamination explicite
— ce sont deux systèmes distincts qui partagent un nom, jamais
fusionnés. Élimination si le candidat maintient la fusion des deux
systèmes après correction.

## Cas N2-3 — Contenu FMS-17 recopié depuis FMS-04

Un candidat réécrit intégralement le contenu des blocs contenu/
campagne de FMS-04 dans son livrable FMS-18. Corrige.

**Critères de notation:** rappelle que ces blocs sont cités par
référence — FMS-18 est une fonction d'opérations de portefeuille de
contenu à travers des projets, pas une re-rédaction du craft de
conception de campagne. Pas d'élimination automatique (pas une
invention), mais note fortement réduite pour duplication de contenu.
