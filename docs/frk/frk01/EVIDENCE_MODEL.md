# FRK-01 — Evidence Model

## Chaîne de preuve

M1 system map annoté → M2 tableau des signaux → M3 tableau des
paliers → M4 note écrite sur la réalité de `issue_proof()` →
correcteur → (jury si 2.0–2.5) → `FRK01.SKILL.*` (réservé, non lié au
runtime).

## Ce qui compte comme preuve

Le system map M1 vérifiable contre `frek_core.py` ; le tableau M2
vérifiable contre `VALID_SIGNALS` ; le tableau M3 vérifiable contre
`STADE_THRESHOLDS` ; la note M4 écrite noir sur blanc, jamais
implicite.

## Ce qui NE compte PAS comme preuve

Une méthode, un signal, ou un palier inventé ; une affirmation que
`issue_proof()` produit une garantie cryptographique aujourd'hui.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`FRK01.SKILL.*`) est en jeu — même principe que chaque module
`docs/kor/`.

## Réservation Skill ID

`FRK01.SKILL.SYSTEM_MAP`, `FRK01.SKILL.SIGNAL_VOCABULARY`,
`FRK01.SKILL.PROGRESSION_TIERS`, `FRK01.SKILL.PROOF_ENGINE_REALITY` —
réservés dans `70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
