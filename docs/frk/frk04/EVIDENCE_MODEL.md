# FRK-04 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Brief de provenance annoté (chaîne de custody, attestation) + note de
gap CVLN → correcteur → (jury si 2.0–2.5) → `FRK04.SKILL.
PROVENANCE_FUNDAMENTALS` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Un brief vérifiable contre la pratique professionnelle réelle
(horodatage à chaque étape, attestation vérifiable par un tiers), avec
une note de gap CVLN explicite.

## Ce qui NE compte PAS comme preuve

Un système CVLN de provenance inventé ; une chaîne de custody sans
horodatage aux étapes intermédiaires ; une affirmation de provenance
non vérifiable présentée comme une attestation.
