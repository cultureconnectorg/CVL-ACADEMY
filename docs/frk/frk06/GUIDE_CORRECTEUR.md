# FRK-06 — Guide Correcteur

## Avant de noter

Ouvre `mint_frek_id()` dans `frek_core.py` à côté de la copie.

## Ce que tu vérifies en priorité

1. Le format d'identifiant est-il exact (`FREK-{seq:03d}`) ?
2. Le candidat invente-t-il une révocation/rotation ?
3. Confond-il avec DID/VC ?

## Ce que tu ne fais pas

Tu ne notes pas sur intuition générique d'un "système d'identité" —
seulement sur le code réel.
