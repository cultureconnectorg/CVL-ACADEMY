# FRK-07 — Evidence Model

## Chaîne de preuve

M1 fondamentaux IdP (non reproduite) → M2 littératie OAuth2/OIDC → M3
cycle de vie des credentials → M4 frontière FRK-06 explicite →
design IAM annoté → correcteur → (jury si 2.0–2.5) → `FRK07.SKILL.*`
(réservé).

## Ce qui compte comme preuve

La restitution correcte du rôle IdP et du modèle OAuth2/OIDC ; un
design IAM cohérent utilisant des patterns réels du marché ; la note
de frontière FRK-06 précisant exactement ce qui manque à
`mint_frek_id()` pour être un IdP.

## Ce qui NE compte PAS comme preuve

Toute affirmation, explicite ou implicite, que `frek_core.py`
implémente OAuth2, OIDC, ou toute forme de cycle de vie de credential ;
une confusion entre authentification et autorisation.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.
