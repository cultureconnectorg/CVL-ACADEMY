# FRK-08 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Littératie DID/VC W3C (document DID, rôles issuer/holder/verifier) |
| C2 | Discipline de gap CVLN (`mint_frek_id()` ≠ DID, précisément) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Affirme une conformité W3C DID/VC inexistante pour `frek_core.py` |
| 1 | Standards mal restitués (confond DID et VC) |
| 2 | Standards corrects mais gap CVLN vague ou incomplet |
| 3 | Standards corrects, gap CVLN explicite, imprécision mineure tolérée |
| 4 | Littératie standard complète + gap CVLN précisément articulé |

## Règle éliminatoire

Toute conformité W3C affirmée à tort pour `frek_core.py` entraîne un 0
automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
