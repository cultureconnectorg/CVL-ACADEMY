# FRK-09 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Cycle de vie identité (émission/rotation/révocation) + récupération/réconciliation |
| C2 | Discipline de gap (FREK-ID n'a aucun de ces mécanismes) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente un mécanisme de rotation/révocation/récupération pour FREK-ID |
| 1 | Cycle de vie mal restitué (confond émission, rotation, révocation) |
| 2 | Cycle de vie correct mais gap FREK-ID vague ou incomplet |
| 3 | Cycle de vie correct, gap explicite, imprécision mineure tolérée |
| 4 | Cycle de vie + récupération/réconciliation complets, gap précisément articulé pour les trois mécanismes |

## Règle éliminatoire

Tout mécanisme inventé (rotation, révocation, ou récupération) pour
FREK-ID entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
