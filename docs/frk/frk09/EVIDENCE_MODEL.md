# FRK-09 — Evidence Model

## Chaîne de preuve

M1 cycle de vie (non reproduite) → M2 récupération/réconciliation →
M3 note de gap FREK-ID explicite pour les trois mécanismes →
design de cycle de vie annoté → correcteur → (jury si 2.0–2.5) →
`FRK09.SKILL.*` (réservé).

## Ce qui compte comme preuve

La restitution correcte des trois stades de cycle de vie (émission,
rotation, révocation) ; un schéma de récupération et un scénario de
réconciliation réels ; la note de gap précisant, pour chacun des trois
mécanismes séparément, ce qui manque à `mint_frek_id()`.

## Ce qui NE compte PAS comme preuve

Toute affirmation, explicite ou implicite, qu'un FREK-ID peut être
rotationné, révoqué, ou récupéré aujourd'hui ; une confusion entre les
trois stades du cycle de vie.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.
