# FRK-10 — Assessment & Rubric

Aucun assessment certifiant n'est administré tant que
`NEEDS_EXPERT_REVIEW` reste non résolu (voir `REFERENTIAL.md`). Seule
une vérification de littératie (`BANQUE_N1.md`/`BANQUE_N2.md`) est
permise — elle ne délivre aucun Skill ID (voir `EVIDENCE_MODEL.md`).

## Compétences couvertes par la vérification de littératie

| Compétence | Description |
|---|---|
| C1 | Littératie eIDAS2/EUDI/SD-JWT (cadre, modèle PID/EAA/QEAA, modèle SD-JWT) |
| C2 | Discipline de juridiction (jamais universel, toujours "sous réglementation UE") |

## Ce qu'une future rubric certifiante exigerait

Une rubric 0–4 par compétence, alignée sur `../CERTIFICATION_MODEL.md`,
n'est écrite qu'une fois `NEEDS_EXPERT_REVIEW` levé par un expert
réglementaire nommé — écrire cette rubric maintenant reviendrait à
fabriquer un jugement de conformité réglementaire que cette Academy
n'a pas la compétence pour rendre seule.

## Règle éliminatoire (applicable dès la vérification de littératie)

Toute généralisation hors UE sans réserve entraîne un 0 automatique,
même au stade littératie non certifiant.
