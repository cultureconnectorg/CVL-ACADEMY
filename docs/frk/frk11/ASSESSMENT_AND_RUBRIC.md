# FRK-11 — Assessment & Rubric

Structure identique à `../fms09/ASSESSMENT_AND_RUBRIC.md` (piste
avancée/practitioner, N1 40% / N2 30% / livrable 30%, même
`../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Construction avancée de chaîne de provenance (PROV-O/C2PA, détection de rupture) |
| C2 | Résolution de litiges/confiance inter-institutions |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente un système CVLN de provenance/confiance avancé |
| 1 | Concepts avancés mal restitués (confond entité/activité/agent, ou fédéré/central) |
| 2 | Concepts corrects mais méthode de résolution de litige vague ou incomplète |
| 3 | Concepts corrects, méthode explicite, imprécision mineure tolérée |
| 4 | Pratique avancée complète (construction + résolution de litige + modèle de confiance), gap explicite hérité de FRK-04 |

## Règle éliminatoire

Tout système CVLN inventé (registre de provenance, autorité de
confiance) entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
