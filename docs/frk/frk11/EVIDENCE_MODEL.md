# FRK-11 — Evidence Model

## Chaîne de preuve

M0 frontière FRK-04 (non reproduite) → M1 construction avancée → M2
résolution de litige & modèle de confiance → cas de litige annoté →
note de réutilisation FRK-04 → correcteur → (jury si 2.0–2.5) →
`FRK11.SKILL.*` (réservé).

## Ce qui compte comme preuve

La construction correcte d'une chaîne multi-maillons (modèle
entité/activité/agent, manifeste signé référençant le précédent) ; la
résolution d'un litige par comparaison maillon-par-maillon avec charge
de la preuve correctement appliquée ; une recommandation de modèle de
confiance (fédéré vs. central) justifiée par le compromis réel.

## Ce qui NE compte PAS comme preuve

Toute invention d'un registre de provenance ou d'une autorité de
confiance CVLN pour trancher un exercice ; une réécriture des
fondamentaux FRK-04 au lieu d'une référence.

`READY_FOR_FREK_PROOF = FALSE`. Aucune éligibilité mission n'existe
encore pour cette formation.
