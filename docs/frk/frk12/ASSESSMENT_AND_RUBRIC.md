# FRK-12 — Assessment & Rubric

Structure identique à `../fms07/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Conception d'artefact de preuve (structure, provenance, détection de falsification) |
| C2 | Méthodologie de validation & vérification (distinction structure/preuve réelle) |
| C3 | Frontière vs. FRK-13 — jamais de capacité CVLN inventée |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Confond avec `issue_proof()`/FRK-13, ou invente une capacité CVLN d'ingénierie de la preuve inexistante |
| 1 | Artefact proposé sans mécanisme de vérification réel (assertion seule) |
| 2 | Artefact structurellement correct mais confond validation et vérification |
| 3 | Distinction validation/vérification correcte, frontière FRK-13 imprécise |
| 4 | Discipline complète — conception + méthodologie + frontière FRK-13 explicite et précise |

## Règle éliminatoire

Toute confusion FRK-12/FRK-13, ou toute affirmation qu'un système CVLN
réel implémente une ingénierie de la preuve complète, entraîne un 0
automatique sur la compétence concernée.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
