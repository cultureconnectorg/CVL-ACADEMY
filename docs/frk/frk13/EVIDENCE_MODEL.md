# FRK-13 — Evidence Model

## Chaîne de preuve

M1 tableau des 3 piliers marché → M2 trace annotée de `issue_proof()`
→ M3 note de communication honnête → M4 note de frontière FRK-75 →
correcteur → (jury si 2.0–2.5) → `FRK13.SKILL.*` (réservé, non lié au
runtime).

## Ce qui compte comme preuve

Le tableau M1 vérifiable contre la pratique professionnelle réelle ;
la trace M2 vérifiable contre `issue_proof()` ; les notes M3/M4
écrites noir sur blanc.

## Ce qui NE compte PAS comme preuve

Une garantie cryptographique affirmée à tort, ou une confusion entre
`issue_proof()` et le vérificateur réel FRK-75.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`FRK13.SKILL.*`) est en jeu.

`FRK13.SKILL.PROOF_CONCEPT`, `FRK13.SKILL.STUB_REALITY`,
`FRK13.SKILL.HONEST_COMMUNICATION` — réservés dans `70_EVIDENCE/
EVIDENCE_ARCHITECTURE.md`.
