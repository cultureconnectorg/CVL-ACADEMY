# FRK-13 — Guide Candidat

## Avant de commencer

Prérequis : FRK-01, FRK-58.

## Ce que tu dois savoir faire

Expliquer les 3 piliers réels d'un proof engine professionnel, la
réalité stub de `issue_proof()`, communiquer l'écart honnêtement, et
distinguer ce stub du vrai vérificateur FRK-75.

## Comment réviser

1. Relis `issue_proof()` dans `frek_core.py`.
2. Fais les 8 questions de `BANQUE_N1.md`, traite les 3 cas de
   `BANQUE_N2.md`.

## Piège le plus fréquent

Soit dénigrer le concept professionnel, soit sur-vendre
l'implémentation actuelle — les deux sont des erreurs.

## Règle absolue

N'affirme jamais une garantie cryptographique inexistante, ni ne
confonds avec FRK-75 — élimination automatique.
