# FRK-15 — Assessment & Rubric

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Rapport sans méthodologie ni référence aux briques amont. |
| 1 | Cite FRK-12/FRK-14 mais sans les articuler correctement. |
| 2 | Articule correctement, structure incomplète. |
| 3 | Structure complète, distingue vérification/production. |
| 4 | Niveau 3 + traite explicitement une frontière FRK-13 le cas échéant. |

**Règle éliminatoire :** accepter une conclusion sans méthodologie
documentée, ou omettre la chaîne de custody sans justification.

**Seuil de passage :** ≥2.5/4.
