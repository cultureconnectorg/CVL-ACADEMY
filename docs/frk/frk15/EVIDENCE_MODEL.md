# FRK-15 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Rapport de preuve technique annoté (méthodologie + chaîne de custody +
conclusion appuyée) → correcteur → (jury si 2.0–2.5) → `FRK15.SKILL.
TECH_EVIDENCE_REPORT.L1` (réservé).

## Ce qui compte comme preuve

Un rapport complet citant FRK-12/FRK-14 par référence, avec une
méthodologie de vérification documentée et une section chaîne de
custody ; une frontière FRK-13 correctement traitée si un artefact
`issue_proof()` est cité.

## Ce qui NE compte PAS comme preuve

Une conclusion sans méthodologie documentée ; une omission de la
chaîne de custody sans justification ; toute présentation de
`issue_proof()` comme preuve techniquement vérifiée.

- Réservation d'ID : `FRK15.SKILL.TECH_EVIDENCE_REPORT.L1` — réservé,
  non émis.
- Prérequis structurel : les preuves de FRK-12 et FRK-14 (une fois
  celle-ci levée de `NEEDS_EXPERT_REVIEW`) doivent être référencées,
  jamais recopiées.
- Mapping `VALID_SIGNALS` : aucun aujourd'hui — l'émission de signal
  suit le même calendrier que celle de FRK-12 (source amont).
