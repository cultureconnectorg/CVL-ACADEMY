# FRK-18 — Assessment & Rubric

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Ne comprend pas le rôle de Bitcoin comme horloge publique. |
| 1 | Comprend le concept, ne sait pas vérifier une preuve. |
| 2 | Vérifie une preuve simplifiée, explication incomplète. |
| 3 | Vérification complète, arbre de Merkle expliqué correctement. |
| 4 | Niveau 3 + discipline CVLN-gap explicite et correcte. |

**Règle éliminatoire :** affirmer qu'un système CVLN utilise
OpenTimestamps aujourd'hui.

**Seuil de passage :** ≥2.5/4.
