# FRK-23 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Schéma d'objet culturel annoté (entités, attributs, relations) → note
de frontière `.fk` → correcteur → (jury si 2.0–2.5) →
`FRK23.SKILL.CULTURAL_OBJECT_MODEL.L1` (réservé).

## Ce qui compte comme preuve

Un modèle avec entités/attributs/relations réutilisables indépendamment
de tout format de sérialisation ; la note de frontière `.fk`
expliquant l'indépendance réelle des deux sujets.

## Ce qui NE compte PAS comme preuve

Un modèle dont un choix de structure est justifié par une supposition
sur l'encodage `.fk` ; toute affirmation de dépendance au format `.fk`.

- Réservation d'ID : `FRK23.SKILL.CULTURAL_OBJECT_MODEL.L1` — réservé,
  non émis.
- Frontière explicite : jamais couplé à `.fk` (FRK-21/22,
  `BLOCKED_PRODUCT_DEPENDENCY`, aucune spec réelle dans ce dépôt).
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
