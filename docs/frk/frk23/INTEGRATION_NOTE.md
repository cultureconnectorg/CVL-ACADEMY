# FRK-23 — Integration Academy Package Note

## Réel vs. supposé

**Réel :** la discipline réelle de modélisation d'objets culturels
(entités, attributs, relations, schémas de métadonnées) comme pratique
marché-générale, structurellement indépendante de tout format de
sérialisation. `.fk` (FRK-21/22) reste sans spécification réelle dans
ce dépôt.

**Supposé :** `FRK23.SKILL.*` réel dans le runtime de cette Academy —
inexistant (`NO_RUNTIME_BINDING`). Toute dépendance d'un modèle FRK-23
à `.fk` — jamais valide, même implicite.

## Dépendances

- `FREK_01_75_RECONCILIATION.md`, `docs/frk/frk21/GAP.md`,
  `docs/frk/frk22/GAP.md` (frontière, jamais fusionnée — ces deux
  formations restent `BLOCKED_PRODUCT_DEPENDENCY`).

## Ce qu'une future intégration exigerait

1. Une entrée `FRK23` dans le registre de certification de cette
   Academy.
2. Une surface candidat réelle (ce corpus est markdown seul).
3. Un vrai schéma d'objet culturel à évaluer par un correcteur humain
   — inexistant aujourd'hui.
4. Note : cette formation n'attend jamais la levée du blocage FRK-21/22
   pour devenir utile — elle est déjà complète et indépendante.
