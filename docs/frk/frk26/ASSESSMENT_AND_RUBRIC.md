# FRK-26 — Assessment & Rubric

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Modèle relationnel plat, pas de graphe. |
| 1 | Graphe basique, cycles non exclus. |
| 2 | Graphe acyclique, horodatage absent. |
| 3 | Graphe acyclique horodaté correct. |
| 4 | Niveau 3 + discipline CVLN-gap explicite. |

**Règle éliminatoire :** graphe cyclique pour une chaîne de dérivation,
ou affirmation d'un graphe de provenance CVLN réel.

**Seuil de passage :** ≥2.5/4.
