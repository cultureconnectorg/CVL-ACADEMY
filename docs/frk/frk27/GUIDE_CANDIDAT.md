# FRK-27 — Guide Candidat

## Avant de commencer

Prérequis : FRK-26. Apprends l'ingénierie de knowledge graph culturel
en réutilisant les fondamentaux de FRK-26 par référence — jamais en les
recopiant.

## Ce que tu dois savoir faire

Concevoir une ontologie minimale (types de nœuds, types de relations)
pour un domaine culturel, et expliquer pourquoi les requêtes
d'inférence sont naturelles sur un knowledge graph mais difficiles en
SQL relationnel classique.

## Comment réviser

1. Relis `docs/frk/frk26/REFERENTIAL.md` (fondamentaux, prérequis).
2. Lis `REFERENTIAL.md` §Objectives et §Modules de cette formation.
3. Fais les 8 questions de `BANQUE_N1.md`.
4. Traite les 3 cas de `BANQUE_N2.md`.

## Piège le plus fréquent

Confondre knowledge graph et base de données relationnelle —
élimination automatique. Second piège : redéfinir les fondamentaux de
FRK-26 au lieu de les citer.

## Règle absolue

Une ontologie a des relations réellement typées, jamais de simples
arêtes génériques renommées.
