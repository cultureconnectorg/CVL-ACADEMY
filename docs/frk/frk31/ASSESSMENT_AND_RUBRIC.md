# FRK-31 — Assessment & Rubric

## Exercice

Le candidat conçoit un petit schéma de signaux d'affinité/résonance/
cadence pour une plateforme culturelle générique, classe trois
observations comportementales sous le bon signal, puis cite de
mémoire les 8 valeurs réelles de `VALID_SIGNALS`.

## Compétences évaluées

| ID | Compétence |
|---|---|
| C1 | Définir précisément affinité, résonance et cadence, sans les confondre entre eux. |
| C2 | Maintenir la frontière obligatoire avec `VALID_SIGNALS` réel. |
| C3 | Citer de mémoire les 8 valeurs réelles de `VALID_SIGNALS`. |

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Confond ce vocabulaire avec `VALID_SIGNALS` réel. |
| 1 | Distingue en théorie, vocabulaire mal défini. |
| 2 | Vocabulaire défini, frontière implicite seulement. |
| 3 | Vocabulaire défini, frontière explicite et correcte. |
| 4 | Niveau 3 + cite les 8 valeurs réelles de `VALID_SIGNALS` de mémoire + classification correcte des trois observations. |

**Règle éliminatoire (obligatoire) :** confondre ce vocabulaire avec
`VALID_SIGNALS`, ou affirmer qu'`emit_signal()` accepte ces valeurs.

**Seuil de passage :** ≥2.5/4.
