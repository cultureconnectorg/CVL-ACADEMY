# FRK-33 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Schéma de cycle de vie créatif annoté (versionnage, provenance) → note
de frontière Fondation Cœurvolan → correcteur → (jury si 2.0–2.5) →
`FRK33.SKILL.CREATIVE_LIFECYCLE.L1` (réservé).

## Ce qui compte comme preuve

Une chaîne d'états techniques (brouillon → publié → dérivé)
référençant correctement son prédécesseur ; l'absence totale de
décision de droits dans le schéma technique.

## Ce qui NE compte PAS comme preuve

Un schéma intégrant, même sous forme de champ de statut, une décision
de gouvernance de droits ; toute duplication de la doctrine Fondation
Cœurvolan.

- Réservation d'ID : `FRK33.SKILL.CREATIVE_LIFECYCLE.L1` — réservé,
  non émis.
- Frontière permanente : suivi technique (FREK) vs. doctrine de droits
  communautaires (Fondation Cœurvolan) — jamais fusionnés.
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
