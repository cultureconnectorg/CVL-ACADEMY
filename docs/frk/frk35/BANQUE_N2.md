# FRK-35 — Banque N2 (cas appliqués)

## Cas 1 — Conception d'une chaîne de versions avec crédits

Le candidat conçoit un schéma de suivi de versions/dérivés avec crédits
de contribution, en citant FRK-34 par référence pour l'identité de
l'œuvre de base.

**Critère éliminatoire :** redéfinir les fondamentaux de FRK-34 au lieu
de les citer.

## Cas 2 — Frontière héritée LabelOS

Le candidat doit expliquer pourquoi les crédits de contribution qu'il
modélise ne constituent jamais une décision de droits d'auteur ou de
répartition de royalties.

**Critère éliminatoire :** intégrer une décision de droits dans le
schéma de crédits.
