# FRK-35 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Schéma de versions/dérivés/crédits annoté → note de référence FRK-34
→ note de frontière LabelOS → correcteur → (jury si 2.0–2.5) →
`FRK35.SKILL.VERSION_CREDIT_TRACKING.L1` (réservé).

## Ce qui compte comme preuve

Une chaîne de versions/dérivés référençant correctement sa source ;
des crédits de contribution purement techniques (contributeur + rôle
+ version) ; la référence correcte à FRK-34 et l'absence de décision
de droits.

## Ce qui NE compte PAS comme preuve

Un schéma de crédits intégrant une décision de droits ou de royalties ;
une redéfinition des fondamentaux de FRK-34 au lieu d'une référence.

- Réservation d'ID : `FRK35.SKILL.VERSION_CREDIT_TRACKING.L1` —
  réservé, non émis.
- Prérequis recommandé : FRK-34, réutilisé par référence.
- Frontière héritée : jamais LabelOS LOS-02 (catalogue/droits).
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
