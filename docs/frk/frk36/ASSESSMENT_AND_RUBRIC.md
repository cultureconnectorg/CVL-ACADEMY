# FRK-36 — Assessment & Rubric

## Exercice

Le candidat conçoit un flux de capture authentique avec preuve
d'intégrité embarquée dès l'origine, rédige une note expliquant la
discipline `NEEDS_REPO_AUDIT` pour FREKRAW, puis distingue ce statut
de `NEEDS_EXPERT_REVIEW`.

## Compétences évaluées

| ID | Compétence |
|---|---|
| C1 | Concevoir une capture authentique avec preuve d'intégrité intégrée dès l'origine. |
| C2 | Maintenir la discipline `NEEDS_REPO_AUDIT` sans affirmer de comportement FREKRAW. |
| C3 | Distinguer `NEEDS_REPO_AUDIT` et `NEEDS_EXPERT_REVIEW`. |

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Affirme un comportement précis de FREKRAW. |
| 1 | Évite l'affirmation, conception de capture incomplète. |
| 2 | Conception de capture correcte, preuve après-coup plutôt qu'à l'origine. |
| 3 | Conception correcte, preuve intégrée dès l'origine. |
| 4 | Niveau 3 + discipline `NEEDS_REPO_AUDIT` explicite et correcte + distinction correcte avec `NEEDS_EXPERT_REVIEW`. |

**Règle éliminatoire :** toute affirmation sur le fonctionnement réel
de FREKRAW.

**Seuil de passage :** ≥2.5/4.
