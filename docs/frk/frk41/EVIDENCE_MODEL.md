# FRK-41 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Schéma de preuve de stem annoté (hash, version, crédit) → note de
référence FRK-40 → note de frontière FMS-03/08 → correcteur → (jury si
2.0–2.5) → `FRK41.SKILL.MUSIC_STEM_VERSION_PROOF.L1` (réservé).

## Ce qui compte comme preuve

Un schéma de versionnage de stem non écrasant (hash + horodatage par
export) ; une preuve de crédit purement technique ; la référence
correcte à FRK-40 et la frontière FMS-03/08 explicitement respectée.

Toute dérive vers un jugement de qualité de production ; une
redéfinition des fondamentaux de suivi de session de FRK-40 au lieu
d'une référence.

- Réservation d'ID : `FRK41.SKILL.MUSIC_STEM_VERSION_PROOF.L1` —
  réservé, non émis.
- Prérequis recommandé : FRK-40, réutilisé par référence.
- Frontière héritée : jamais FMS-03/08 (craft de production).
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
