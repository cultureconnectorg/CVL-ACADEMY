# FRK-44 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Mécanisme de réconciliation annoté (détection, stratégie, compromis) →
note de référence FRK-43 → correcteur → (jury si 2.0–2.5) →
`FRK44.SKILL.OFFLINE_RECOVERY_RECONCILIATION.L1` (réservé).

## Ce qui compte comme preuve

Un mécanisme de détection de divergence d'état réel ; une stratégie de
réconciliation choisie avec son compromis explicitement identifié ; la
référence correcte à FRK-43.

## Ce qui NE compte PAS comme preuve

L'absence de mécanisme de réconciliation ; une stratégie présentée
sans compromis identifié ; une redéfinition des fondamentaux de FRK-43
au lieu d'une référence.

  — réservé, non émis.
- Prérequis recommandé : FRK-43, réutilisé par référence.
