# FRK-53 — Assessment & Rubric

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Affirme l'existence d'un SDK FREK public. |
| 1 | Évite l'affirmation, conception de SDK incomplète. |
| 2 | Conception correcte, DX non traitée. |
| 3 | Conception correcte avec DX (types, erreurs actionnables). |
| 4 | Niveau 3 + référence propre et non-dupliquée à FRK-52. |

**Règle éliminatoire :** affirmer l'existence d'un SDK FREK public, ou
redéfinir FRK-52 au lieu de le citer.

**Seuil de passage :** ≥2.5/4.
