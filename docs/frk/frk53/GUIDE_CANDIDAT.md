# FRK-53 — Guide Candidat

## Avant de commencer

Prérequis recommandé : FRK-52. Apprends l'ingénierie de SDK
(bibliothèque cliente, DX) — jamais attribuée à un système CVLN, car
aucun SDK FREK public n'existe aujourd'hui (même constat que FRK-52).

## Ce que tu dois savoir faire

Concevoir un SDK avec modèles typés, erreurs traduites en exceptions
actionnables, et une politique de retry/idempotence claire — et citer
FRK-52 par référence pour les fondamentaux de conception d'API.

## Comment réviser

1. Relis `docs/frk/frk52/REFERENTIAL.md` (fondamentaux, prérequis).
2. Lis `REFERENTIAL.md` §Objectives et §Modules de cette formation.
3. Fais les 9 questions de `BANQUE_N1.md`.
4. Traite les 3 cas de `BANQUE_N2.md`.

## Piège le plus fréquent

Affirmer l'existence d'un SDK FREK public — élimination automatique.
Second piège : redéfinir les fondamentaux de conception d'API de
FRK-52 au lieu de les citer.

## Règle absolue

Aucun SDK FREK public n'existe aujourd'hui.
