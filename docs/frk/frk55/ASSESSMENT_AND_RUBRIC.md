# FRK-55 — Assessment & Rubric

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Standards transversaux API/événements (taxonomie d'erreur, versionnage unifié) + référence FRK-52/54 |

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Aucune cohérence transversale entre API et événements. |
| 1 | Cohérence partielle, taxonomie d'erreur incomplète. |
| 2 | Cohérence correcte, versionnage non unifié. |
| 3 | Cohérence et versionnage unifiés correctement. |
| 4 | Niveau 3 + référence propre et non-dupliquée à FRK-52/54. |

**Règle éliminatoire :** redéfinir FRK-52/54 au lieu de les citer, ou
schémas de version incohérents non perçus comme problème.

**Seuil de passage :** ≥2.5/4.
