# FRK-55 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Standards transversaux annotés (taxonomie d'erreur, versionnage) →
note de référence FRK-52/54 → diagnostic de bug d'intégration →
correcteur → (jury si 2.0–2.5) →
`FRK55.SKILL.CROSS_CUTTING_STANDARDS.L1` (réservé).

## Ce qui compte comme preuve

Une taxonomie d'erreur et un schéma de version réellement identiques à
travers API et événements ; un diagnostic correct d'un bug
d'intégration causé par divergence de version ; la référence correcte
à FRK-52/54.

## Ce qui NE compte PAS comme preuve

Des schémas de version incohérents non perçus comme problème ; une
redéfinition des fondamentaux de FRK-52 ou FRK-54 au lieu d'une
référence.

- Réservation d'ID : `FRK55.SKILL.CROSS_CUTTING_STANDARDS.L1` —
  réservé, non émis.
- Prérequis recommandés : FRK-52, FRK-54, réutilisés par référence,
  jamais redéfinis.
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
