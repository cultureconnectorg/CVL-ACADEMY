# FRK-56 — Assessment & Rubric

Structure identique à `docs/frk/frk01/ASSESSMENT_AND_RUBRIC.md` (N1
40% / N2 30% / livrable 30%, même `../CERTIFICATION_MODEL.md`).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Littératie des headers `FREK_PROOF_MAPPING` réels |
| C2 | Rationale écrite de `READY_FOR_FREK_PROOF = FALSE` |
| C3 | Discipline de réutilisation du cas worked, jamais re-dérivé |
| C4 | Anti-contamination (header ≠ intégration technique) |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Affirme `READY_FOR_FREK_PROOF = TRUE` sans preuve, ou affirme une intégration technique inexistante |
| 1 | Re-dérive le cas depuis zéro sans citer le précédent |
| 2 | Littératie correcte mais rationale imprécise |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite `kor01/skills/EVIDENCE_MODEL.md` ligne par ligne |

## Règle éliminatoire

Toute affirmation `TRUE` non justifiée, ou toute intégration technique
inventée, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
