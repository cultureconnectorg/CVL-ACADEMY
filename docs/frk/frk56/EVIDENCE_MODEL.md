# FRK-56 — Evidence Model

## Chaîne de preuve

M1 lecture de header annotée → M2 rationale écrite (citée verbatim de
`kor01/skills/EVIDENCE_MODEL.md`) → M3+M4 notes de discipline →
correcteur → (jury si 2.0–2.5) → `FRK56.SKILL.*` (réservé, non lié au
runtime).

## Ce qui compte comme preuve

La lecture M1 vérifiable contre un header réel ; la rationale M2
vérifiable contre `kor01/skills/EVIDENCE_MODEL.md` ; les notes M3/M4
écrites noir sur blanc.

## Ce qui NE compte PAS comme preuve

Une affirmation `TRUE` non justifiée, ou une intégration technique
FREK↔KORA inventée.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`FRK56.SKILL.*`) est en jeu.
