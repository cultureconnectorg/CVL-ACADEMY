## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Affirme une intégration fonctionnelle FREK×Wallet, ou confond les 4 systèmes en jeu |
| 1 | Schedule de retry incorrect ou table d'outbox confondue |
| 2 | Littératie correcte mais frontière imprécise |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite `docs/gmd/gmd31`/`gmd32` ligne par ligne |

## Règle éliminatoire

Toute intégration fonctionnelle affirmée à tort, ou toute confusion
entre les 4 systèmes distincts, entraîne un 0 automatique.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
