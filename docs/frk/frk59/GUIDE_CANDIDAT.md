# FRK-59 — Guide Candidat

## Avant de commencer

Prérequis : FRK-01, FRK-58, littératie de `docs/gmd/gmd31`/`gmd32`.

## Ce que tu dois savoir faire

Décrire les deux outbox réels et indépendants de Good Mood, et refuser
d'affirmer qu'ils forment une intégration fonctionnelle FREK×Wallet.

## Comment réviser

1. Lis `docs/gmd/gmd31/REFERENTIAL.md` et `gmd32/REFERENTIAL.md` en
   entier.
2. Fais les 8 questions de `BANQUE_N1.md`, traite les 3 cas de
   `BANQUE_N2.md`.

## Piège le plus fréquent

Affirmer que deux clients découplés dans le même code base forment une
intégration, ou confondre les systèmes Good Mood avec ceux de cette
Academy.

## Règle absolue

N'affirme jamais une intégration fonctionnelle inexistante —
élimination automatique.
