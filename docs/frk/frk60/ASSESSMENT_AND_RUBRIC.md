# FRK-60 — Assessment & Rubric

## Grille (0–4)

| Niveau | Critère |
|---|---|
| 0 | Affirme qu'une intégration FREK↔Intelligence OS existe aujourd'hui. |
| 1 | Évite l'affirmation, exigences documentées incomplètes. |
| 2 | Exigences documentées complètes, double-stub non perçu. |
| 3 | Exigences complètes + double-stub correctement identifié. |
| 4 | Niveau 3 + citation précise des deux artefacts réels concernés. |

**Règle éliminatoire :** affirmer qu'une intégration réelle existe côté
FREK ou côté Intelligence OS.

**Seuil de passage :** ≥2.5/4.
