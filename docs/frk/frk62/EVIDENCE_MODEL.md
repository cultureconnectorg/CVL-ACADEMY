# FRK-62 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Plan de vérification patrimoniale annoté (cadence, méthode) → note de
référence FRK-61 → note de frontière Fondation Cœurvolan → correcteur
→ (jury si 2.0–2.5) → `FRK62.SKILL.HERITAGE_RECORD_INTEGRITY.L1`
(réservé).

## Ce qui compte comme preuve

Un plan de vérification périodique réel (ré-hachage, audit
d'échantillon) avec cadence justifiée ; la référence correcte à
FRK-61 ; l'absence totale de décision de droits d'accès dans le plan.

## Ce qui NE compte PAS comme preuve

Un plan qui confond sauvegarde et vérification active ; toute décision
de droits d'accès intégrée au plan de vérification technique.

- Réservation d'ID : `FRK62.SKILL.HERITAGE_RECORD_INTEGRITY.L1` —
  réservé, non émis.
- Prérequis recommandé : FRK-61, réutilisé par référence.
- Frontière héritée : jamais Fondation Cœurvolan §18 (droits/consentement).
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
