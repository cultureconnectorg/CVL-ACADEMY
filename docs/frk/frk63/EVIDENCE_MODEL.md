# FRK-63 — Evidence Model

`READY_FOR_FREK_PROOF = FALSE`.

## Chaîne de preuve

Mécanisme de preuve géographique annoté (coordonnées signées,
horodatage) → note de frontière KOR-15 → correcteur → (jury si
2.0–2.5) → `FRK63.SKILL.GEO_EVIDENCE_PROVENANCE.L1` (réservé).

## Ce qui compte comme preuve

Un mécanisme technique liant coordonnées, horodatage et hash de
l'actif ; les garanties exactes précisément énoncées (localisation
authentique, rien de plus) ; la frontière KOR-15 correctement
articulée.

## Ce qui NE compte PAS comme preuve

Un mécanisme intégrant une décision de stratégie commerciale/droits ;
toute affirmation qu'une preuve géographique détermine automatiquement
des droits.

- Réservation d'ID : `FRK63.SKILL.GEO_EVIDENCE_PROVENANCE.L1` —
  réservé, non émis.
- Frontière d'altitude : preuve technique (FRK-63) vs. stratégie
  marché/droits par territoire (KOR-15, non construit) — jamais
  fusionnées.
- Mapping `VALID_SIGNALS` : aucun aujourd'hui.
