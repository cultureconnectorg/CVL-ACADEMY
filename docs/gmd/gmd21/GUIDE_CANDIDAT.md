# GMD-21 — Guide Candidat

## Ce que tu vas apprendre

À la fin de GMD-21, tu sauras lire le système réel de Good Mood OS
(catalogue, événements, billets, scan, CRM fans, merch, paiements,
reporting, outbox FREK/Wallet, sécurité admin) et savoir immédiatement
qui — quelle spécialisation GMD — est responsable de quoi. C'est la
formation d'orientation : elle ne te rend expert d'aucun sous-système,
elle te donne la carte pour choisir ta spécialisation ensuite.

## Comment travailler

1. Lis `REFERENTIAL.md` en entier avant de commencer les modules.
2. Les 4 modules (M1-M4) se travaillent dans l'ordre — chacun suppose
   le précédent acquis.
3. Chaque module a un livrable réel, pas un exercice théorique : tu
   produiras une carte de routes annotée, une fiche de modèles de
   données, une analyse d'auth, une explication de l'outbox.
4. La seule source de vérité est le vrai code (`gmfest972/
   goodmooddjsayd`, lecture seule) — jamais une supposition. Si tu ne
   trouves pas la réponse dans le code, la réponse honnête est "je ne
   sais pas, il faudrait vérifier", jamais une invention.

## Ce qui t'éliminera à l'évaluation

Inventer une capacité qui n'existe pas dans le repo réel — en
particulier prétendre qu'un mécanisme d'incident/rollback (GMD-34)
existe. Ce n'est pas un piège : c'est la compétence la plus importante
de cette formation.

## Après GMD-21

Tu es prêt pour n'importe laquelle des spécialisations GMD-22→33,
selon tes affinités (données/CRUD : GMD-22/23/24/27 ; terrain :
GMD-25 ; relation client : GMD-26/29 ; argent : GMD-28 ; intégrations
externes : GMD-31/32 ; sécurité : GMD-33).
