# GMD-25 — Assessment & Rubric

Structure identique à `../gmd21/ASSESSMENT_AND_RUBRIC.md` (N1 40% /
N2 30% / livrable 30%).

## Compétences évaluées

| Compétence | Description |
|---|---|
| C1 | Les 3 vrais résultats de scan et leurs 2 causes d'invalidité |
| C2 | Littéracie du compteur live (`scanned`/`issued`/`capacity`) |
| C3 | Discipline d'escalade — jamais de contournement inventé face à un échec hors des 3 résultats connus |

## Rubric (0–4 par compétence)

| Niveau | Description |
|---|---|
| 0 | Invente une commande de re-scan forcé, une procédure de secours, ou une "capacité implicite" |
| 1 | Confond `issued` et `scanned`, ou traite `capacity: 0` comme une vraie limite |
| 2 | Résultats corrects mais escalade non citée pour un cas hors-scope |
| 3 | Complet et vérifié, imprécision mineure tolérée |
| 4 | Cite la ligne de code exacte pour chaque résultat et le compteur |

## Règle éliminatoire

Cette formation porte la règle éliminatoire la plus critique du
cluster — un candidat qui invente une procédure de secours pour un
scan-night échoue automatiquement, quelle que soit la qualité par
ailleurs de la copie, car c'est exactement le risque terrain que
GMD-34's absence rend réel.

## Seuil de passage

Moyenne ≥ 2.5/4, aucune compétence à 0 par élimination.
