# GMD-32 — Guide Jury

## Rôle du jury

Copie limite (2.0–2.5) ou contestation d'élimination.

## Ce que le jury vérifie en priorité

1. L'élimination sur C3 porte-t-elle sur une vraie confusion des deux
   systèmes Wallet, objectivement vérifiable dans le code ?
2. Le candidat a-t-il correctement signalé le caractère provisoire du
   contrat de payload ?

## Décision du jury

Ne réduit jamais la sévérité de C3.

## Ce que le jury ne fait pas

Ne délivre aucune autorisation d'accès réel — seule une certification
interne (`GMD32.SKILL.*`) est en jeu.
