## Namespace — collision check

`FMSxx-Ay` (FMS) vs `KLTxx.SKILL.Cnn` (Kiltikonet) : formes distinctes,
aucune collision possible même en cas d'import réel dans le même
système (vérifié par grep : zéro ID `KLTxx.SKILL.*` dans `fms_canonical/`
ou `fms_import/`). Entre formations KLT : préfixe `KLTxx` unique par
formation, aucune collision.

## Compétences communes vs spécialisées — synthèse

- **Communes (famille identifiable, objet disjoint)** : lecture de
  contexte (5/5 formations), documenter/prouver sans fabriquer (4/5 +
  1 adjacente), éthique/tension (4/5), synthèse terminale (5/5).
- **Spécialisées** : la majorité des 59 — chaque formation a entre 5 et
  9 compétences qui n'ont aucun équivalent ailleurs dans le corpus (ex.
  `KLT-01`/C08-C09 adaptation publics, `KLT-03`/C02-C05 navigation
  institutionnelle, `KLT-04`/C03-C06 fondation associative,
  `KLT-05`/C02-C04 identités/badges).
