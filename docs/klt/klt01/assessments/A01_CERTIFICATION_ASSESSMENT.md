# KLT01-A01 — Assessment certificatif

```
ASSESSMENT_ID: KLT01-A01
NAMESPACE: distinct de FMS (aucun ID FMSxx-Ay réutilisé — voir
skills/SKILL_ID_REGISTRY.md)
NIVEAU: N3, terminal (= module M11)
```

## Objectif

Prouver que le candidat peut préparer et conduire une action de
médiation culturelle structurée, **dans les limites de son rôle**
(voir `KLT0003_CANONICAL_REFERENTIAL.md` §1.4/§11) — pas au-delà.

## Ce que l'assessment vérifie (et ce qu'il ne vérifie pas)

Vérifie l'articulation de C1 à C10 sur une action réelle (le cas fil
rouge ou une action réelle équivalente en situation professionnelle
future). Ne vérifie **pas** une compétence de négociation institutionnelle
(`KLT-03`), de gestion budgétaire (`KLT-02`), de gouvernance (`KLT-04`)
ou d'opération de plateforme (`KLT-05`) — un dossier qui empiète sur ces
domaines n'est pas mieux noté, il est hors périmètre.

## Format du dossier professionnel attendu

| Section | Contenu attendu | Origine (module) |
|---|---|---|
| Contexte | Territoire, organisation commanditaire, enjeu | M01 |
| Diagnostic | Besoin réel distinct de la demande formulée | M01, M02 |
| Acteurs | Cartographie qualifiée et priorisée | M03 |
| Publics | Publics visés, caractérisés (jeunes/seniors/autres) | M08, M09 |
| Objectifs | Objectifs de l'action, reliés au diagnostic | M04 |
| Dispositif | Fiche action complète | M04 |
| Méthode | Déroulé, posture d'animation retenue | M05 |
| Accessibilité | Contraintes identifiées et traitées dès la conception | M04, M08, M09 |
| Risques | Tensions anticipées (dont interculturelles) et traitement prévu | M07 |
| Posture | Positionnement du candidat dans les limites de son rôle | référentiel §1.4 |
| Documentation | Registre de preuves | M10 |
| Preuves | Pièces réelles produites (livrables M01-M09) | M01-M09 |
| Bilan / retour réflexif | Ce qui a fonctionné, ce qui n'a pas fonctionné, honnêtement | tous |

## Déroulé

1. **Dossier écrit** — remis avant la soutenance, structuré selon le
   tableau ci-dessus.
2. **Soutenance orale** — 20 minutes de présentation + questions du jury
   (voir `guides/JURY_GUIDE.md`).
3. **Délibération** — sur la base de `RUBRIC.md`, seuils observables.

## Conditions d'échec explicites (`FAILURE_MODES`)

- Le dossier revendique une action hors du mandat `KLT-01` (négociation
  institutionnelle, décision budgétaire, autorité de gouvernance,
  opération de plateforme) → non conforme, indépendamment de la qualité
  rédactionnelle.
- Une pièce du registre de preuves (M10) est présentée sans source ni
  provenance, ou une donnée Observatory est simulée (`NO_FAKE_
  OBSERVATORY`) → éliminatoire.
- Le bilan réflexif ne mentionne aucune limite ou difficulté réelle
  (dossier "parfait" non crédible) → pénalisant, non nécessairement
  éliminatoire (voir `RUBRIC.md`).
- Le consentement documenté est absent pour l'interview de mémoire orale
  (M09) → éliminatoire pour la pièce concernée, dossier renvoyé pour
  régularisation avant délibération finale.

## Ce que la réussite délivre — et ne délivre pas

La réussite de `KLT01-A01` délivre une évaluation **Academy** (interne à
CVLN Academy) et maintient le badge `Kiltikonet Ambassador` en tant que
`DISPLAY_ONLY_LEGACY` (voir `skills/EVIDENCE_MODEL.md`,
`CERTIFICATION_MODEL.md`). Elle ne délivre **ni** une certification RNCP
ou d'État, **ni** une autorisation d'opérateur Kiltikonet
(`OPERATOR_AUTHORIZATION = N/A` pour ce métier) — voir
`CERTIFICATION_MODEL.md` pour la distinction complète.
