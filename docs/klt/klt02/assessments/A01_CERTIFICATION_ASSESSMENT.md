# KLT02-A01 — Assessment certificatif

```
ASSESSMENT_ID: KLT02-A01
NAMESPACE: distinct de FMS et de KLT-01 (voir skills/SKILL_ID_REGISTRY.md)
NIVEAU: N3, terminal (= module M11)
```

## Objectif

Prouver que le candidat peut piloter un projet culturel réel, du cadrage
à la reconduction stratégique, **dans les limites de son rôle** — pas
au-delà (voir référentiel `00_REFERENTIEL_ET_BLUEPRINTS.md`, limites du
rôle).

## Ce que l'assessment vérifie (et ce qu'il ne vérifie pas)

Vérifie l'articulation de `C1` à `C10` sur un projet réel (le cas fil
rouge angle projet, ou un projet réel équivalent). Ne vérifie pas une
compétence de négociation institutionnelle formelle (`KLT-03`), de
gouvernance associative (`KLT-04`), d'opération de plateforme (`KLT-05`)
ni de conduite directe de l'action de médiation (`KLT-01`, déjà couvert
ailleurs dans le parcours).

## Format du dossier professionnel attendu

| Section | Contenu attendu | Origine (module) |
|---|---|---|
| Mandat | Note de cadrage validée | M01 |
| Parties prenantes | Étude de besoin + carte | M02 |
| Budget | Budget prévisionnel complet | M03 |
| Financement | Dossier(s) de financement | M04 |
| Équipe | Planning + organigramme | M05 |
| Pilotage | Tableau de bord + écarts documentés | M06 |
| Communication | Kit + plan média | M07 |
| Risques | Registre des risques | M08 |
| Impact | Rapport d'évaluation | M09 |
| Bilan | Bilan + feuille de route | M10 |
| Réflexif | Perturbation réelle rencontrée et sa gestion | tous |

## Déroulé

1. Dossier écrit.
2. Soutenance orale (20 min + questions).
3. Délibération sur la base de `RUBRIC.md`.

## Conditions d'échec explicites

- Le dossier revendique une action hors mandat (négociation
  institutionnelle, décision de gouvernance, opération de plateforme,
  conduite directe de médiation) → non conforme.
- Une donnée Observatory est simulée dans le rapport d'impact (M09) →
  éliminatoire.
- Un chiffre d'impact non observé est présenté comme un fait →
  éliminatoire.
- Aucune perturbation réelle n'est documentée (dossier "parfait" non
  crédible) → pénalisant.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** ; badge `Cultural Project Manager` maintenu en
`DISPLAY_ONLY_LEGACY`. Ni certification RNCP, ni autorisation
d'opérateur (`OPERATOR_AUTHORIZATION = N/A` pour ce métier) — voir
`CERTIFICATION_MODEL.md`.
