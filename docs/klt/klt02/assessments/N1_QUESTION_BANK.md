# KLT-02 — Banque N1

```
Répartition : notions, responsabilités, limites, publics, éthique,
méthode, reconnaissance de situation, lecture de contexte.
```

**Q-N1-01** (notions, C1) — Un mandat projet répond à quelles quatre
questions qu'une intention formulée ne répond jamais ?
`CORRECT_ANSWER` : périmètre, ressources, autorité de décision, échéance.
`RATIONALE` : M01, notions essentielles.
`DISTRACTOR_RATIONALE` : "budget et calendrier seulement" omet
l'autorité de décision, point de friction fréquent en cours de projet.
`DIFFICULTY` : facile.

**Q-N1-02** (notions, C3) — Un budget prévisionnel doit distinguer quoi
de quoi ?
`CORRECT_ANSWER` : financement confirmé et financement à obtenir.
`RATIONALE` : M03.
`DISTRACTOR_RATIONALE` : "dépenses fixes et variables" est une
distinction réelle mais non celle exigée par le critère de réussite.
`DIFFICULTY` : facile.

**Q-N1-03** (responsabilités, C4) — Face à trois pistes de financement
aux délais différents, la priorisation se fait sur :
`CORRECT_ANSWER` : le délai le plus contraint croisé avec l'écart de
financement à combler.
`RATIONALE` : M04, méthode.
`DISTRACTOR_RATIONALE` : "le montant potentiel le plus élevé seul" est
l'erreur nommée explicitement en M04.
`DIFFICULTY` : moyen.

**Q-N1-04** (limites, `ROLE_BOUNDARIES`) — Un chef de projet `KLT-02`
peut-il signer une convention institutionnelle au nom de Kiltikonet avec
la DAC ?
`CORRECT_ANSWER` : non — ce mandat relève de `KLT-03`.
`RATIONALE` : référentiel `KLT-02`, limites du rôle.
`DISTRACTOR_RATIONALE` : "oui, s'il dépose le dossier de financement"
confond dépôt de dossier (dans son mandat) et signature institutionnelle
(hors mandat).
`DIFFICULTY` : moyen.

**Q-N1-05** (limites, badge) — Le badge "Cultural Project Manager" est-il
une certification RNCP reconnue ?
`CORRECT_ANSWER` : non — badge d'accomplissement interne
(`DISPLAY_ONLY_LEGACY`).
`RATIONALE` : `CERTIFICATION_MODEL.md`.
`DISTRACTOR_RATIONALE` : "oui, s'il complète M11" ignore la distinction
`ACADEMY_CERTIFICATION`/`RNCP_OR_STATE_CERTIFICATION`.
`DIFFICULTY` : difficile.

**Q-N1-06** (publics, C2) — Une carte de parties prenantes projet
diffère d'une cartographie d'acteurs terrain (`KLT-01`) en ce qu'elle
qualifie :
`CORRECT_ANSWER` : le pouvoir de décision/financement/blocage sur le
projet lui-même.
`RATIONALE` : M02, notions essentielles.
`DISTRACTOR_RATIONALE` : "la proximité géographique" n'est pas le
critère de qualification demandé.
`DIFFICULTY` : moyen.

**Q-N1-07** (éthique, C7) — Un récit de communication projet basé sur un
résultat non encore obtenu est :
`CORRECT_ANSWER` : une erreur — les preuves de réalisation doivent être
réelles, jamais une promesse présentée comme acquise.
`RATIONALE` : M07, erreurs fréquentes.
`DISTRACTOR_RATIONALE` : "acceptable si le résultat est probable" ignore
la règle de vérifiabilité posée en M07.
`DIFFICULTY` : moyen.

**Q-N1-08** (éthique, C9) — Une évaluation d'impact qui présente une
interprétation comme un fait observé commet quelle erreur ?
`CORRECT_ANSWER` : confondre donnée observée et interprétation.
`RATIONALE` : M09, notions essentielles.
`DISTRACTOR_RATIONALE` : "sous-estimer l'impact réel" n'est pas l'erreur
nommée — le problème est la confusion de nature de la donnée, pas son
sens.
`DIFFICULTY` : difficile.

**Q-N1-09** (méthode, C5) — Un planning d'équipe mêlant salariés et
bénévoles doit prévoir en priorité :
`CORRECT_ANSWER` : un relais pour les tâches reposant sur une seule
personne à disponibilité incertaine.
`RATIONALE` : M05, méthode.
`DISTRACTOR_RATIONALE` : "un contrat pour chaque bénévole" contredit la
réalité associative décrite dans le module.
`DIFFICULTY` : moyen.

**Q-N1-10** (méthode, C8) — Un risque et un enjeu de conformité se
traitent comment ?
`CORRECT_ANSWER` : différemment — le risque s'atténue, la conformité se
respecte ou s'escalade.
`RATIONALE` : M08, notions essentielles.
`DISTRACTOR_RATIONALE` : "de la même façon, avec un registre unique" est
partiellement vrai sur le support mais faux sur le traitement, ce que la
question cible.
`DIFFICULTY` : moyen.

**Q-N1-11** (reconnaissance de situation, C6) — Un tableau de bord de
projet qui ne montre que des indicateurs verts alors qu'un financement
est en retard est :
`CORRECT_ANSWER` : un tableau de bord défaillant — il doit montrer les
écarts réels.
`RATIONALE` : M06, erreurs fréquentes.
`DISTRACTOR_RATIONALE` : "acceptable tant que le retard n'est pas
confirmé définitivement" contredit le principe de transparence du
pilotage.
`DIFFICULTY` : facile.

**Q-N1-12** (lecture de contexte, C9) — Face à une donnée Observatory
absente pour évaluer l'impact, le chef de projet doit :
`CORRECT_ANSWER` : nommer explicitement l'absence plutôt que la simuler.
`RATIONALE` : M09, `NO_FAKE_OBSERVATORY`.
`DISTRACTOR_RATIONALE` : "estimer la donnée à partir de projets
similaires" revient à fabriquer une preuve non réelle.
`DIFFICULTY` : difficile.

**Q-N1-13** (lecture de contexte, C10) — Une recommandation de
reconduction stratégique doit s'appuyer sur :
`CORRECT_ANSWER` : les faits établis dans le bilan (budget, impact,
risques survenus).
`RATIONALE` : M10, méthode.
`DISTRACTOR_RATIONALE` : "l'enthousiasme de l'équipe projet" n'est pas
une base factuelle suffisante.
`DIFFICULTY` : moyen.
