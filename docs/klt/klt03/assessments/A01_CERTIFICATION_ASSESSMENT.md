# KLT03-A01 — Assessment certificatif

```
ASSESSMENT_ID: KLT03-A01
NAMESPACE: distinct de FMS, KLT-01, KLT-02.
NIVEAU: N3, terminal (= module M12)
```

## Objectif

Prouver que le candidat peut construire et défendre une stratégie
institutionnelle réelle, dans les limites de son mandat.

## Ce que l'assessment vérifie (et ce qu'il ne vérifie pas)

Vérifie l'articulation de `C1` à `C11`. Ne vérifie pas la gestion
budgétaire opérationnelle (`KLT-02`), l'autorité de gouvernance
(`KLT-04`), ni l'opération de plateforme (`KLT-05`).

## Format du dossier professionnel attendu

| Section | Contenu attendu | Origine |
|---|---|---|
| Cartographie et stratégie | Institutions ciblées, priorisation | M01 |
| Navigation institution-spécifique | OIF/UNESCO-CARIFESTA/DAC-CTM/Europe (au moins 2) | M02-M05 |
| Convention | Term sheet préparé | M06 |
| Diplomatie | Note de posture | M07 |
| Représentation | Intervention préparée | M08 |
| Lobbying | Plan argumenté | M09 |
| Reporting | Rapport financeur sourcé | M10 |
| Portefeuille | Plan relationnel | M11 |
| Réflexif | Difficulté/refus réel rencontré et sa gestion | tous |

## Conditions d'échec explicites

- Le dossier revendique une signature ou un engagement institutionnel
  définitif non validé par le CA → non conforme.
- Une donnée Observatory est simulée en M10 → éliminatoire.
- Un fait institutionnel daté (calendrier, montant) est présenté comme
  certain sans réserve `SOURCE_STATUS` → pénalisant, éliminatoire si
  répété.
- Le dossier ne mentionne aucune difficulté réelle → pénalisant.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** ; badge `Institutional Strategist` maintenu en
`DISPLAY_ONLY_LEGACY`. Ni RNCP, ni autorisation d'opérateur — voir
`CERTIFICATION_MODEL.md`.
