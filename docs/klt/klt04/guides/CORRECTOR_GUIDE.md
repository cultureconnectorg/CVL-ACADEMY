# KLT04_CORRECTOR_GUIDE

## Rôle

Évaluer `M01`-`M13` par critère observable.

## Points de vigilance spécifiques

| Module | Vigilance particulière |
|---|---|
| M01 | Les 4 blocs statutaires sont-ils vérifiés, pas seulement listés ? |
| M02 | Le cumul de rôles identifié dans le cas est-il compensé par un garde-fou concret ? |
| M03 | Le bilan est-il cohérent avec les mouvements réels du cas ? |
| M04 | Aucun seuil fiscal n'est-il affirmé sans réserve `SOURCE_STATUS` ? |
| M05 | Le PV mentionne-t-il quorum et vote ? |
| M06 | La distinction défraiement/rémunération est-elle appliquée correctement ? |
| M07 | Les 4 notions (association/réseau/opérateur/comité) sont-elles distinguées, pas confondues ? |
| M08 | Le mandat du comité est-il écrit avant toute décision qui lui est attribuée ? |
| M09 | Chaque délégation a-t-elle une obligation de rendre compte ? |
| M10 | Le traitement du conflit d'intérêt est-il proportionné (ni ignoré, ni excessif) ? |
| M11 | Le modèle coordonne-t-il sans subordonner ? |
| M12 | Chaque obligation de conformité a-t-elle une preuve documentée ? |
| M13 | Les recommandations d'audit sont-elles actionnables, pas génériques ? |

## Ce que le correcteur ne fait pas

Ne pas évaluer une compétence hors mandat (médiation, budget projet,
représentation institutionnelle, opération de plateforme).
