# KLT05-A01 — Assessment certificatif

```
ASSESSMENT_ID: KLT05-A01
NAMESPACE: distinct de FMS, KLT-01, KLT-02, KLT-03, KLT-04.
NIVEAU: N3, terminal (= module M11)
OPERATOR_AUTHORIZATION = NOT_IMPLEMENTED / NOT_GRANTED — rappelé ici
explicitement, cette certification ne délivre aucun accès réel.
```

## Objectif

Prouver que le candidat peut opérer la présence numérique d'une action
culturelle sur une plateforme de type Kiltikonet, dans les limites de
son rôle.

## Ce que l'assessment vérifie (et ce qu'il ne vérifie pas)

Vérifie l'articulation de `C1` à `C10`. Ne vérifie pas la conduite de
médiation (`KLT-01`), la gestion budgétaire (`KLT-02`), la représentation
institutionnelle (`KLT-03`), ni la gouvernance associative (`KLT-04`).
**Ne délivre, en aucun cas, un accès administrateur réel.**

## Format du dossier professionnel attendu

| Section | Contenu attendu | Origine |
|---|---|---|
| Architecture | System map | M01 |
| Accès | Access checklist | M02 |
| Contenus | Plan de publication | M03 |
| Preuves | Runbook badge/scan (marqué simulé) | M04 |
| Communauté | Éditorial diaspora | M05 |
| Modération | Charte de modération | M06 |
| Support | Support log | M07 |
| Partenariats/événement | Ops checklist | M08 |
| Analytics | Rapport d'engagement | M09 |
| Incident | Incident report | M10 |
| Réflexif | Difficulté réelle rencontrée et sa gestion | tous |

## Conditions d'échec explicites

- Le dossier prétend, même implicitement, à un accès administrateur réel
  ou à une autorisation d'opérateur → non conforme, éliminatoire.
- Le protocole badge/scan (M04) n'est pas explicitement marqué comme
  simulé → éliminatoire.
- Une donnée Observatory est simulée en M09 → éliminatoire.
- L'incident de M10 n'est pas documenté ou est minimisé → pénalisant.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** ; badge `Kiltikonet Platform Operator` maintenu en
`DISPLAY_ONLY_LEGACY`. **Ni RNCP, ni surtout aucune autorisation
d'opérateur réelle** — voir `CERTIFICATION_MODEL.md`.
