# KLT-05 — Évaluations N2 (décision / application)

```
Situations dégradées, arbitrage requis.
```

## E-N2-01 — Éditorial diaspora traité comme un flux générique

**Situation** : le premier brouillon d'éditorial pour "Racines
d'Ailleurs" recycle telles quelles les publications destinées au public
local, sans adaptation.

**Décision attendue** : identifier que la diaspora appelle un angle
différent (récit, mémoire, lien affectif) et réviser l'éditorial en
conséquence.
**Compétences testées** : C5.
**Barème** : identification du problème (40%), révision concrète avec
angle adapté (40%), maintien d'un calendrier cohérent (20%).

## E-N2-02 — Rôle dépassé sans le savoir

**Situation** : pour résoudre rapidement un problème d'affichage, le
candidat est tenté de modifier les droits d'un autre compte plutôt que
d'escalader.

**Décision attendue** : reconnaître que cette action dépasse le rôle
"éditeur" et escalader plutôt que d'agir.
**Compétences testées** : C2, `ROLE_BOUNDARIES`.
**Barème** : reconnaissance du dépassement (50%, éliminatoire si absent),
escalade correcte (30%), absence d'action non autorisée (20%).

## E-N2-03 — Preuve simulée présentée comme réelle

**Situation** : un membre de l'équipe suggère de présenter le protocole
de scan simulé comme "une vraie preuve numérique FREK" pour rassurer les
Doyens sur la fiabilité de la démarche.

**Décision attendue** : refuser de présenter le protocole simulé comme
réel, expliquer honnêtement sa nature pédagogique.
**Compétences testées** : C4.
**Barème** : refus de la présentation trompeuse (50%, éliminatoire si
absent), explication honnête proposée (30%), maintien de la confiance
avec les Doyens (20%).

## E-N2-04 — Escalade de support ignorée

**Situation** : une question de support technique dépasse clairement les
connaissances du candidat, qui est tenté de répondre "au mieux" plutôt
que d'escalader.

**Décision attendue** : escalader plutôt que de deviner une réponse.
**Compétences testées** : C7.
**Barème** : reconnaissance de la limite de connaissance (50%,
éliminatoire si absent), escalade appropriée (30%), réponse d'attente
correcte au demandeur (20%).

## E-N2-05 — Incident minimisé

**Situation** : après correction de l'erreur d'adresse, un membre de
l'équipe propose de ne pas documenter l'incident "puisque c'est réglé".

**Décision attendue** : documenter malgré tout, pour la leçon future.
**Compétences testées** : C10.
**Barème** : refus de la minimisation (50%, éliminatoire si absent),
documentation complète produite (30%), leçon identifiée pour l'avenir
(20%).

---

**Couverture** : 5 évaluations, couvrant C2, C4, C5, C7, C10 et les
limites du rôle.
