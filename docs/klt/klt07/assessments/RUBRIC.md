# KLT07-A01 — Grille certificative (RUBRIC)

```
Même échelle 0-4 que les formations précédentes. 8 critères, scopés aux
7 compétences construites.
```

## Critères (8)

| # | Critère | Seuil minimal | Éliminatoire si 0 ? |
|---|---|---|---|
| 1 | Écosystème territorial cadré, aucun statut présumé (C1) | ≥2 | non |
| 2 | Frontière avec la gouvernance associative respectée, aucune substitution (C2) | 4 (binaire) | **oui si absent** |
| 3 | Dossier d'onboarding structuré, jamais présenté comme une licence accordée (C3) | ≥3 | **oui** |
| 4 | Fiche de couverture citant des endpoints/collections réels, RBAC territorial respecté, aucune couverture fabriquée (C4) | ≥3 | **oui si absent** |
| 5 | Relation opérateur maintenant la vigilance sur les fragilités connues (C5) | ≥2 | non |
| 6 | Évaluation de faisabilité nuancée, ancrée sur des fragilités réelles (C6) | ≥2 | non |
| 7 | Incident documenté et remonté, jamais minimisé (C7) | ≥2 | non |
| 8 | Aucune connexion Network live fabriquée à aucun moment du dossier | 4 (binaire) | **oui si absent** |

## Seuil global

Moyenne ≥ 2,5 **ET** critères éliminatoires (2, 3, 4, 8) non nuls/
conformes. Le critère 2 reste le plus spécifique à cette formation :
aucun dossier n'est certifié s'il montre une substitution à la décision
de gouvernance de l'association. Le critère 8 est spécifique à la mise
à jour 2026-09-07 : le schéma réel vérifié du Network (`C4`) peut être
cité, jamais présenté comme une connexion live qu'Academy n'a pas.
