## Situation professionnelle

Mémoire Vive exprime l'ambition de devenir "opérateur relais" du réseau
Kiltikonet pour son territoire. Avant d'évaluer quoi que ce soit, il
faut situer cette association dans l'écosystème réseau plus large —
quels autres opérateurs existent, quels territoires sont déjà couverts,
lesquels ne le sont pas.

## Objectifs d'apprentissage

- Nommer les objets structurants de l'écosystème territorial Kiltikonet
  (opérateur, territoire, licence, couverture).
- Situer un candidat opérateur dans cet écosystème plus large.
- Distinguer ce qui est réellement connu de l'écosystème de ce qui reste
  à vérifier (Network non connecté).

## Notions essentielles

Un **opérateur territorial** est une structure autorisée à représenter
Kiltikonet sur un territoire donné. Une **licence** formalise cette
autorisation. La **couverture** décrit l'ensemble des territoires
effectivement couverts par des opérateurs actifs. Ces concepts existent
en principe (nommés par le master plan) mais aucune donnée réelle
(`territories`, `operators`, `licenses`) n'existe dans Academy
aujourd'hui.

## Méthode

1. Cadrer les concepts d'opérateur, territoire, licence, couverture pour
   le cas donné.
2. Situer le candidat (ici, Mémoire Vive) dans cet écosystème, avec ce
   qui est réellement connu.
3. Nommer explicitement ce qui resterait à vérifier via un accès Network
   réel.

## Exemples

"Mémoire Vive est actuellement une association locale, pas un opérateur
territorial licencié" est un cadrage correct ; présumer un statut
d'opérateur non encore accordé serait une erreur.

## Cas

Note de cadrage écosystème pour la candidature de Mémoire Vive comme
opérateur relais.

## Erreurs fréquentes

- Traiter un candidat opérateur comme s'il était déjà licencié.
- Décrire l'état de couverture territoriale comme s'il était connu, sans
  accès Network réel.

## Activité

Cartographie guidée d'un écosystème territorial fictif (3 opérateurs, 2
territoires couverts, 1 non couvert) pour s'approprier les concepts.

## Exercice

Rédiger la note de cadrage écosystème pour Mémoire Vive.

## Livrable

Note de cadrage écosystème.

## Critères de réussite

- Les quatre concepts (opérateur, territoire, licence, couverture) sont
  correctement distingués.
- Le statut réel de Mémoire Vive (candidat, pas opérateur licencié) est
  correctement établi.

`FREK-WORK`.
