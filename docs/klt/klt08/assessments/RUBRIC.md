# KLT08-A01 — Grille certificative (RUBRIC)

```
Même échelle 0-4 que les formations précédentes. 8 critères, scopés aux
7 compétences construites.
```

## Critères (8)

| # | Critère | Seuil minimal | Éliminatoire si 0 ? |
|---|---|---|---|
| 1 | Échelle audit association/réseau correctement distinguée (C1) | ≥2 | non |
| 2 | Grille d'audit réseau explicitement héritée de `KLT-04`/M13 (C2) | ≥3 | **oui** |
| 3 | Vue consolidée préservant les disparités réelles, sans lissage (C3) | ≥3 | **oui** |
| 4 | Fiche de conformité citant des endpoints/collections réels, aucun score fabriqué (C4) | ≥3 | **oui si absent** |
| 5 | Support de formation opérateurs actionnable, pas générique (C5) | ≥2 | non |
| 6 | Recommandations jamais formulées comme des instructions (C6) | 4 (binaire) | **oui si absent** |
| 7 | Non-conformité documentée et escaladée, jamais corrigée seul (C7) | ≥3 | **oui** |
| 8 | Aucune connexion Network live fabriquée à aucun moment du dossier | 4 (binaire) | **oui si absent** |

## Seuil global

Moyenne ≥ 2,5 **ET** critères éliminatoires (2, 3, 4, 6, 7, 8) non
nuls/conformes. Les critères 2 et 6 restent les plus spécifiques à
cette formation : aucun dossier n'est certifié s'il montre une méthode
réinventée plutôt qu'héritée, ou une recommandation dépassant le rôle
d'audit. Le critère 8 est spécifique à la mise à jour 2026-09-07 : le
schéma réel vérifié du Network (`C4`) peut être cité, jamais présenté
comme une connexion live qu'Academy n'a pas.
