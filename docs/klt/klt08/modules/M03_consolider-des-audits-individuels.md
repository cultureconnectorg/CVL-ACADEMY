## Situation professionnelle

L'audit de Mémoire Vive (`KLT-04`/M13) et celui d'un autre opérateur du
réseau produisent chacun des résultats distincts. Les consolider en une
vue réseau sans que l'un n'écrase l'autre, ni que les disparités réelles
soient gommées, est l'objet de ce module.

## Objectifs d'apprentissage

- Consolider plusieurs résultats d'audit individuels en une vue réseau
  cohérente.
- Préserver les disparités réelles entre opérateurs plutôt que de les
  lisser.
- Identifier les points communs et les points spécifiques à chaque
  opérateur.

## Notions essentielles

Consolider n'est pas moyenner. Une vue réseau qui présenterait "la
gouvernance du réseau est globalement satisfaisante" en absorbant le
point encore ouvert de Mémoire Vive (cumul de rôles, `KLT-04`/M13) dans
une moyenne flatteuse serait une consolidation stérile — l'objectif est
une vue qui garde la trace de chaque disparité réelle.

## Méthode

1. Rassembler les résultats d'audit de chaque opérateur (Mémoire Vive,
   un autre opérateur du réseau).
2. Identifier les points communs (tendances réseau) et les points
   spécifiques à chaque opérateur.
3. Produire une vue consolidée qui garde la trace des disparités, sans
   les lisser.

## Exemples

"2 opérateurs sur 2 ont des points de vigilance sur la conformité
accessibilité ; Mémoire Vive a en plus un point ouvert sur le cumul de
rôles" est une consolidation fidèle ; "le réseau est globalement
conforme" sans mentionner les points spécifiques ne l'est pas.

## Cas

Vue consolidée réseau à partir de l'audit de Mémoire Vive (`KLT-04`/M13)
et d'un autre opérateur fictif du réseau.

## Erreurs fréquentes

- Lisser les disparités réelles pour produire une vue plus flatteuse.
- Consolider sans distinguer tendance réseau et point spécifique à un
  opérateur.

## Activité

Consolidation guidée de 2 audits fictifs contrastés (l'un solide, l'autre
fragile) pour s'approprier la méthode.

## Exercice

Rédiger la vue consolidée réseau pour Mémoire Vive et l'autre opérateur
de ce cas.

## Livrable

Vue consolidée réseau.

## Critères de réussite

- Les disparités réelles entre opérateurs sont préservées, pas lissées.
- Les tendances réseau et les points spécifiques sont distingués.

## Preuve

Vue consolidée réseau, conservée dans le registre de preuves — signal
`FREK-SCORE`.

## Auto-évaluation

*Ma vue consolidée garde-t-elle la trace des disparités réelles, ou
les ai-je lissées ?*
