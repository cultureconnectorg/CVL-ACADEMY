# KLT-18 — Evidence Model

```
Même discipline que les formations précédentes : READY_FOR_FREK_PROOF =
FALSE partout.
```

| Compétence | EVIDENCE_TYPE | VERIFICATION_RULE | PRIVACY_LEVEL | READY_FOR_FREK_PROOF |
|---|---|---|---|---|
| C1 | Plan de campagne | objectif mesurable et borné, distinct de l'animation quotidienne | interne | `FALSE` |
| C2 | Déclinaison multi-canal | message de fond identique d'un canal à l'autre, éditorial existant respecté | interne | `FALSE` |
| C3 | Plan de communication de crise | tension de fond non tranchée, coordination avec KLT-01/KLT-03 documentée | interne, sensible | `FALSE` |
| C4 | Rapport d'impact de campagne | données réellement disponibles uniquement, écart à l'objectif rapporté honnêtement | interne | `FALSE` |
| C5 | Revue de campagne | écart et incident inclus, recommandations distinguées d'une décision | interne, diffusable si validé | `FALSE` |

`READY_FOR_FREK_PROOF = FALSE` pour les 5 compétences construites —
même justification que les autres formations KLT (pas d'ancrage de
preuve externe réel encore établi).
