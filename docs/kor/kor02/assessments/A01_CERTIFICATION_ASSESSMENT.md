# KOR02-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR02-A01
NAMESPACE: distinct de FMS, KLT et KOR01.SKILL.xxx
NIVEAU: N3, terminal (= module M12)
```

## Objectif

Prouver que le candidat peut concevoir, vérifier, écrire et diffuser
une pièce de storytelling culturel complète, **dans les limites de son
mandat** (voir modules, sections `ROLE_BOUNDARIES`) — pas au-delà.

## Ce que l'assessment vérifie (et ce qu'il ne vérifie pas)

Vérifie l'articulation de C1 à C11 sur une production réelle (le cas
fil rouge ou une production réelle équivalente). Ne vérifie **pas** une
compétence de production audio (`KOR-01`), de production vidéo
(`KOR-03`), de programmation éditoriale multi-supports (`KOR-04`) ou de
négociation contractuelle réelle de co-production — un dossier qui
empiète sur ces domaines n'est pas mieux noté, il est hors périmètre.

## Format du dossier professionnel attendu

| Section | Contenu attendu | Origine (module) |
|---|---|---|
| Diagnostic éditorial | Paysage analysé, sujet positionné | M01 |
| Vérification | Divergence factuelle traitée, protocole | M02 |
| Angle | Angles comparés, angle défendu | M03 |
| Interview | Guide + interview de vérification | M04 |
| Écriture | Feature complète intégrant la divergence | M05 |
| Narration | Structure narrative justifiée | M06 |
| Multiformats | Déclinaisons cohérentes | M07 |
| Déontologie | Charte, consentements, conflits d'intérêt traités | M08 |
| Représentation | Arbitrage face à la pression d'exotisation | M09 |
| Diffusion | Pitch de co-production cohérent | M10 |
| Portfolio | Pièce contextualisée + bio | M11 |
| Bilan réflexif | Ce qui a fonctionné, ce qui n'a pas fonctionné, honnêtement | tous |

## Déroulé

1. **Dossier écrit** — remis avant la soutenance.
2. **Soutenance orale** — 20 minutes de présentation + questions du
   jury (voir `guides/JURY_GUIDE.md`).
3. **Délibération** — sur la base de `RUBRIC.md`, seuils observables.

## Conditions d'échec explicites (`FAILURE_MODES`)

- Le dossier revendique une action hors du mandat `KOR-02` (production
  audio/vidéo, programmation multi-supports, négociation contractuelle
  réelle) → non conforme.
- Une divergence factuelle est dissimulée ou tranchée arbitrairement
  sans justification → **éliminatoire**.
- L'angle "secret révélé" (ou équivalent exotisant) est adopté sans
  arbitrage documenté → **éliminatoire**.
- Le consentement de Man Rosa pour l'usage journalistique n'est pas
  documenté distinctement du consentement pédagogique de `KOR-01` →
  éliminatoire pour la pièce concernée, dossier renvoyé pour
  régularisation.
- Le bilan réflexif ne mentionne aucune difficulté réelle → pénalisant,
  non nécessairement éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

La réussite de `KOR02-A01` délivre une évaluation **Academy** et
maintient le badge `Cultural Broadcaster` en tant que
`DISPLAY_ONLY_LEGACY`. Elle ne délivre **ni** une certification RNCP ou
d'État, **ni** une autorisation d'opérateur KORA
(`OPERATOR_AUTHORIZATION = N/A`) — voir `CERTIFICATION_MODEL.md`.
