# KOR-03 — Modèle pédagogique de certification

Même modèle que `KOR-01`/`KOR-02` (`docs/kor/kor01/
CERTIFICATION_MODEL.md`) : `ACADEMY_CERTIFICATION` (réelle, sanctionne
`KOR03-A01`) ≠ `RNCP_OR_STATE_CERTIFICATION` (inexistante pour
`KOR-03`).

## Spécificité KOR-03

`KOR-03` n'a pas de formation legacy ni de badge existant en base — la
certification `KOR03-A01` ne remplace ni ne réactive aucun badge
préexistant (`NO_FAKE_CERTIFICATION`). Une réflexion sur un futur badge
d'accomplissement relève d'un ticket ultérieur, pas de ce chantier.

## Ce que la certification ne délivre pas

Aucune autorisation d'opérateur de plateforme KORA, aucune diffusion
réelle garantie — cohérent avec `REFERENTIAL.md` §6 (aucune
`PRODUCT_DEPENDENCY`).
