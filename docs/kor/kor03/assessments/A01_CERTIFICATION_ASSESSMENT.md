# KOR03-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR03-A01
NIVEAU: N3, terminal (= M11)
```

## Objectif

Prouver que le candidat peut concevoir, tourner, monter et livrer une
production vidéo courte complète, dans les limites de son mandat.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C10. Ne vérifie pas une compétence de programmation
éditoriale (`KOR-04`), d'exploitation de plateforme (`KOR-06`), ni de
production audio autonome (`KOR-01`).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic | M01 |
| Préproduction | M02 |
| Captation (lumière/son, single-cam, multicam, régie) | M03-M06 |
| Montage et postproduction | M07-M08 |
| Livraison (encodage, publication, QC) | M09-M10 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier revendique une action hors mandat `KOR-03`.
- L'arbitrage de représentation de `KOR-02`/M09 est contredit ou rouvert
  sans justification → éliminatoire.
- Un défaut connu est publié sciemment (M10) → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement. Aucune certification RNCP/État,
aucune autorisation d'opérateur de plateforme KORA.
