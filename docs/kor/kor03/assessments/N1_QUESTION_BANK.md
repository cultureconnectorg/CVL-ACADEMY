# KOR-03 — Banque N1

**Q-N1-01** (C1) — Un teaser qui répète le récit déjà raconté en audio/
texte apporte-t-il une valeur ajoutée ?
`CORRECT_ANSWER` : non — l'image doit montrer, pas répéter.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C2) — Un script visuel décrit-il des répliques ?
`CORRECT_ANSWER` : non — il décrit des plans (cadrage, mouvement,
durée), les répliques relèvent du script audio (`KOR-01`).
`RATIONALE` : M02. `DIFFICULTY` : facile.

**Q-N1-03** (C6) — La régie doit-elle attendre le montage pour évaluer
la qualité d'une prise ?
`CORRECT_ANSWER` : non — l'évaluation se fait en direct, surtout
quand une seule journée de tournage est possible.
`RATIONALE` : M06. `DIFFICULTY` : moyen.

**Q-N1-04** (C9) — Les formats vertical et horizontal sont-ils
interchangeables par simple redimensionnement ?
`CORRECT_ANSWER` : non — un recadrage réfléchi est nécessaire pour
garder le sujet centré.
`RATIONALE` : M09. `DIFFICULTY` : moyen.
