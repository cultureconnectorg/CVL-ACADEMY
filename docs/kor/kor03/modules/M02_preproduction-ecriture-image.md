## Situation professionnelle

Une seule journée de tournage est possible chez Man Rosa. Sans plan
précis (script visuel, repérage), le temps sera perdu à improviser sur
place — inacceptable avec une source qui se fatigue vite.

## Objectifs d'apprentissage

- Écrire un script visuel (plans, non dialogues) distinct d'un script
  audio.
- Repérer un lieu non professionnel (le salon de Man Rosa) pour en
  anticiper les contraintes.
- Prévoir un plan lumière/son avant le jour du tournage.

## Notions essentielles

Un **script visuel** décrit des plans (cadrage, mouvement, durée
estimée), pas des répliques — à la différence du script audio de
`KOR-01`. Le **repérage** anticipe les contraintes réelles du lieu
(fenêtres, bruit, espace) avant le jour J, pas pendant.

## Méthode

1. Lister les plans nécessaires pour le teaser (portrait de Man Rosa,
   plan sur la valise, plans de coupe du collectif).
2. Repérer le salon de Man Rosa (lumière naturelle disponible, bruit,
   espace pour deux caméras).
3. Rédiger un plan lumière/son prévisionnel à partir de ce repérage.

## Exemple

Le repérage révèle qu'une fenêtre côté ouest donnera une lumière trop
dure en après-midi — le tournage est planifié le matin en conséquence.

## Cas

Le script visuel et le repérage portent sur le salon réel de Man Rosa
(`case/CASE.md`), pas un plateau hypothétique.

## Erreurs fréquentes

- Confondre script visuel et script audio (dialogues au lieu de plans).
- Ne pas anticiper la lumière/le bruit réels du lieu avant le jour J.

## Activité

Repérage documenté du lieu de tournage (lumière, bruit, espace).

## Exercice

Rédiger le script visuel des plans nécessaires + le plan lumière/son
prévisionnel.

## Livrable

Script visuel + repérage documenté.

## Critères de réussite

- Le script visuel décrit des plans, pas des dialogues.
- Le repérage identifie au moins une contrainte réelle du lieu.
- Le plan lumière/son est cohérent avec le repérage.

## Preuve

Script visuel + repérage, signal `FREK-WORK`.
