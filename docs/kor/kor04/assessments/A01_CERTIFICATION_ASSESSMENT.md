# KOR04-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR04-A01
NIVEAU: N3, terminal (= M09)
```

## Objectif

Prouver que le candidat peut programmer et curer un catalogue de
contenus existants selon une ligne éditoriale assumée, dans les
limites de son mandat.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C8. Ne vérifie pas une compétence de création de contenu
(`KOR-01`/`02`/`03`), de recommandation algorithmique réelle (`KOR-12`,
non construit), ni de stratégie d'acquisition d'audience (`KOR-09`, non
construit).

## Format du dossier

| Section | Origine |
|---|---|
| Ligne éditoriale | M01 |
| Publics | M02 |
| Calendrier | M03 |
| Playlists | M04 |
| Arbitrage de diversité | M05 |
| Contextualisation | M06 |
| Recommandations | M07 |
| Événement et mesure | M08 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier revendique une action hors mandat (création de contenu,
  recommandation algorithmique réelle).
- Une recommandation humaine est présentée comme data-driven sans
  preuve → éliminatoire.
- Un chiffre d'audience non mesurable est présenté comme réel →
  éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement, aucune certification RNCP/État.
