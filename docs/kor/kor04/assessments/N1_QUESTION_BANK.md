# KOR-04 — Banque N1

**Q-N1-01** (C1) — Une programmation par disponibilité seule
équivaut-elle à une ligne éditoriale ?
`CORRECT_ANSWER` : non — la ligne éditoriale répond à pourquoi/pour qui,
pas seulement à quoi.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C2) — Un public acquis et un public potentiel sont-ils la
même chose ?
`CORRECT_ANSWER` : non — l'un est déjà engagé, l'autre est à atteindre.
`RATIONALE` : M02. `DIFFICULTY` : facile.

**Q-N1-03** (C6) — Contextualiser un contenu implique-t-il de le
modifier ?
`CORRECT_ANSWER` : non — seul un texte de présentation est ajouté
autour, le contenu reste inchangé.
`RATIONALE` : M06. `DIFFICULTY` : moyen.
