# KOR04_CORRECTOR_GUIDE

## Rôle du correcteur

Évaluer M01-M08 selon les critères de chaque module. Ne délibère pas
sur `KOR04-A01`.

## Points de vigilance par module

| Module | Vigilance |
|---|---|
| M01 | La ligne éditoriale répond-elle vraiment à pourquoi/pour qui ? |
| M02 | Public acquis et potentiel sont-ils distingués pour chaque contenu ? |
| M03 | Le calendrier sert-il la ligne éditoriale, ou est-il arbitraire ? |
| M04 | Un contenu a-t-il été modifié en le curant (hors mandat) ? |
| M05 | Le compromis de diversité sert-il les deux objectifs, pas un seul ? |
| M06 | Le contenu original a-t-il été modifié en le contextualisant ? |
| M07 | Une recommandation prétend-elle à une donnée réelle inexistante ? |
| M08 | Un chiffre non mesurable est-il présenté comme réel ? |

## Ce que le correcteur ne fait jamais

Ne certifie pas `KOR04-A01`, ne valide pas une compétence sans
livrable réel.
