# KOR05-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR05-A01
NIVEAU: N3, terminal (= M10)
```

## Objectif

Prouver que le candidat peut opérer le flux de production d'un ou
plusieurs créateurs, dans les limites de son mandat.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C9. Ne vérifie pas une compétence de création (`KOR-01`/
`02`/`03`), de programmation éditoriale (`KOR-04`), ni de sourcing/
acquisition de créateurs (`KOR-13`, non construit).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic | M01 |
| Onboarding | M02 |
| Ingestion et convention | M03 |
| Contrôle qualité | M04 |
| Calendrier de releases | M05 |
| Corrections | M06 |
| Support | M07 |
| Suivi catalogue | M08 |
| Incident et reporting | M09 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier revendique une action hors mandat (création, sourcing).
- Un incident est dissimulé au créateur affecté → éliminatoire.
- Une limite de méthode (échelle) est cachée plutôt que reconnue →
  éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement.
