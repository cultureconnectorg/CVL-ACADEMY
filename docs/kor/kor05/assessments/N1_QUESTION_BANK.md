# KOR-05 — Banque N1

**Q-N1-01** (C1) — Un flux opérationnel chaotique est-il un jugement
sur la qualité créative d'un créateur ?
`CORRECT_ANSWER` : non — les deux problèmes sont distincts.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C3) — Une convention de nommage doit-elle être complexe
pour être efficace ?
`CORRECT_ANSWER` : non — simple et systématiquement appliquée suffit.
`RATIONALE` : M03. `DIFFICULTY` : facile.

**Q-N1-03** (C6) — Une demande de "refaire le montage" relève-t-elle du
mandat opérations créateur ?
`CORRECT_ANSWER` : non — c'est une refonte créative, à rediriger vers
le créateur.
`RATIONALE` : M06. `DIFFICULTY` : moyen.

**Q-N1-04** (C8) — Un registre manuel (tableur) tiendrait-il à
n'importe quelle échelle ?
`CORRECT_ANSWER` : non — sa limite d'échelle doit être reconnue
explicitement, pas comblée par une fausse capacité produit.
`RATIONALE` : M08. `DIFFICULTY` : moyen.
