# KOR-06 — Modèle pédagogique de certification

Même modèle que `KOR-01`→`05`. `ACADEMY_CERTIFICATION` (réelle,
`KOR06-A01`) ≠ `RNCP_OR_STATE_CERTIFICATION` (inexistante). Aucun badge
legacy. **Précision spécifique** : cette certification atteste une
compétence de marché (exploitation de plateforme streaming/podcast
réelle), jamais une autorisation d'opérer une plateforme KORA — KORA
n'a aujourd'hui aucune plateforme réelle à opérer (`REFERENTIAL.md`
§6).
