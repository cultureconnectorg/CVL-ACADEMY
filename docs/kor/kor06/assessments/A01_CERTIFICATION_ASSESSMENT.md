# KOR06-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR06-A01
NIVEAU: N3, terminal (= M09)
```

## Objectif

Prouver que le candidat peut exploiter une plateforme de streaming/
podcast (chez un hébergeur du marché réel), dans les limites de son
mandat.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C8. Ne vérifie **jamais** une capacité KORA réelle (aucune
n'existe, `REFERENTIAL.md` §6) — le dossier porte sur Anba Tonèl Host,
véhicule générique. Ne vérifie pas une compétence de parcours
utilisateur (`KOR-14`, non construit) ni de droits (`KOR-07`, non
construit).

## Format du dossier

| Section | Origine |
|---|---|
| Fonctionnement DSP | M01 |
| Chaîne ingestion→delivery | M02 |
| Exploitation quotidienne | M03 |
| Player/CDN | M04 |
| SLA/SLO | M05 |
| Incident et escalade | M06 |
| Monitoring | M07 |
| Multi-territoires | M08 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier présente une capacité KORA réelle comme existante →
  éliminatoire (`NO_FAKE_KORA_CAPABILITY`).
- Un SLA intenable est validé sans réserve → éliminatoire.
- L'incident n'est pas communiqué honnêtement au créateur affecté →
  éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement, applicable au marché réel de
l'hébergement podcast/streaming — pas une autorisation d'opérer une
plateforme KORA (qui n'existe pas).
