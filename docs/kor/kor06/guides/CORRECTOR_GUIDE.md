# KOR06_CORRECTOR_GUIDE

## Rôle du correcteur

Évaluer M01-M08 selon les critères de chaque module. Ne délibère pas
sur `KOR06-A01`.

## Points de vigilance par module

| Module | Vigilance |
|---|---|
| M01 | Les composants du DSP sont-ils vraiment distincts, pas traités en boîte noire ? |
| M02 | Le schéma couvre-t-il toutes les étapes, y compris les moins visibles ? |
| M03 | La routine de vérification est-elle tenable dans la durée ? |
| M04 | La distinction CDN/player est-elle appliquée à un cas réel, pas seulement théorique ? |
| M05 | Le SLA/SLO est-il cohérent avec les moyens réels d'Anba Tonèl Host ? |
| M06 | Le créateur affecté est-il informé honnêtement pendant l'incident ? |
| M07 | Le plan de monitoring aurait-il vraiment détecté l'incident de M06 ? |
| M08 | Les fuseaux horaires sont-ils vraiment pris en compte ? |

## Ce que le correcteur ne fait jamais

Ne certifie pas `KOR06-A01`, ne valide jamais une affirmation qui
présenterait une capacité KORA réelle comme existante.
