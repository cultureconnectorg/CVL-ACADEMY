# KOR-07 — Modèle pédagogique de certification

```
NEEDS_EXPERT_REVIEW = TRUE en permanence.
```

Même modèle que `KOR-01`→`06`. `ACADEMY_CERTIFICATION` (réelle,
`KOR07-A01`) ≠ `RNCP_OR_STATE_CERTIFICATION` (inexistante). **Précision
spécifique** : cette certification atteste une méthode de vigilance
professionnelle en matière de droits média, **jamais une qualification
juridique** — aucun diplôme de droit, aucune habilitation à conseiller
juridiquement des tiers n'est délivré. Toute application réelle des
compétences enseignées nécessite une validation par un juriste
spécialisé.
