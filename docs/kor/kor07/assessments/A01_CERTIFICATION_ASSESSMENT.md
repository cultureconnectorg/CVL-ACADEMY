# KOR07-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR07-A01
NIVEAU: N3, terminal (= M09)
NEEDS_EXPERT_REVIEW = TRUE en permanence.
```

## Objectif

Prouver que le candidat peut analyser une situation de droits média
avec la vigilance appropriée, dans les limites de son mandat — jamais
un avis juridique qualifié.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C8 comme méthode de vigilance et d'analyse. Ne vérifie
**jamais** une compétence de rédaction contractuelle opposable, de
conseil juridique définitif, ni de stratégie de déploiement
international (`KOR-15`, non construit).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic de droits | M01 |
| Licences/masters/publishing | M02 |
| Territoires/fenêtres | M03 |
| Exclusivité/clearance | M04 |
| Lecture contractuelle | M05 |
| Takedown | M06 |
| Royalties | M07 |
| Cadre international | M08 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Une incertitude de droits est tranchée par supposition → **éliminatoire**.
- Le dossier prétend à un avis juridique définitif sans réserve
  `NEEDS_EXPERT_REVIEW` → éliminatoire.
- Un contrat est présenté comme signable sans relecture professionnelle
  → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement — jamais une qualification juridique
professionnelle, jamais un conseil opposable.
