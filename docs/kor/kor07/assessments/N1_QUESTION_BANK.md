# KOR-07 — Banque N1

```
NEEDS_EXPERT_REVIEW = TRUE — cette banque teste une méthode de
vigilance, jamais une réponse juridique définitive.
```

**Q-N1-01** (C1) — Face à une incertitude de droits, la bonne pratique
est-elle de supposer un statut favorable ?
`CORRECT_ANSWER` : non — marquer l'incertitude (`NEEDS_EXPERT_REVIEW`),
jamais la combler par supposition.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C2) — Master et publishing désignent-ils la même chose ?
`CORRECT_ANSWER` : non — le master est l'enregistrement, le publishing
la composition sous-jacente.
`RATIONALE` : M02. `DIFFICULTY` : facile.

**Q-N1-03** (C4) — Une exclusivité a-t-elle un coût uniquement pour le
bénéficiaire de l'exclusivité ?
`CORRECT_ANSWER` : non — elle a un coût réel pour celui qui l'accorde
(renonciation à d'autres opportunités).
`RATIONALE` : M04. `DIFFICULTY` : moyen.

**Q-N1-04** (C7) — Un terme non documenté dans ce repo (comme "CVE")
doit-il être deviné pour compléter un calcul de royalties ?
`CORRECT_ANSWER` : non — signaler l'absence de clarification
(`EXTERNAL_PRODUCT_EVIDENCE_NOT_AUDITED`), jamais deviner.
`RATIONALE` : M07. `DIFFICULTY` : moyen.
