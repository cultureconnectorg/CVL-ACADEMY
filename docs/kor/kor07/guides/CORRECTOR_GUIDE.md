# KOR07_CORRECTOR_GUIDE

```
NEEDS_EXPERT_REVIEW = TRUE.
```

## Rôle du correcteur

Évaluer M01-M08 selon les critères de chaque module. Ne délibère pas
sur `KOR07-A01`.

## Points de vigilance par module

| Module | Vigilance |
|---|---|
| M01 | Le diagnostic distingue-t-il vraiment certain/incertain, sans combler par supposition ? |
| M02 | Master et publishing sont-ils correctement distingués ? |
| M03 | L'absence de fenêtre est-elle relevée, pas supposée ? |
| M04 | Le coût de l'exclusivité est-il vraiment évalué ? |
| M05 | La grille de lecture rappelle-t-elle `NEEDS_EXPERT_REVIEW` ? |
| M06 | Le takedown est-il traité proportionnellement, sans décision définitive sur preuve partielle ? |
| M07 | Le calcul de royalties est-il vérifié, pas accepté tel quel ? |
| M08 | Chaque juridiction est-elle traitée individuellement ? |

## Ce que le correcteur ne fait jamais

Ne certifie pas `KOR07-A01`, ne valide jamais une réponse qui tranche
une incertitude juridique par supposition.
