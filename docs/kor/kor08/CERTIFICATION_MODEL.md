# KOR-08 — Modèle pédagogique de certification

Même modèle que `KOR-01`→`07`. `ACADEMY_CERTIFICATION` (réelle,
`KOR08-A01`) ≠ `RNCP_OR_STATE_CERTIFICATION` (inexistante). **Précision
spécifique** : cette certification atteste une compétence
d'exploitation streaming des métadonnées, jamais une compétence de
gestion de droits/catalogue label — celle-ci relève de LabelOS,
non délivrée ici.
