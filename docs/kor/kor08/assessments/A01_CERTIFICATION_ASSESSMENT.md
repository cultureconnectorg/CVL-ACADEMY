# KOR08-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR08-A01
NIVEAU: N3, terminal (= M09)
```

## Objectif

Prouver que le candidat peut structurer les métadonnées d'un contenu
pour l'exploitation streaming, sans jamais dupliquer les standards
détenus par LabelOS.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C8. Ne vérifie **jamais** une compétence de gestion de
droits/royalties label (relève de LabelOS, `LOS-02`), ni de mesure
d'usage de données (`KOR-12`, non construit).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic de périmètre | M01 |
| Pont vers LabelOS | M02 |
| Crédits | M03 |
| Normalisation | M04 |
| Modèle d'entrée catalogue | M05 |
| Enrichissement culturel | M06 |
| Contrôle qualité | M07 |
| Découvrabilité | M08 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier réinvente un standard détenu par LabelOS (ISRC/ISWC/DDEX)
  → éliminatoire (`NO_DUPLICATE_CURRICULUM`).
- Un contributeur est crédité de façon minimisante sans justification →
  éliminatoire.
- Un mot-clé sans rapport réel est utilisé pour maximiser la
  visibilité → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement.
