# KOR-08 — Banque N1

**Q-N1-01** (C1) — Faut-il inventer un identifiant propre si un
standard existant (LabelOS) couvre déjà le besoin ?
`CORRECT_ANSWER` : non — utiliser/orienter vers le standard existant.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C2) — Ce module délivre-t-il lui-même un ISRC réel ?
`CORRECT_ANSWER` : non — il oriente vers LabelOS, qui détient cette
compétence.
`RATIONALE` : M02. `DIFFICULTY` : facile.

**Q-N1-03** (C4) — Un contenu multilingue doit-il être réduit à sa
langue dominante dans les métadonnées ?
`CORRECT_ANSWER` : non — toutes les langues réellement présentes
doivent être documentées.
`RATIONALE` : M04. `DIFFICULTY` : moyen.

**Q-N1-04** (C7) — Le contrôle qualité de métadonnées se limite-t-il à
vérifier la présence de chaque champ ?
`CORRECT_ANSWER` : non — il vérifie aussi la cohérence entre les
champs.
`RATIONALE` : M07. `DIFFICULTY` : moyen.
