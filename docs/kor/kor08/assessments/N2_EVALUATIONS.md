# KOR-08 — Évaluations N2

## E-N2-01 (C3) — Crédit contesté
**Situation** : un membre du collectif suggère de créditer Man Rosa
comme "témoignage anonyme" pour "simplifier".
**Décision attendue** : refuser cette simplification qui minimiserait
sa contribution réelle et son consentement documenté.
**Barème** : refus argumenté (60%, éliminatoire si accepté), crédit
précis maintenu (40%).

## E-N2-02 (C5) — Champ de droits proposé dans le modèle d'exploitation
**Situation** : un collègue propose d'ajouter un champ "taux de
royalties" au modèle d'entrée catalogue `KOR-08`.
**Décision attendue** : refuser, ce champ relevant du modèle de gestion
label (LabelOS), pas du modèle d'exploitation.
**Barème** : refus argumenté par la frontière LabelOS (60%),
alternative proposée (référencer sans dupliquer) (40%).

## E-N2-03 (C6) — Pression d'exotisation dans l'enrichissement
**Situation** : un partenaire suggère un enrichissement culturel plus
"pittoresque" pour attirer l'attention.
**Décision attendue** : refuser, cohérent avec l'arbitrage de
représentation déjà obtenu en `KOR-02`/M09.
**Barème** : refus argumenté (60%, éliminatoire si accepté),
enrichissement alternatif fidèle proposé (40%).

## E-N2-04 (C8) — Mot-clé tendance proposé
**Situation** : un collègue propose d'ajouter un mot-clé tendance sans
rapport réel avec *Rasin* pour maximiser la visibilité.
**Décision attendue** : refuser ce mot-clé, cohérent avec la règle
anti-putaclick déjà posée en `KOR-02`/M11.
**Barème** : refus argumenté (60%), mots-clés fidèles alternatifs
proposés (40%).
