# KOR-08 — Cas : L'Antenne Lanbi — métadonnées de "Rasin"

```
CASE_STATUS = PEDAGOGICAL_SIMULATION
```

## Continuité

*Rasin* (épisode 0, `KOR-01`/`02`/`03`) doit être structuré en
métadonnées exploitables pour la découvrabilité et l'affichage des
crédits — au-delà du simple flux RSS déjà configuré (`KOR-01`/M10).

## Acteurs

| Acteur | Nature |
|---|---|
| Lanbi Collective | détenteur du contenu |
| LabelOS (référence, non simulé ici) | détient les standards ISRC/ISWC/DDEX réels — non réinventé dans ce cas |
| Man Rosa | contributrice/témoin à créditer correctement |

## Tension centrale

Le Lanbi Collective, faute de connaître LabelOS, envisage d'inventer
son propre système d'identifiants pour *Rasin* — un doublon inutile et
risqué (incompatibilité future). Le candidat doit orienter vers les
standards existants plutôt que d'en fabriquer de nouveaux.

## Contraintes réelles

Le Lanbi Collective n'a pas de budget pour un enregistrement ISRC
formel (payant selon les circuits) ; Man Rosa doit être créditée avec
exactitude (nom, rôle : témoin/interprète, pas "artiste invitée"
générique) ; le chant traditionnel (incertitude de droits, `KOR-07`)
complique aussi le crédit de contributeur.

## Action à concevoir

Diagnostiquer le périmètre réel de métadonnées nécessaire (sans
réinventer LabelOS), créditer correctement les contributeurs, normaliser
genre/langue/territoire, enrichir culturellement l'entrée catalogue, en
contrôler la qualité, et optimiser la découvrabilité — dans les limites
budgétaires réelles du collectif.

## Limites explicites

Le cas ne demande jamais de définir un ISRC/ISWC/DDEX depuis zéro (relève
de LabelOS), de trancher l'incertitude de droits du chant (`KOR-07`), ni
de construire un moteur de recherche réel (`KOR-08` optimise pour la
découvrabilité conceptuellement, ne construit aucun code).
