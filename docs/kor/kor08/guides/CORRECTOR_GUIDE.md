# KOR08_CORRECTOR_GUIDE

## Rôle du correcteur

Évaluer M01-M08 selon les critères de chaque module. Ne délibère pas
sur `KOR08-A01`.

## Points de vigilance par module

| Module | Vigilance |
|---|---|
| M01 | Le périmètre est-il clairement délimité par rapport à LabelOS ? |
| M02 | Le candidat prétend-il délivrer une expertise LabelOS lui-même ? |
| M03 | Les crédits sont-ils précis, pas génériques ? |
| M04 | Le multilinguisme réel est-il reflété ? |
| M05 | Un champ de gestion de droits a-t-il été dupliqué dans le modèle d'exploitation ? |
| M06 | L'enrichissement culturel exotise-t-il, contredisant `KOR-02`/M09 ? |
| M07 | La cohérence inter-champs est-elle vérifiée, pas seulement la présence ? |
| M08 | Un mot-clé sans rapport réel a-t-il été utilisé ? |

## Ce que le correcteur ne fait jamais

Ne certifie pas `KOR08-A01`, ne valide jamais un doublon de standard
LabelOS.
