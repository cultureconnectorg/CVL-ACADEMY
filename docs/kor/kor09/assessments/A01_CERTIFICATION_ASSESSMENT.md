# KOR09-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR09-A01
NIVEAU: N3, terminal (= M11)
```

## Objectif

Prouver que le candidat peut développer une audience diaspora dispersée
avec des moyens limités, en équilibrant acquisition et rétention.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C10. Ne vérifie pas une compétence de parcours produit
in-app (`KOR-14`, non construit) ni de programmation éditoriale
(`KOR-04`).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic d'audience | M01 |
| Personas | M02 |
| Funnel d'acquisition | M03 |
| Activation | M04 |
| Communauté | M05 |
| CRM | M06 |
| Rétention/churn | M07 |
| Campagne/ambassadeurs | M08 |
| Diaspora | M09 |
| Mesure | M10 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Le dossier ignore la rétention au profit de la seule acquisition →
  éliminatoire.
- Un résultat de mesure décevant ou ambigu est présenté comme un
  succès → éliminatoire.
- Le dossier prétend à un CRM/A-B testing réel à grande échelle sans
  reconnaître la limite de méthode → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement.
