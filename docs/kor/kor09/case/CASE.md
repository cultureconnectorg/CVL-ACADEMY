# KOR-09 — Cas : L'Antenne Lanbi — faire grandir l'audience de "Rasin"

```
CASE_STATUS = PEDAGOGICAL_SIMULATION
```

## Continuité

Après la publication (`KOR-01`) et le premier plan d'audience simple
(`KOR-01`/M12), le Lanbi Collective veut structurer une vraie démarche
de développement d'audience. Marc-Andy, déjà community manager
bénévole, est rejoint par le candidat comme consultant croissance.

## Acteurs

| Acteur | Nature |
|---|---|
| Marc-Andy | community manager bénévole, déjà en poste |
| Auditeurs diaspora dispersés (Caraïbe, Amérique du Nord, Europe) | public cible |
| *Dyaspora FM* | partenaire de diffusion déjà engagé (`KOR-02`) |

## Tension centrale

Marc-Andy veut concentrer tous les efforts sur l'acquisition de
nouveaux auditeurs ; le candidat doit lui montrer que sans rétention,
l'acquisition seule ne suffit pas (un public qui écoute un épisode et
ne revient jamais ne fait pas grandir *Rasin* durablement).

## Contraintes réelles

Budget nul (pas de publicité payante) ; équipe réduite (Marc-Andy
seul, quelques heures par semaine) ; audience dispersée sur plusieurs
fuseaux horaires et réseaux sociaux différents selon les territoires.

## Action à concevoir

Diagnostiquer le paysage d'audience, segmenter les publics réels,
construire un funnel d'acquisition réaliste, activer les nouveaux
auditeurs, animer une communauté, structurer un CRM simple,
travailler la rétention, mener une campagne avec ambassadeurs,
adresser les spécificités diaspora, et expérimenter/mesurer sans
outils sophistiqués.

## Limites explicites

Le cas ne demande jamais de construire un vrai CRM technique
(`KORA_PRODUCT_GAP`, `REFERENTIAL.md` §6), de programmer le contenu
lui-même (`KOR-04`), ni de construire un parcours produit in-app
(`KOR-14`, non construit).
