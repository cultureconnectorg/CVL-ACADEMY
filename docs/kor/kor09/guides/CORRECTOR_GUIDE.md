# KOR09_CORRECTOR_GUIDE

## Rôle du correcteur

Évaluer M01-M10 selon les critères de chaque module. Ne délibère pas
sur `KOR09-A01`.

## Points de vigilance par module

| Module | Vigilance |
|---|---|
| M01 | Le diagnostic s'appuie-t-il sur des données réelles ? |
| M02 | Les personas sont-ils basés sur des données observées ? |
| M03 | Le funnel suppose-t-il un budget inexistant ? |
| M04 | L'activation est-elle distincte de la simple découverte ? |
| M05 | Le rythme d'animation est-il soutenable pour une personne seule ? |
| M06 | La limite d'échelle du CRM est-elle reconnue ? |
| M07 | L'argumentaire de rétention est-il basé sur des données réelles ? |
| M08 | Les ambassadeurs sont-ils choisis sur engagement réel ? |
| M09 | Les spécificités diaspora sont-elles vraiment adressées ? |
| M10 | Un résultat décevant est-il rapporté honnêtement ? |

## Ce que le correcteur ne fait jamais

Ne certifie pas `KOR09-A01`, ne valide jamais un résultat enjolivé.
