## Situation professionnelle

Sans outil d'expérimentation sophistiqué, Marc-Andy doit néanmoins
savoir si ses actions (campagne, animation) fonctionnent réellement,
pas seulement le supposer.

## Objectifs d'apprentissage

- Concevoir une expérimentation simple sans outils sophistiqués
  (A/B manuel, mesure avant/après).
- Mesurer honnêtement, y compris quand le résultat est décevant.

## Notions essentielles

Une **expérimentation simple** peut comparer deux approches
successivement (avant/après) plutôt que simultanément (A/B testing
réel, qui nécessiterait un outil non disponible) — moins rigoureux
mais honnête sur cette limite. La mesure doit être rapportée
fidèlement, y compris un résultat négatif ou nul.

## Méthode

1. Concevoir une expérimentation simple (avant/après) sur une action
   du plan (ex. nouveau rythme de publication).
2. Mesurer avec les moyens disponibles (CRM de M06).
3. Rapporter le résultat honnêtement, y compris s'il est décevant.

## Exemple

Comparer le taux d'activation avant/après un changement de rythme de
publication — si le résultat est neutre ou négatif, le rapporter
tel quel plutôt que de l'enjoliver.

## Cas

L'expérimentation porte sur une action réelle du cas (`case/CASE.md`).

## Erreurs fréquentes

- Prétendre à un A/B testing rigoureux sans outil pour le mener
  réellement.
- Enjoliver un résultat décevant dans le rapport.

## Activité

Conception de l'expérimentation avant/après.

## Exercice

Mesurer et rapporter le résultat honnêtement.

## Livrable

Protocole de mesure + résultat rapporté.

## Critères de réussite

- La méthode (avant/après, pas A/B réel) est honnêtement qualifiée.
- Le résultat est rapporté fidèlement, même s'il est décevant.

## Preuve

Protocole + résultat, signal `FREK-SCORE`.
