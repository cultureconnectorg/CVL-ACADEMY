# KOR10-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR10-A01
NIVEAU: N3, terminal (= M10)
```

## Objectif

Prouver que le candidat peut concevoir un modèle économique de
streaming chiffré et réaliste, en s'appuyant sur les mécanismes réels
disponibles (Wallet/JCC) et en traitant les incertitudes (CVE, droits)
avec la vigilance appropriée.

## Ce qu'il vérifie / ne vérifie pas

Vérifie C1-C9. Ne vérifie pas une compétence de négociation
contractuelle réelle (`KOR-07`), ni de construction technique de
Wallet (hors mandat pédagogique).

## Format du dossier

| Section | Origine |
|---|---|
| Diagnostic économique | M01 |
| Modèle free/premium/abonnement | M02 |
| Publicité/sponsoring | M03 |
| ARPU/LTV | M04 |
| Partage de valeur | M05 |
| Royalties | M06 |
| Pricing/coûts | M07 |
| Wallet/JCC | M08 |
| Clarification CVE | M09 |
| Bilan réflexif | tous |

## Conditions d'échec explicites

- Un chiffre est présenté sans hypothèses explicites → éliminatoire si
  systématique.
- Une contribution non technique (Man Rosa) est exclue du partage sans
  justification → éliminatoire.
- CVE est défini par invention → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas

Évaluation **Academy** uniquement.
