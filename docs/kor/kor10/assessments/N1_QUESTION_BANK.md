# KOR-10 — Banque N1

**Q-N1-01** (C1) — Un diagnostic économique doit-il partir d'un modèle
idéal théorique ?
`CORRECT_ANSWER` : non — il doit partir des données réelles
d'audience et de moyens.
`RATIONALE` : M01. `DIFFICULTY` : facile.

**Q-N1-02** (C2) — Le freemium est-il adapté à n'importe quelle taille
d'audience ?
`CORRECT_ANSWER` : non — il nécessite un seuil d'audience minimal
réaliste.
`RATIONALE` : M02. `DIFFICULTY` : facile.

**Q-N1-03** (C6) — Ce module doit-il refaire l'analyse juridique de
KOR-07 ?

`RATIONALE` : M06. `DIFFICULTY` : moyen.

cas ?

repo.
`RATIONALE` : M08. `DIFFICULTY` : moyen.
