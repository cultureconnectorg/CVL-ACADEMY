## Situation professionnelle

Le Lanbi Collective hésite entre plusieurs modèles économiques sans
les avoir clairement comparés — un diagnostic structuré est
nécessaire avant toute décision.

## Objectifs d'apprentissage

- Identifier les options économiques réalistes pour *Rasin*.
- Poser un diagnostic basé sur l'audience réelle (issue de `KOR-09`),
  pas une ambition abstraite.

## Notions essentielles

Un **diagnostic économique** part de la réalité (audience actuelle,
moyens du collectif) pour identifier les options réalistes, pas d'un
modèle économique idéal théorique. Les données d'audience de `KOR-09`
sont la base de tout calcul ultérieur.

## Méthode

1. Recenser les données d'audience réelles disponibles.
2. Identifier les options économiques réalistes compte tenu de cette
   audience.
3. Formuler le diagnostic sans encore trancher entre options.

## Exemple

Avec quelques centaines d'auditeurs réguliers, un modèle d'abonnement
payant seul serait probablement irréaliste — le diagnostic doit le
signaler, pas l'ignorer par optimisme.

## Cas

Le diagnostic porte sur *Rasin* réellement (`case/CASE.md`).

## Erreurs fréquentes

- Diagnostiquer sans s'appuyer sur les données réelles d'audience.
- Trancher prématurément entre options avant le diagnostic complet.

## Activité

Recensement des données d'audience disponibles.

## Exercice

Rédiger le diagnostic des options réalistes.

## Livrable

Diagnostic économique.

## Critères de réussite

- Le diagnostic s'appuie sur les données réelles d'audience.
- Aucune option n'est écartée ou retenue prématurément.

## Preuve

Diagnostic, signal `FREK-WORK`.
