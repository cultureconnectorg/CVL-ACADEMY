## Situation professionnelle

Si le chant traditionnel (incertitude de droits, `KOR-07`) génère des
royalties, le modèle économique doit intégrer cette possibilité sans
refaire l'analyse juridique déjà menée.

## Objectifs d'apprentissage

- Comprendre les modèles de calcul de royalties courants (au prorata
  d'écoute, forfaitaire).
- Intégrer l'incertitude de droits déjà identifiée en `KOR-07` dans le
  modèle économique, sans la retrancher.

## Notions essentielles

Un modèle de royalties **au prorata d'écoute** verse proportionnellement
à l'usage réel ; un modèle **forfaitaire** verse un montant fixe
indépendamment de l'usage. L'incertitude sur l'ayant droit du chant
traditionnel (`KOR-07`) doit être **provisionnée** dans le modèle
économique (une réserve), pas ignorée en attendant une clarification
juridique.

## Méthode

1. Comprendre les deux modèles de calcul.
2. Vérifier la cohérence avec l'analyse déjà menée en `KOR-07` (ne pas
   la refaire, la citer).
3. Provisionner l'incertitude du chant traditionnel dans le modèle
   économique.

## Exemple

Une réserve de 10% des revenus liés à l'épisode, mise de côté en
attendant la clarification du statut du chant traditionnel — plutôt que
de distribuer 100% du revenu en ignorant le risque.

## Cas

Le modèle porte sur l'incertitude réelle déjà identifiée dans le cas
(`case/CASE.md`, `KOR-07`).

## Erreurs fréquentes

- Refaire l'analyse juridique de `KOR-07` au lieu de la citer.
- Distribuer 100% du revenu en ignorant l'incertitude de droits.

## Activité

Compréhension des modèles de calcul.

## Exercice

Provisionner l'incertitude dans le modèle économique.

## Livrable

## Critères de réussite

- Une provision réaliste est prévue pour l'incertitude.
