## Situation professionnelle

Le terme "CVE" a été mentionné par le Founder pour ce domaine
(monétisation), sans qu'aucune définition ne soit documentée dans ce
repo — un module dédié doit poser cette absence explicitement, sans la
combler par une invention.

## Objectifs d'apprentissage

- Reconnaître qu'un terme évoqué peut désigner un système CVLN réel
  non présent dans ce repo.
- Documenter cette absence sans conclure à une inexistence ni inventer
  une définition.

## Notions essentielles

`CVE` reste `ACADEMY_LOCAL_EVIDENCE = NOT_FOUND` dans ce repo — aucune
occurrence, aucune définition (`KOR-0001` §4, `KOR-0002` §1.3). La
vigilance impose de le marquer `EXTERNAL_PRODUCT_EVIDENCE_NOT_AUDITED`
(le système peut exister ailleurs dans l'écosystème CVLN, simplement
non vérifiable ici) — **jamais** `CVE_DOES_NOT_EXIST`, conclusion que
rien ne permet de tirer.

## Méthode

1. Vérifier l'absence de toute définition de CVE dans ce repo.
2. Documenter cette absence avec le vocabulaire correct.
3. Ne construire aucun modèle économique qui dépendrait d'une
   définition inventée de CVE.

## Exemple

Formulation correcte : « CVE n'est pas documenté dans ce repo —
`EXTERNAL_PRODUCT_EVIDENCE_NOT_AUDITED` — le modèle économique de
*Rasin* ne peut donc pas s'appuyer dessus tant qu'une clarification
n'est pas obtenue du Founder. » Formulation à proscrire : deviner que
CVE signifie "Culture Value Exchange" ou toute autre définition
inventée.

## Cas

La clarification porte sur l'absence réelle constatée dans ce repo
(`case/CASE.md`, `REFERENTIAL.md` §1).

## Erreurs fréquentes

- Inventer une définition de CVE pour "faire avancer" le modèle
  économique.
- Conclure que CVE n'existe pas dans l'écosystème CVLN au sens large.

## Activité

Vérification de l'absence de CVE dans ce repo.

## Exercice

Rédiger la note de clarification avec le vocabulaire correct.

## Livrable

Note de clarification CVE.

## Critères de réussite

- Aucune définition inventée n'est proposée.
- Le vocabulaire `EXTERNAL_PRODUCT_EVIDENCE_NOT_AUDITED` est utilisé,
  pas `CVE_DOES_NOT_EXIST`.
