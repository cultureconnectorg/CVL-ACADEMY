# KOR-10 — Templates

Seuls les templates réellement nécessaires à la production des
livrables du dossier `KOR10-A01` sont fournis (pas de gabarit pour le
volume).

## T1 — Gabarit de diagnostic économique (M01)
Sections : contexte, sources de revenus actuelles/potentielles,
contraintes réelles observées, hypothèses de départ explicites.

## T2 — Gabarit de calcul ARPU/LTV (M04)
Colonnes : hypothèse, valeur retenue, source/justification, sensibilité
(optimiste/pessimiste). Aucune ligne ne peut être remplie sans colonne
justification renseignée.

## T3 — Gabarit de partage de valeur (M05)
Lignes : contributeur, nature de la contribution (technique/non
technique), part proposée, justification. Une ligne "Man Rosa" est
obligatoire dans le cas fil rouge.

## T4 — Gabarit de note Wallet/JCC (M08)
Sections : mécanisme réel utilisé, fichier(s) source cité(s), limite
actuelle observée, ce qui reste hors périmètre.

## T5 — Gabarit de clarification CVE (M09)
Sections : ce qui est demandé, ce qui est réellement documenté
aujourd'hui, statut retenu (`EXTERNAL_PRODUCT_EVIDENCE_NOT_AUDITED`),
ce qui manque pour lever l'incertitude.

`STATUS = PROPOSED` pour l'ensemble des templates.
