# KOR11-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR11-A01
NIVEAU: N3, terminal (= M13)
NEEDS_EXPERT_REVIEW: TRUE
```

## Objectif
Prouver que le candidat peut conduire un dossier Trust & Safety complet
— signalement, modération, classification culturelle, fraude/usurpation,
handoff droits, protection mineurs, harcèlement, sanction/recours,
transparence, arbitrage culturel — avec rigueur et sans jamais trancher
par supposition ce qui dépasse son mandat.

## Ce qu'il vérifie / ne vérifie pas
Vérifie C1-C12 en situation intégrée. Ne vérifie pas une compétence
juridique réelle (droits, protection légale des mineurs), ni une
compétence de négociation (`KOR-07`, `KOR-13`).

## Format du dossier
| Section | Origine |
|---|---|
| Politique et gouvernance | M01 |
| Signalement et tri | M02 |
| Modération (épisode A) | M03 |
| Classification culturelle (épisode A) | M04 |
| Fraude/usurpation (épisode C) | M05/M06 |
| Handoff droits (épisode B) | M07 |
| Escalade mineurs (scénario dédié) | M08 |
| Harcèlement | M09 |
| Sanction et recours | M10 |
| Transparence | M11 |
| Arbitrage culturel (épisode B) | M12 |

## Conditions d'échec explicites
- Un litige de droits est tranché par une décision de modération seule
  → éliminatoire.
- Un contenu culturellement situé est retiré sans preuve réelle de
  nuisance → éliminatoire.
- Une victimisation secondaire est constatée dans le traitement d'un
  harcèlement → éliminatoire.
- Une capacité d'automatisation est affirmée sans preuve → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas
Évaluation **Academy** uniquement. Aucune habilitation légale, aucune
autorisation produit KORA.
