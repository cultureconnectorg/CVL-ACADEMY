# M03 — Conduire un workflow de modération

```
SKILL_ID: KOR11.SKILL.C03
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Conduire un signalement catégorisé jusqu'à une décision documentée et
traçable.

## Contenu
- Étapes d'un workflow de modération : réception, examen, décision,
  notification, journal.
- Délais raisonnables et proportionnés au type de signalement.
- Traçabilité : chaque décision doit pouvoir être réexaminée.

## Cas fil rouge
Épisode A, suite — conduire le signalement recueilli en M02 jusqu'à
décision.

## Exercice
Produire un rapport de modération complet pour l'épisode A (examen du
contenu, décision, justification, notification).

## Évaluation
N2 — `E-N2-01`.

## Évidence
Rapport de modération (`EVIDENCE_TYPE = MODERATION_REPORT`).
