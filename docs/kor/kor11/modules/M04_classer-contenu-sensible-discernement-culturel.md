# M04 — Classer un contenu sensible avec discernement culturel

```
SKILL_ID: KOR11.SKILL.C04
NEEDS_EXPERT_REVIEW: TRUE
```

## Objectif
Distinguer un contenu réellement problématique d'un contenu
culturellement situé qu'une lecture décontextualisée classerait à tort
comme sensible.

## Contenu
- Risques de sur-modération de contenus culturels créoles/caribéens
  (langue, imagerie, pratiques rituelles) par des grilles génériques.
- Méthode de classification : contexte, intention, public visé, impact
  réel documenté (pas supposé).
- Quand consulter un expert culturel avant de trancher.

## Cas fil rouge
Épisode A — évaluer si *Rasin* contient réellement un contenu
sensible, ou si le signalement relève d'une lecture décontextualisée.

## Exercice
Rédiger une note de classification justifiant le rejet ou le maintien
du signalement de l'épisode A.
