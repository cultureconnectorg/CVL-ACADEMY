# M05 — Identifier fraude et spam

```
SKILL_ID: KOR11.SKILL.C05
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Identifier des patterns de fraude/spam sans multiplier les faux
positifs sur des comptes légitimes.

## Contenu
- Signaux typiques : volume anormal, contenu dupliqué, liens suspects,
  demandes de paiement hors canal officiel.
- Faux positifs fréquents : créateurs actifs multi-plateformes,
  campagnes légitimes de promotion.

## Cas fil rouge
Préparation de l'épisode C (faux compte imitant Marc-Andy).

## Exercice
Identifier les signaux de fraude dans un jeu de comptes simulés,
distinguer le vrai compte du faux.

## Évaluation
N1 — `Q-N1-03`.

## Évidence
Note de détection (`EVIDENCE_TYPE = FRAUD_DETECTION_NOTE`).
