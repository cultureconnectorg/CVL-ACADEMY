# M06 — Traiter l'usurpation d'identité

```
SKILL_ID: KOR11.SKILL.C06
NEEDS_EXPERT_REVIEW: TRUE
```

## Objectif
Traiter un cas d'usurpation d'identité avec une action proportionnée
et une protection réelle de la victime.

## Contenu
- Vérification d'identité : preuves acceptables, limites de ce qui est
  vérifiable à distance.
- Action proportionnée : suspension provisoire vs retrait définitif.
- Protection de la victime : communication, non-exposition
  supplémentaire.

## Cas fil rouge
Épisode C — faux compte imitant Marc-Andy sollicitant des paiements de
sponsors.

## Exercice
Constituer le dossier d'usurpation, décider de l'action, rédiger la
communication à Marc-Andy.

## Évaluation
N2 — `E-N2-03`.

## Évidence
Dossier d'usurpation (`EVIDENCE_TYPE = IMPERSONATION_CASE_FILE`).
