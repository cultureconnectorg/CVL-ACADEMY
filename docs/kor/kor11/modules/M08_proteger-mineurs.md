# M08 — Protéger les mineurs

```
SKILL_ID: KOR11.SKILL.C08
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Appliquer une politique de protection des mineurs incluant escalade
obligatoire, sans improviser une réponse individuelle sur un sujet à
haut risque légal.

## Contenu
- Ce qui relève d'une escalade légale/institutionnelle obligatoire
  (hors mandat Academy — `NEEDS_EXPERT_REVIEW = TRUE` explicite).
- Ce qui relève d'une action de modération de premier niveau (retrait
  conservatoire immédiat).
- Documentation minimale requise pour toute escalade.

## Cas fil rouge
Non applicable directement (sujet trop sensible pour être simulé sur
le fil rouge existant) — traité par exercice dédié.

## Exercice
Sur un scénario dédié (non lié au fil rouge), produire une fiche
d'escalade complète et identifier explicitement ce qui dépasse le
mandat Academy.

## Évaluation
N1 — `Q-N1-05`.

## Évidence
Fiche d'escalade (`EVIDENCE_TYPE = MINOR_SAFETY_ESCALATION_NOTE`).

## Avertissement explicite
Ce module ne remplace aucune obligation légale réelle de signalement.
`NEEDS_EXPERT_REVIEW = TRUE` — toute politique réelle de protection des
mineurs doit être validée par une expertise juridique externe avant
tout déploiement.
