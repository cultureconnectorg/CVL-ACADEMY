# M11 — Produire un rapport de transparence

```
SKILL_ID: KOR11.SKILL.C11
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Produire un rapport de transparence honnête sur l'activité de
modération, sans sur-vendre une automatisation qui n'existe pas.

## Contenu
- Métriques honnêtes : volume de signalements, délai moyen de
  traitement, taux de recours, taux de réversion de décision.
- Interdiction explicite de présenter un processus manuel comme
  "alimenté par IA" ou "automatisé" s'il ne l'est pas
  (`NO_FAKE_PRODUCT_CAPABILITY`).
- Ce qu'un rapport de transparence doit et ne doit pas contenir
  (jamais de données personnelles identifiables des personnes
  signalées).

## Cas fil rouge
Rapport de transparence trimestriel fictif pour Anba Tonèl Host,
couvrant les épisodes A/B/C.

## Exercice
Rédiger le rapport, avec ses limites explicitement énoncées.

## Évaluation
N1 — `Q-N1-06`.

## Évidence
Rapport de transparence (`EVIDENCE_TYPE = TRANSPARENCY_REPORT`).
