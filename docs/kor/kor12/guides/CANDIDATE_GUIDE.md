# KOR-12 — Guide du Candidat

## Ce que cette formation certifie
Conduire une analyse data de bout en bout sur un contenu streaming
culturel — instrumentation (M01) jusqu'à la soutenance (M13) — en
distinguant systématiquement donnée fiable/non fiabilisée, capacité
réelle/hypothétique, éclairage/décision.

## Ce que cette formation NE certifie PAS
- Une compétence d'ingénierie de données réelle (pipelines,
  infrastructure).
- Une compétence de décision éditoriale (`KOR-04`).
- Une capacité produit KORA de recommandation ou d'interfaçage Brain.

## Parcours
M01 événements → M02 dashboards → M03 qualité des données → M04
comportement → M05 cohortes → M06 rétention → M07 tendances → M08
performance → M09 recommandation (concept) → M10 biais → M11
intelligence culturelle → M12 éclairage éditorial → M13 synthèse et
soutenance.

## Cas fil rouge
Vous incarnez Fabiola, analyste data, qui répond à une question de
Naïma (`KOR-04`) sur *Rasin*.

## Vigilance obligatoire
- Aucune capacité de recommandation ou de connexion Brain→KORA
  n'existe — ne jamais l'affirmer (C9, éliminatoire).
- Les biais culturels anticipés doivent être identifiés même pour un
  système hypothétique (C10, éliminatoire).
- Une note d'éclairage ne prescrit jamais une décision (C12,
  éliminatoire).

## Ce que délivre la réussite
Une évaluation Academy (`KOR12-A01`).
