# M02 — Construire métriques et dashboards

```
SKILL_ID: KOR12.SKILL.C02
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un dashboard lisible à partir d'un jeu de données simulé,
avec des métriques pertinentes pour l'audience culturelle visée.

## Contenu
- Métriques de base : plays, taux de complétion, durée moyenne
  d'écoute.
- Choix de visualisation adaptés à une audience non technique
  (Naïma, `KOR-04`).
- Éviter les métriques de vanité (nombre brut sans contexte).

## Cas fil rouge
Épisode A, suite — dashboard de complétion par épisode pour *Rasin*.

## Exercice
Construire le dashboard (maquette ou tableau) sur données simulées
fournies.

## Évaluation
N1 — `Q-N1-02`.

## Évidence
Dashboard (`EVIDENCE_TYPE = DASHBOARD_SPEC`).
