# M03 — Assurer la qualité des données

```
SKILL_ID: KOR12.SKILL.C03
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Détecter et traiter un problème de qualité de données avant toute
interprétation.

## Contenu
- Problèmes typiques : doublons, événements manquants, incohérence
  entre seuils.
- Méthode de fiabilisation : dédoublonnage, règles de validation,
  documentation des limites connues.
- Ne jamais interpréter des données non fiabilisées comme si elles
  l'étaient.

## Cas fil rouge
Épisode B — doublons suspectés dans les événements de *Rasin*.

## Exercice
Produire un rapport de qualité de données identifiant le problème et
sa correction.

## Évaluation
N2 — `E-N2-01`.

## Évidence
Rapport de qualité (`EVIDENCE_TYPE = DATA_QUALITY_REPORT`).
