# M05 — Construire des cohortes

```
SKILL_ID: KOR12.SKILL.C05
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire des cohortes d'audience pertinentes pour une comparaison
utile.

## Contenu
- Critères de cohorte : date d'acquisition, canal, segment
  géographique/diaspora (`KOR-09`).
- Éviter les cohortes trop fines pour être statistiquement
  significatives sur un petit jeu de données.

## Cas fil rouge
Épisode C — cohorte "auditeurs diaspora" vs "auditeurs locaux"
(rattaché à `KOR-09`).

## Exercice
Construire les deux cohortes et documenter le critère de découpage.

## Évaluation
N2 — `E-N2-02`.

## Évidence
Analyse de cohortes (`EVIDENCE_TYPE = COHORT_ANALYSIS`).
