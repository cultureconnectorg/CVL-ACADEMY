# M07 — Détecter des tendances

```
SKILL_ID: KOR12.SKILL.C07
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Détecter une tendance réelle dans un jeu de données simulé, sans
confondre bruit et signal.

## Contenu
- Différence tendance vs fluctuation ponctuelle.
- Fenêtre d'observation minimale avant de conclure à une tendance.

## Cas fil rouge
Non couvert par le fil rouge central — exercice dédié sur un jeu de
données simulé multi-émissions d'Anba Tonèl Host (`KOR-06`).

## Exercice
Identifier, sur le jeu fourni, une tendance réelle et une fausse
tendance (bruit), en justifiant la distinction.

## Évaluation
N1 — `Q-N1-04`.

## Évidence
Note de tendance (`EVIDENCE_TYPE = TREND_NOTE`).
