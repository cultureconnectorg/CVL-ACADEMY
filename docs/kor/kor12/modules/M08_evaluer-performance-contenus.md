# M08 — Évaluer la performance des contenus

```
SKILL_ID: KOR12.SKILL.C08
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Évaluer la performance de plusieurs contenus avec des critères
multiples, pas un seul chiffre de vanité.

## Contenu
- Grille multi-critères : complétion, rétention induite, engagement
  qualitatif (commentaires, partages simulés).
- Distinguer performance commerciale (`KOR-10`) et performance
  éditoriale (ce module).

## Cas fil rouge
Comparer *Rasin*, *Gwo Siwo* et *Anlè Lakou* (fil rouge `KOR-04`) sur
un jeu de données simulé.

## Exercice
Produire le rapport de performance comparatif multi-critères.

## Évaluation
N1 — `Q-N1-05`.

## Évidence
Rapport de performance (`EVIDENCE_TYPE = CONTENT_PERFORMANCE_REPORT`).
