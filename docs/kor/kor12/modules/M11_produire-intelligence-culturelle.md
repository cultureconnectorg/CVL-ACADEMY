# M11 — Produire une intelligence culturelle

```
SKILL_ID: KOR12.SKILL.C11
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Transformer des données en interprétation culturelle utile — pas
seulement des chiffres, un sens.

## Contenu
- Différence donnée brute vs intelligence culturelle : le "pourquoi"
  derrière le "combien".
- Risque d'interprétation hâtive : une donnée peut avoir plusieurs
  lectures culturelles plausibles — les nommer toutes avant de choisir.

## Cas fil rouge
Épisode E — pourquoi *Rasin* a-t-il une forte complétion mais peu de
nouveaux auditeurs ? Fabiola doit proposer plusieurs lectures possibles
(bouche-à-oreille insuffisant, absence de recommandation, niche
linguistique) avant de conclure.

## Exercice
Rédiger la note d'intelligence culturelle avec ses lectures multiples
et sa conclusion argumentée.

## Évaluation
N2 — `E-N2-05`.

## Évidence
Note d'intelligence culturelle (`EVIDENCE_TYPE = CULTURAL_INTELLIGENCE_NOTE`).
