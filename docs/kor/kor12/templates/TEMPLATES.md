# KOR-12 — Templates

## T1 — Gabarit de plan d'événements (M01)
Colonnes : événement, déclencheur, donnée capturée, justification.

## T2 — Gabarit de rapport de qualité de données (M03)
Sections : problème détecté, impact, correction, limite résiduelle.

## T3 — Gabarit d'analyse de cohortes (M05)
Sections : critère de découpage, taille de chaque cohorte, métrique
comparée, conclusion prudente.

## T4 — Gabarit de rapport de biais (M10)
Sections : source de biais potentielle, population affectée, mesure
d'atténuation proposée, statut (hypothétique/réel).

## T5 — Gabarit de note d'éclairage éditorial (M12)
Sections : constat, options possibles avec implications, recommandation
non prescriptive, décision laissée à l'éditorial.
