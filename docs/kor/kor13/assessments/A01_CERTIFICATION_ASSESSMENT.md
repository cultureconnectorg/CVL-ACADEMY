# KOR13-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR13-A01
NIVEAU: N3, terminal (= M13)
NEEDS_EXPERT_REVIEW: TRUE
```

## Objectif
Prouver que le candidat peut conduire un dossier de partenariats
créateurs de bout en bout — cartographie jusqu'au suivi et à la
décision de renouvellement — en respectant strictement les frontières
avec `KOR-05` (onboarding) et `KOR-07` (droits).

## Ce qu'il vérifie / ne vérifie pas
Vérifie C1-C12. Ne vérifie pas une compétence d'onboarding quotidien
(`KOR-05`), ni une habilitation juridique réelle à signer un contrat.

## Format du dossier
| Section | Origine |
|---|---|
| Cartographie | M01 |
| Sourcing | M02 |
| Qualification | M03 |
| Proposition de valeur | M04 |
| Négociation | M05 |
| Handoff KOR-05 | M06 |
| Acquisition | M07 |
| Partenariat institutionnel/média | M08 |
| Relation dans la durée | M09 |
| Campagne commune | M10 |
| Suivi de performance | M11 |
| Décision de renouvellement | M12 |

## Conditions d'échec explicites
- Le handoff vers `KOR-05` duplique le contenu d'onboarding plutôt que
  de le préparer → éliminatoire.
- Une clause de droits est négociée en détail plutôt que renvoyée à
  `KOR-07` → éliminatoire.
- Une capacité KORA de CRM partenariats est affirmée comme existante →
  éliminatoire.

## Ce que la réussite délivre — et ne délivre pas
Évaluation **Academy** uniquement. Aucune habilitation à signer un
contrat réel.
