# KOR-13 — Guide du Jury

## Rôle du jury
Valider que le candidat sait défendre ses choix de partenariat face à
la contestation, en respectant les frontières `KOR-05`/`KOR-07`.

## Trame de soutenance recommandée
1. Présentation du dossier (5 min).
2. Question obligatoire sur le handoff M06 : qu'est-ce qui distingue ce
   dossier d'un dossier d'onboarding `KOR-05` ?
3. Question obligatoire sur M08 : que ferait le candidat si Rézo Radyo
   Kreyòl insistait pour régler la question des droits directement
   avec lui plutôt que via `KOR-07` ?
4. Question sur M12 : le candidat aurait-il renouvelé le partenariat
   simulé même si les chiffres étaient légèrement en dessous du
   seuil ?
