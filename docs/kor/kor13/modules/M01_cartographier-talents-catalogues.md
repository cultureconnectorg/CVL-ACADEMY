# M01 — Cartographier talents et catalogues

```
SKILL_ID: KOR13.SKILL.C01
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Cartographier un paysage de créateurs et catalogues culturels
pertinents pour une stratégie de partenariat.

## Contenu
- Critères de cartographie : genre, audience, maturité, disponibilité.
- Sources : observation directe, réseau, recommandations.

## Cas fil rouge
Épisode A — cartographie incluant Lanbi Collective, Kajou Studio
(`KOR-05`).

## Exercice
Produire une cartographie de 5 créateurs/catalogues fictifs classés
par pertinence.

## Évaluation
N1 — `Q-N1-01`.

## Évidence
Cartographie (`EVIDENCE_TYPE = TALENT_MAP`).
