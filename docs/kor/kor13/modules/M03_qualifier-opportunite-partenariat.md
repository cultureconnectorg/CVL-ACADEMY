# M03 — Qualifier une opportunité de partenariat

```
SKILL_ID: KOR13.SKILL.C03
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Qualifier une opportunité de partenariat avec des critères explicites,
sans se laisser porter par le seul enthousiasme du premier contact.

## Contenu
- Critères de qualification : cohérence éditoriale, disponibilité
  réelle, capacité de production (rattaché à `KOR-05`), audience.
- Signaux d'alerte : promesses disproportionnées, absence de
  disponibilité réelle.

## Cas fil rouge
Épisode B — qualifier Lanbi Collective avant de construire la
proposition.

## Exercice
Produire la note de qualification avec verdict argumenté.

## Évaluation
N2 — `E-N2-01`.

## Évidence
Note de qualification (`EVIDENCE_TYPE = QUALIFICATION_NOTE`).
