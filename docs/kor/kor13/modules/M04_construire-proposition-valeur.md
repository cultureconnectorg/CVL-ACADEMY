# M04 — Construire une proposition de valeur

```
SKILL_ID: KOR13.SKILL.C04
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire une proposition de valeur adaptée au partenaire qualifié,
pas un modèle générique.

## Contenu
- Ce qu'une proposition de valeur crédible contient : ce que le
  partenaire apporte, ce qu'il reçoit, ce que cela ne couvre pas
  (renvoi explicite à `KOR-10` pour la monétisation détaillée).
- Éviter les promesses non tenables (capacité KORA inexistante).

## Cas fil rouge
Épisode B, suite — proposition de valeur pour Lanbi Collective.

## Exercice
Rédiger la proposition de valeur complète.

## Évaluation
N2 — `E-N2-02`.

## Évidence
Proposition de valeur (`EVIDENCE_TYPE = VALUE_PROPOSITION_DOC`).
