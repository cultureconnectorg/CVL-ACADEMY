# M05 — Négocier les termes d'un partenariat

```
SKILL_ID: KOR13.SKILL.C05
NEEDS_EXPERT_REVIEW: TRUE

```

## Objectif
Conduire une négociation méthodique, sans habilitation juridique réelle
à engager contractuellement l'organisation.

## Contenu
- Méthode de négociation : intérêts vs positions, marges de manœuvre,
  points non négociables.
- Limite explicite : ce module enseigne la méthode, il n'habilite à
  signer aucun contrat réel.

## Cas fil rouge
Épisode C — négociation avec Ana, Wilkens, Solène (Lanbi Collective).

## Exercice
Simuler la négociation et documenter les termes provisoirement
convenus.

## Évaluation
N2 — `E-N2-03`.

## Évidence
Note de négociation (`EVIDENCE_TYPE = NEGOTIATION_NOTE`).
