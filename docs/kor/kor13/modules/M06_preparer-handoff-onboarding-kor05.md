# M06 — Préparer le handoff d'onboarding vers KOR-05

```
SKILL_ID: KOR13.SKILL.C06
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Préparer un dossier de handoff complet vers l'onboarding quotidien
(`KOR-05`), sans dupliquer le contenu d'onboarding lui-même.

## Contenu
- Ce que le handoff doit contenir : termes convenus, contacts,
  attentes, contraintes connues.
- Ce que le handoff ne doit pas faire : refaire le travail
  d'onboarding déjà couvert par `KOR-05`.

## Cas fil rouge
Épisode C, suite — dossier de handoff Lanbi Collective vers Kessy
(`KOR-05`).

## Exercice
Produire le dossier de handoff complet.

## Évaluation
N1 — `Q-N1-03`.

## Évidence
Dossier de handoff (`EVIDENCE_TYPE = ONBOARDING_HANDOFF_FILE`).

## Boundary check
Un dossier qui reproduit le contenu d'onboarding de `KOR-05` au lieu de
le préparer échoue ce critère (`NO_DUPLICATE_CURRICULUM`).
