# M07 — Conduire une acquisition de catalogue

```
SKILL_ID: KOR13.SKILL.C07
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Conduire une acquisition de catalogue (contenus existants d'un
créateur) distincte d'un partenariat de production continue.

## Contenu
- Différence acquisition (catalogue existant) vs partenariat continu
  (production future).
- Diligence minimale : origine des droits (renvoi `KOR-07`), qualité
  technique (renvoi `KOR-08` pour les métadonnées).

## Cas fil rouge
Non couvert par le fil rouge central — exercice dédié : acquisition
d'un catalogue archive fictif d'un créateur retraité.

## Exercice
Produire la note d'acquisition avec ses points de diligence.

## Évaluation
N1 — `Q-N1-04`.

## Évidence
Note d'acquisition (`EVIDENCE_TYPE = ACQUISITION_NOTE`).
