# M09 — Entretenir la relation créateur dans la durée

```
SKILL_ID: KOR13.SKILL.C09
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un plan relationnel qui dépasse le point de signature,
distinct du support quotidien (`KOR-05`).

## Contenu
- Cadence relationnelle : points réguliers, écoute des besoins
  émergents, anticipation des tensions.
- Différence avec `KOR-05` : ce module porte sur la relation
  stratégique (le partenariat reste-t-il pertinent ?), pas sur le
  support opérationnel quotidien.

## Cas fil rouge
Non directement couvert — exercice dédié sur un partenariat fictif
plus ancien.

## Exercice
Produire un plan relationnel sur 12 mois.

## Évaluation
N1 — `Q-N1-05`.

## Évidence
Plan relationnel (`EVIDENCE_TYPE = RELATIONSHIP_PLAN`).
