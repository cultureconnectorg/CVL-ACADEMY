# M10 — Concevoir une campagne commune

```
SKILL_ID: KOR13.SKILL.C10
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir une campagne commune entre deux partenaires, avec des
bénéfices équilibrés pour chacun.

## Contenu
- Structure d'une campagne commune : objectif partagé, contribution de
  chaque partie, mesure de succès.
- Risque d'asymétrie : une campagne qui profite surtout à une partie
  fragilise la relation.

## Cas fil rouge
Exercice dédié : campagne commune Lanbi Collective × Fondasyon Kreyòl.

## Exercice
Rédiger le brief de campagne commune.

## Évaluation
N1 — `Q-N1-06`.

## Évidence
Brief de campagne (`EVIDENCE_TYPE = JOINT_CAMPAIGN_BRIEF`).
