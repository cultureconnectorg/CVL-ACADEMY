# M11 — Suivre la performance d'un partenariat

```
SKILL_ID: KOR13.SKILL.C11
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un tableau de suivi de performance de partenariat avec des
indicateurs pertinents (pas seulement financiers, voir `KOR-10`).

## Contenu
- Indicateurs : respect des engagements, qualité relationnelle,
  résultats concrets (audience, image, co-création).
- Fréquence de suivi adaptée à la nature du partenariat.

## Cas fil rouge
Suivi du partenariat Lanbi Collective sur 2 trimestres simulés.

## Exercice
Produire le tableau de suivi avec ses indicateurs.

## Évaluation
N1 — `Q-N1-07`.

## Évidence
Tableau de suivi (`EVIDENCE_TYPE = PARTNERSHIP_PERFORMANCE_TRACKER`).
