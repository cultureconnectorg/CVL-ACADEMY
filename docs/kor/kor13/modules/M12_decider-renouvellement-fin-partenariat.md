# M12 — Décider un renouvellement ou une fin de partenariat

```
SKILL_ID: KOR13.SKILL.C12
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Décider, sur la base du suivi (M11), un renouvellement, un ajustement,
ou une fin de partenariat — avec une justification honnête.

## Contenu
- Critères de décision : performance réelle, alignement stratégique
  toujours valide, coût relationnel d'une fin de partenariat.
- Comment mettre fin à un partenariat sans dégrader la réputation.

## Cas fil rouge
Décision de renouvellement (ou non) pour le partenariat suivi en M11.

## Exercice
Rédiger la note de décision avec sa justification.

## Évaluation
N2 — `E-N2-05`.

## Évidence
Note de décision (`EVIDENCE_TYPE = RENEWAL_DECISION_NOTE`).
