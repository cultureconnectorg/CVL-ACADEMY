# KOR14-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR14-A01
NIVEAU: N3, terminal (= M14)
```

## Objectif
Prouver que le candidat peut concevoir une expérience produit/UX de
streaming culturel complète, en respectant les frontières avec
`KOR-06` (exploitation), `KOR-09` (acquisition) et `KOR-12` (data), et
sans jamais affirmer une capacité KORA inexistante.

## Ce qu'il vérifie / ne vérifie pas
Vérifie C1-C13. Ne vérifie pas une compétence de développement
technique réelle (frontend/mobile), ni d'exploitation infrastructure
(`KOR-06`).

## Format du dossier
| Section | Origine |
|---|---|
| Parcours utilisateur | M01 |
| Discovery/home/feed | M02 |
| Recherche | M03 |
| Bibliothèque | M04 |
| Player/queue/playlists | M05 |
| Placement recommandations | M06 |
| Accessibilité | M07 |
| Multi-surface | M08 |
| Expérience creator | M09 |
| Tests utilisateurs | M10 |
| Analytics produit | M11 |
| Incident UX | M12 |
| Amélioration continue | M13 |

## Conditions d'échec explicites
- Un moteur de recommandation ou une capacité KORA inexistante est
  affirmée → éliminatoire.
- Un incident de disponibilité (`KOR-06`) est traité comme un incident
  UX (ou l'inverse) → éliminatoire.
- Une métrique de streaming (`KOR-12`) est présentée comme une métrique
  produit → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas
Évaluation **Academy** uniquement.
