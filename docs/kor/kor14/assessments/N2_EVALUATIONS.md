# KOR-14 — Évaluations N2

## E-N2-01 (C2) — Home/feed pour Rasin
**Situation** : mettre en avant *Rasin* sans moteur de recommandation.
**Décision attendue** : maquette avec justification éditoriale
(curation, renvoi `KOR-04`), pas algorithmique.
**Barème** : pertinence de la mise en avant (60%), absence de
prétention algorithmique (40%).

## E-N2-02 (C3) — Recherche tolérante
**Situation** : un auditeur ne retrouve pas *Rasin*.
**Décision attendue** : maquette de recherche tolérante à
l'orthographe.
**Barème** : tolérance démontrée (60%), cas de test couverts (40%).

## E-N2-03 (C7) — Accessibilité pour audience diaspora
**Situation** : faible littératie numérique.
**Décision attendue** : rapport avec recommandations concrètes et
réalistes.
**Barème** : pertinence culturelle (60%), faisabilité (40%).

## E-N2-04 (C8) — Priorité mobile
**Situation** : connectivité limitée pour l'audience diaspora.
**Décision attendue** : priorisation mobile justifiée.
**Barème** : justification (60%), cohérence avec `KOR-09` (40%).

## E-N2-05 (C10) — Tests utilisateurs du nouveau parcours
**Situation** : tester le parcours redessiné.
**Décision attendue** : protocole rigoureux, conclusions prudentes.
**Barème** : rigueur du protocole (60%), prudence des conclusions
(40%).

## E-N2-06 (C12) — Incident UX après mise à jour
**Situation** : navigation cassée pour une partie des utilisateurs.
**Décision attendue** : diagnostic correct (UX, pas disponibilité) et
correctif proposé.
**Barème** : diagnostic correct (60%, éliminatoire si confondu avec
`KOR-06`), correctif pertinent (40%).
