# M01 — Cartographier le parcours utilisateur de bout en bout

```
SKILL_ID: KOR14.SKILL.C01
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Cartographier le parcours actuel d'un utilisateur type, des points de
friction aux moments de valeur.

## Contenu
- Étapes typiques : arrivée, découverte, écoute, retour.
- Distinction entre le parcours *in-app* (`KOR-14`) et le canal qui a
  amené l'utilisateur (`KOR-09`).

## Cas fil rouge
Épisode A — cartographier le parcours actuel d'un auditeur diaspora
type vers *Rasin*.

## Exercice
Produire la carte de parcours avec points de friction identifiés.

## Évaluation
N1 — `Q-N1-01`.

## Évidence
Carte de parcours (`EVIDENCE_TYPE = USER_JOURNEY_MAP`).
