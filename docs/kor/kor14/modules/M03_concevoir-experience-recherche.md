# M03 — Concevoir une expérience de recherche

```
SKILL_ID: KOR14.SKILL.C03
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir une recherche tolérante à la variabilité orthographique
(créole, translittérations multiples).

## Contenu
- Tolérance orthographique, suggestions, résultats partiels plutôt que
  "aucun résultat".
- Métadonnées nécessaires à une bonne recherche (renvoi `KOR-08`).

## Cas fil rouge
Épisode B — un auditeur ne retrouve pas *Rasin* via la recherche.

## Exercice
Produire la maquette de recherche tolérante avec cas de test
orthographiques.

## Évaluation
N2 — `E-N2-02`.

## Évidence
Maquette de recherche (`EVIDENCE_TYPE = SEARCH_UX_MOCKUP`).
