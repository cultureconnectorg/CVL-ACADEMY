# M04 — Concevoir une bibliothèque personnelle

```
SKILL_ID: KOR14.SKILL.C04
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir une bibliothèque personnelle simple pour un public à faible
littératie numérique.

## Contenu
- Principes de simplicité : peu de catégories, icônes claires,
  vocabulaire familier.
- Éviter la sur-fonctionnalité qui nuit à l'utilisabilité.

## Cas fil rouge
Épisode B, suite — bibliothèque simplifiée pour l'audience diaspora.

## Exercice
Produire la maquette de bibliothèque.

## Évaluation

## Évidence
Maquette (`EVIDENCE_TYPE = LIBRARY_UX_MOCKUP`).
