# M05 — Concevoir player, file d'attente et playlists

```
SKILL_ID: KOR14.SKILL.C05
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir une expérience de lecture cohérente (player, file d'attente,
playlists) comme un ensemble, pas trois écrans disjoints.

## Contenu
- Contrôles essentiels du player, gestion de la file d'attente,
  création/édition de playlists.
- Continuité entre les trois composants (ne pas perdre la file
  d'attente en éditant une playlist).

## Cas fil rouge
Non couvert directement — exercice dédié sur l'écoute de *Rasin* et
d'autres émissions à la suite.

## Exercice
Produire la maquette intégrée player/queue/playlists.
