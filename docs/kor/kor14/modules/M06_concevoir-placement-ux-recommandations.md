# M06 — Concevoir le placement UX de recommandations

```
SKILL_ID: KOR14.SKILL.C06
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir où et comment une recommandation apparaîtrait dans
l'interface, sans que le moteur lui-même existe — angle UX, distinct
de l'angle data (`KOR-12`).

## Contenu
- Emplacements typiques : home, fin de lecture, recherche.
- Rappel explicite : aucun moteur de recommandation KORA n'existe
  aujourd'hui (cohérent avec `KOR-12`) — ce module conçoit
  l'emplacement, pas l'algorithme.

## Cas fil rouge
Épisode A, suite — où *Rasin* apparaîtrait-il si une recommandation
existait un jour ?

## Exercice
Produire la note de placement UX avec ses hypothèses explicites.

## Évaluation
N1 — `Q-N1-04`.

## Évidence
Note de placement (`EVIDENCE_TYPE = RECOMMENDATION_PLACEMENT_NOTE`).

## Boundary check
Toute affirmation qu'un moteur de recommandation existe aujourd'hui
échoue ce critère (repris en assessment).
