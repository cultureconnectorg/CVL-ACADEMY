# M07 — Assurer l'accessibilité de l'expérience

```
SKILL_ID: KOR14.SKILL.C07
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir une expérience accessible pour une audience à faible
littératie numérique et pour des besoins d'accessibilité standards
(lecteurs d'écran, contraste, taille de police).

## Contenu
- Principes d'accessibilité universels (WCAG, niveau conceptuel).
- Accessibilité culturelle : vocabulaire, icônes compréhensibles sans
  alphabétisation avancée.

## Cas fil rouge
Épisode C — audience diaspora à faible littératie numérique.

## Exercice
Produire le rapport d'accessibilité avec recommandations concrètes.

## Évaluation
N2 — `E-N2-03`.

## Évidence
Rapport d'accessibilité (`EVIDENCE_TYPE = ACCESSIBILITY_REPORT`).
