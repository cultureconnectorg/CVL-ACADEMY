# M08 — Adapter l'expérience à TV/mobile/web

```
SKILL_ID: KOR14.SKILL.C08
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Adapter une expérience à plusieurs surfaces sans dupliquer trois fois
le travail de conception.

## Contenu
- Contraintes propres à chaque surface : TV (distance, télécommande),
  mobile (connexion limitée, écran réduit), web (clavier/souris).
- Priorisation : quelle surface sert le mieux l'audience diaspora à
  faible connectivité (mobile) ?

## Cas fil rouge
Épisode C, suite — priorité mobile pour l'audience diaspora.

## Exercice
Produire la note d'adaptation multi-surface avec priorité justifiée.

## Évaluation
N2 — `E-N2-04`.

## Évidence
Note multi-surface (`EVIDENCE_TYPE = MULTI_SURFACE_ADAPTATION_NOTE`).
