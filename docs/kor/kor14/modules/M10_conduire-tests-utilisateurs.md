# M10 — Conduire des tests utilisateurs

```
SKILL_ID: KOR14.SKILL.C10
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Conduire un test utilisateur structuré sur le nouveau parcours et en
tirer des conclusions actionnables.

## Contenu
- Méthode : protocole de test, tâches, observation, éviter de suggérer
  la réponse attendue.
- Analyse des résultats sans sur-interpréter un petit échantillon.

## Cas fil rouge
Épisode E — tests utilisateurs sur le nouveau parcours de découverte
de *Rasin*.

## Exercice
Produire le rapport de tests utilisateurs avec conclusions et limites.

## Évaluation
N2 — `E-N2-05`.

## Évidence
Rapport de tests (`EVIDENCE_TYPE = USER_TESTING_REPORT`).
