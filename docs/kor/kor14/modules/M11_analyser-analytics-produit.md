# M11 — Analyser des analytics produit

```
SKILL_ID: KOR14.SKILL.C11
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Analyser des métriques produit (usage de fonctionnalités, taux de
complétion d'un parcours) — distinct de l'analyse de données de
streaming (`KOR-12`, comportement d'audience et contenu).

## Contenu
- Différence analytics produit (l'interface est-elle utilisée
  correctement ?) vs data streaming (`KOR-12`, le contenu
  performe-t-il ?).
- Métriques typiques : taux de complétion de parcours, taux d'abandon
  à une étape.

## Cas fil rouge
Analyse simulée du taux d'abandon dans le nouveau parcours de
découverte.

## Exercice
Produire la note d'analytics produit.

## Évaluation
N1 — `Q-N1-06`.

## Évidence
Note d'analytics (`EVIDENCE_TYPE = PRODUCT_ANALYTICS_NOTE`).
