# KOR-15 — Modèle de certification

## Ce que délivre KOR15-A01
`ACADEMY_CERTIFICATION` (interne KORA Academy) uniquement.

## Distinctions obligatoires
| Terme | Statut ici |
|---|---|
| `COURSE_COMPLETION` | Atteint dès N1/N2 complétés |
| `SKILL_VALIDATION` | Atteint compétence par compétence via Skill IDs |
| `ACADEMY_CERTIFICATION` | Atteint via `KOR15-A01` |
| `BADGE` | Non traité ici |
| `PRODUCT_AUTHORIZATION` | **Jamais délivré** |
| `RNCP_OR_STATE_CERTIFICATION` | **Non applicable** |

## Conditions de délivrance
Voir `assessments/RUBRIC.md` (seuil global + critères 5, 11
éliminatoires).

## Avertissement
Cette certification n'habilite à aucun déploiement réel ni négociation
de droits territoriaux réelle. `NEEDS_EXPERT_REVIEW = TRUE`.

## Statut
`FULLY_COMPLETE = FALSE`. `CORE_BUILD = COMPLETE`.
