# KOR15-A01 — Assessment certificatif

```
ASSESSMENT_ID: KOR15-A01
NIVEAU: N3, terminal (= M12)
NEEDS_EXPERT_REVIEW: TRUE
```

## Objectif
Prouver que le candidat peut conduire une stratégie de distribution
internationale de streaming culturel de bout en bout, en respectant
les frontières avec `KOR-07` (droits), `KOR-13` (partenariats) et
`KLT-07` (réseau Kiltikonet, confirmé non pertinent ici).

## Ce qu'il vérifie / ne vérifie pas
Vérifie C1-C11. Ne vérifie pas une compétence juridique réelle de
droits territoriaux, ni une négociation contractuelle réelle.

## Format du dossier
| Section | Origine |
|---|---|
| Stratégie territoriale | M01 |
| Analyse de marché (×3) | M02 |
| Localisation | M03 |
| Adaptation culturelle | M04 |
| Droits territoriaux (handoff KOR-07) | M05 |
| Partenariat local | M06 |
| Partenariat institution | M07 |
| Partenariat telco/média | M08 |
| Mécanisme de distribution | M09 |
| Playbook de déploiement | M10 |
| Coordination internationale | M11 |

## Conditions d'échec explicites
- Un déploiement est programmé sans condition sur la clarification des
  droits territoriaux → éliminatoire.
- La coordination internationale reproduit la logique d'un réseau
  d'opérateurs Kiltikonet (`KLT-07`) → éliminatoire.
- Une capacité d'infrastructure de distribution KORA est affirmée
  comme existante → éliminatoire.

## Ce que la réussite délivre — et ne délivre pas
Évaluation **Academy** uniquement. Aucune habilitation juridique,
aucun déploiement réel autorisé.
