# KOR-15 — Évaluations N2

## E-N2-01 (C2) — Analyse de 3 marchés
**Situation** : appliquer la même grille à Caraïbe, diaspora, Afrique.
**Décision attendue** : 3 analyses cohérentes, méthode transférable
démontrée.
**Barème** : cohérence méthodologique (60%), pertinence des
conclusions par marché (40%).

## E-N2-02 (C4) — Adaptation culturelle pour le marché africain
**Situation** : marché sans historique culturel connu de l'équipe.
**Décision attendue** : adaptation équilibrée, sans dénaturer l'œuvre
ni ignorer les différences réelles.
**Barème** : pertinence de l'adaptation (60%), équilibre démontré
(40%).

## E-N2-03 (C6) — Partenariat avec Rézo Radyo Kreyòl
**Situation** : construire le partenariat local.
**Décision attendue** : dossier complet, méthode `KOR-13` appliquée
sans être refaite de zéro.
**Barème** : complétude (60%), cohérence avec `KOR-13` (40%).

## E-N2-04 (C10) — Playbook de déploiement Caraïbe
**Situation** : déploiement conditionné à la clarification des droits.
**Décision attendue** : playbook qui pose explicitement cette
condition.
**Barème** : structure du playbook (50%), condition de droits
explicite (50%, éliminatoire si absente).

## E-N2-05 (C11) — Coordination des 3 marchés
**Situation** : coordonner sans dupliquer `KLT-07`.
**Décision attendue** : plan de coordination produit/distribution,
jamais un réseau d'opérateurs façon Kiltikonet.
**Barème** : cohérence de la coordination (60%), absence de confusion
avec `KLT-07` (40%, éliminatoire si confondu).
