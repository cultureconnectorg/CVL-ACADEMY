# M01 — Concevoir une stratégie territoriale globale

```
SKILL_ID: KOR15.SKILL.C01
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir un cadre de stratégie territoriale applicable à plusieurs
marchés sans le refaire à chaque fois de zéro.

## Contenu
- Composantes d'une stratégie territoriale : priorisation des marchés,
  ressources disponibles, séquencement.
- Différence stratégie globale (ce module) et analyse marché par
  marché (M02).

## Cas fil rouge
Épisode A — cadre de stratégie pour Caraïbe, diaspora, Afrique.

## Exercice
Produire la note de stratégie territoriale avec priorisation
justifiée.

## Évaluation
N1 — `Q-N1-01`.

## Évidence
Note de stratégie (`EVIDENCE_TYPE = TERRITORIAL_STRATEGY_NOTE`).
