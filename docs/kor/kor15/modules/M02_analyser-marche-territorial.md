# M02 — Analyser un marché territorial

```
SKILL_ID: KOR15.SKILL.C02
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Appliquer une méthode d'analyse de marché transférable à des
territoires différents (Caraïbe, diaspora, Afrique, Amériques/Europe),
sans refaire une méthode différente pour chacun.

## Contenu
- Grille d'analyse commune : taille de marché estimée, concurrence,
  infrastructure locale, réceptivité culturelle.
- Application de la même grille à 3 territoires différents — ce qui
  varie, c'est le contenu de la grille, pas la méthode.

## Cas fil rouge
Épisode A, suite — analyse des 3 marchés cibles avec la même grille.

## Exercice
Produire les 3 analyses de marché.

## Évaluation
N2 — `E-N2-01`.

## Évidence
Analyse de marché (`EVIDENCE_TYPE = MARKET_ANALYSIS_REPORT`).
