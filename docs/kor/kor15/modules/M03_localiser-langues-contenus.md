# M03 — Localiser langues et contenus

```
SKILL_ID: KOR15.SKILL.C03
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir un plan de localisation (langues, métadonnées multilingues)
distinct de l'adaptation culturelle plus profonde (M04).

## Contenu
- Éléments à localiser : sous-titres, description, métadonnées
  (renvoi `KOR-08`).
- Différence localisation (traduction fidèle) et adaptation culturelle
  (M04, changement de forme/contenu).

## Cas fil rouge
Épisode B — plan de localisation de *Rasin* pour les 3 marchés.

## Exercice
Produire le plan de localisation.

## Évaluation
N1 — `Q-N1-02`.

## Évidence
Plan de localisation (`EVIDENCE_TYPE = LOCALIZATION_PLAN`).
