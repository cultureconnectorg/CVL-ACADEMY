# M04 — Adapter culturellement une offre

```
SKILL_ID: KOR15.SKILL.C04
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Identifier ce qui, au-delà de la traduction, doit être adapté pour
qu'une offre soit réellement pertinente dans un nouveau marché.

## Contenu
- Ce qui s'adapte : références culturelles, rythme narratif, format de
  diffusion (renvoi `KOR-03`/`KOR-04`).
- Risque d'adaptation excessive qui dénature l'œuvre originale — équilibre
  à documenter.

## Cas fil rouge
Épisode B, suite — qu'est-ce qui, dans *Rasin*, nécessite une
adaptation réelle pour le marché africain testé (sans historique
culturel préalable connu de l'équipe) ?

## Exercice
Produire la note d'adaptation culturelle avec ses arbitrages.

## Évaluation
N2 — `E-N2-02`.

## Évidence
Note d'adaptation (`EVIDENCE_TYPE = CULTURAL_ADAPTATION_NOTE`).
