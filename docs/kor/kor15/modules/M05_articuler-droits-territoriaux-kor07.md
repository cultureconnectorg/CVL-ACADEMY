# M05 — Articuler les droits territoriaux avec KOR-07

```
SKILL_ID: KOR15.SKILL.C05
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Reconnaître qu'un déploiement territorial ne peut avancer sans
clarification des droits, et renvoyer cette clarification à `KOR-07`
sans la trancher soi-même.

## Contenu
- Ce qu'un déploiement international implique en droits : territoire
  couvert, exclusivité, durée.
- Rappel du litige chant traditionnel (`KOR-07`, jamais résolu) —
  repris ici comme condition bloquante pour le déploiement sur Rézo
  Radyo Kreyòl, **toujours non résolu**.

## Cas fil rouge
Épisode C — clarifier les droits avant tout déploiement sur Rézo Radyo
Kreyòl.

## Exercice
Produire la fiche de handoff vers `KOR-07`, documentant explicitement
que le déploiement reste conditionné à cette clarification.

## Évaluation
N1 — `Q-N1-03`.

## Évidence
Fiche de handoff (`EVIDENCE_TYPE = TERRITORIAL_RIGHTS_HANDOFF_NOTE`).

## Boundary check
Un candidat qui propose de déployer malgré le litige non résolu, sans
condition explicite, échoue ce critère.
