# M06 — Construire des partenariats locaux

```
SKILL_ID: KOR15.SKILL.C06
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un partenariat avec un acteur local pertinent pour un
déploiement territorial, en s'appuyant sur la méthode déjà posée en
`KOR-13` sans la refaire.

## Contenu
- Spécificité du partenariat local territorial : connaissance du
  terrain, réseau de distribution existant.
- Renvoi explicite à `KOR-13` pour la méthode générale de
  sourcing/négociation — ce module l'applique à un contexte
  international, ne la reconstruit pas.

## Cas fil rouge
Épisode D — partenariat avec Rézo Radyo Kreyòl.

## Exercice
Produire le dossier de partenariat local.
