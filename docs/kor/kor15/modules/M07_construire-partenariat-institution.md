# M07 — Construire un partenariat institution

```
SKILL_ID: KOR15.SKILL.C07
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un partenariat avec une institution culturelle ou publique
dans un contexte de déploiement international.

## Contenu
- Spécificités : processus de décision institutionnel, enjeux
  diplomatiques/réputationnels à l'international.
- Renvoi à `KOR-13`/M08 pour la méthode de partenariat institutionnel
  générale.

## Cas fil rouge
Exercice dédié : partenariat institutionnel pour le test de marché
africain (institution culturelle fictive locale).

## Exercice
Produire le dossier institutionnel.

## Évaluation
N1 — `Q-N1-04`.

## Évidence
Dossier institutionnel (`EVIDENCE_TYPE = INTERNATIONAL_INSTITUTIONAL_FILE`).
