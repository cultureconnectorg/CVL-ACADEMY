# M08 — Construire un partenariat telco/média

```
SKILL_ID: KOR15.SKILL.C08
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un partenariat de distribution avec un opérateur télécom ou
un média, en tenant compte des contraintes de connectivité locale.

## Contenu
- Spécificités telco : forfaits data, zero-rating, contraintes
  techniques.
- Lien avec `KOR-09`/`KOR-14` : la connectivité limitée en diaspora et
  en Afrique influence le choix du partenaire de distribution.

## Cas fil rouge
Épisode D, suite — partenariat telco pour la distribution mobile en
zone à faible connectivité.

## Exercice
Produire le dossier telco/média.

## Évaluation
N1 — `Q-N1-05`.

## Évidence
Dossier telco/média (`EVIDENCE_TYPE = TELCO_MEDIA_PARTNERSHIP_FILE`).
