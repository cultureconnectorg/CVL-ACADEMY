# M09 — Concevoir un mécanisme de distribution

```
SKILL_ID: KOR15.SKILL.C09
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Concevoir le mécanisme concret par lequel un contenu atteint un
territoire (canal direct, relais partenaire, syndication).

## Contenu
- Types de mécanismes : distribution directe (application), relais
  partenaire (Rézo Radyo Kreyòl rediffuse), syndication (telco).
- Choix du mécanisme selon la stratégie (M01) et le marché (M02).

## Cas fil rouge
Non couvert directement — exercice dédié sur le choix de mécanisme
pour le marché africain testé.

## Exercice
Produire la note de mécanisme de distribution avec justification du
choix.

## Évaluation
N1 — `Q-N1-06`.

## Évidence
Note de mécanisme (`EVIDENCE_TYPE = DISTRIBUTION_MECHANISM_NOTE`).
