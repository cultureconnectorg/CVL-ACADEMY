# M10 — Piloter un déploiement marché

```
SKILL_ID: KOR15.SKILL.C10
NEEDS_EXPERT_REVIEW: TRUE
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Construire un playbook de déploiement marché intégrant les étapes
précédentes (stratégie, analyse, localisation, droits, partenariats).

## Contenu
- Structure d'un playbook : conditions préalables (droits clarifiés),
  séquencement, jalons, critères d'arrêt/poursuite.
- Rappel réglementation locale : `NEEDS_EXPERT_REVIEW = TRUE`, ce
  module ne remplace aucune expertise juridique/réglementaire locale
  réelle.

## Cas fil rouge
Épisode E — playbook de déploiement test pour le marché Caraïbe
(Rézo Radyo Kreyòl), conditionné à la clarification des droits (M05).

## Exercice
Produire le playbook de déploiement.

## Évaluation
N2 — `E-N2-04`.

## Évidence
Playbook (`EVIDENCE_TYPE = MARKET_DEPLOYMENT_PLAYBOOK`).

## Boundary check
Un playbook qui programme le déploiement sans condition sur la
clarification des droits (M05) échoue ce critère.
