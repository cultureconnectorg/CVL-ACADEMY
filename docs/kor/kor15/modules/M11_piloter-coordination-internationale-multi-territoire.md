# M11 — Piloter une coordination internationale multi-territoire

```
SKILL_ID: KOR15.SKILL.C11
FREK_PROOF_MAPPING: READY_FOR_FREK_PROOF = FALSE
```

## Objectif
Coordonner plusieurs marchés en parallèle sans dupliquer un réseau
d'opérateurs façon Kiltikonet (`KLT-07`) — confirmer explicitement la
différence de mandat.

## Contenu
- Coordination : priorisation entre marchés, partage d'apprentissages
  d'un marché à l'autre, cohérence de marque.
- Rappel explicite de non-duplication avec `KLT-07` (voir
  `REFERENTIAL.md` §5) : ce module coordonne une stratégie de
  distribution produit, pas un réseau d'opérateurs associatifs internes.

## Cas fil rouge
Épisode E, suite — coordination des 3 marchés (Caraïbe, diaspora,
Afrique) par Nadège.

## Exercice
Produire le plan de coordination internationale.

## Évaluation
N2 — `E-N2-05`.

## Évidence
Plan de coordination (`EVIDENCE_TYPE = INTERNATIONAL_COORDINATION_PLAN`).

## Boundary check
Un plan qui reproduit la logique d'onboarding d'opérateurs de `KLT-07`
au lieu d'une coordination de distribution produit échoue ce critère.
