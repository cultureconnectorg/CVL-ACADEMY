# KORA Master Package — Certification Architecture

## Distinctions jamais confondues, appliquées uniformément aux 15 formations

| Terme | Statut à travers tout le corpus KOR |
|---|---|
| `COURSE_COMPLETION` | Atteint dès N1/N2 complétés, par formation |
| `SKILL_VALIDATION` | Atteint compétence par compétence, via Skill IDs |
| `ACADEMY_CERTIFICATION` | Atteint via `KORxx-A01`, par formation, indépendamment des autres |
| `BADGE` | Non traité dans ce corpus (hors mandat de ce chantier) |
| `PRODUCT_AUTHORIZATION` | **Jamais délivré**, aucune formation |
| `RNCP_OR_STATE_CERTIFICATION` | **Non applicable**, aucune démarche engagée |

## Absence de certification composite

Il n'existe **aucune** certification "méta" qui agrégerait plusieurs
`KORxx-A01` en un diplôme unique — chaque formation reste
indépendamment certifiable. Les parcours de
`PROFESSIONAL_PATHWAY_MAP.md` sont des lectures de portefeuille, pas
des cursus certifiants composites.

## Formations avec vigilance renforcée (`NEEDS_EXPERT_REVIEW = TRUE`)

- `KOR-07` (droits, licensing, réglementation)
- `KOR-11` (modération, mineurs, harcèlement)
- `KOR-13`/M05,M08 (négociation contractuelle réelle)
- `KOR-15` (droits territoriaux, réglementation locale)

Toute certification obtenue dans ces formations n'habilite à aucune
pratique professionnelle réelle sans validation experte indépendante
(voir `EXTERNAL_VALIDATION_REGISTER.md`).
