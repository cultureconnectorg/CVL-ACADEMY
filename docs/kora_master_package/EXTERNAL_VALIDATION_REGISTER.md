# KORA Master Package — External Validation Register

Domaines nécessitant une expertise externe avant tout déploiement réel
(`NEEDS_EXPERT_REVIEW = TRUE`) — jamais convertis en vérité par ce
chantier.

| Formation | Domaine | Ce qui manque |
|---|---|---|
| `KOR-07` | Droits, licensing, réglementation média | Validation juridique réelle des mécanismes de droits et royalties enseignés |
| `KOR-10` | CVE | Audit produit externe pour confirmer/infirmer l'existence et la définition de CVE |
| `KOR-11` | Modération, mineurs, harcèlement | Validation juridique et éthique (protection des mineurs notamment) |
| `KOR-13` | Négociation contractuelle réelle | Validation juridique avant toute application réelle des méthodes M05/M08 |
| `KOR-15` | Droits territoriaux, réglementation locale | Validation juridique par territoire (Caraïbe, Afrique, Amériques/Europe) |

## Règle

Aucune hypothèse ci-dessus n'a été convertie en fait établi pour
"finir" une formation — chaque formation reste `CORE_BUILD = COMPLETE`
et `FULLY_COMPLETE = FALSE` simultanément, précisément à cause de ces
validations manquantes.
