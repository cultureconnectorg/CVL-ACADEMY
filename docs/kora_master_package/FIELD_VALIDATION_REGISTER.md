`FIELD_VALIDATED = FALSE` pour les 15 formations. Aucune session
réelle de candidats, aucune correction réelle, aucune soutenance jury
réelle n'a eu lieu à ce jour — ce corpus est un **build pédagogique**,
pas un résultat de terrain.

## Discipline

`FULLY_COMPLETE = FALSE` reste vrai pour toutes les formations tant
qu'aucune ligne ci-dessus n'est cochée par un ticket dédié — jamais
déclaré vrai par supposition ou par volume de contenu produit.
