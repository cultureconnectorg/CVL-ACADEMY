# KORA Academy — Master Package

Ce dossier consolide, sans le dupliquer, le corpus pédagogique complet
`KOR-01`→`KOR-15` construit sous `docs/kor/kor01/` … `docs/kor/kor15/`.
Chaque document ici **pointe** vers le corpus (chemins, IDs, tableaux
de synthèse) — le contenu pédagogique lui-même vit exclusivement dans
`docs/kor/korXX/`.

## Portée

15 formations, 169 modules/compétences, 435 fichiers documentaires,
construits sous l'autorisation Founder "GO — AUTORISATION GLOBALE"
(KOR-03→KOR-15 continuous build), en continuité du socle
`KOR-01`/`KOR-02` (déjà construit, `REFERENCE_SKELETON`).

## Comment lire ce Master Package

1. `MASTER_INDEX.md` — point d'entrée, table des 15 formations.
2. `PORTFOLIO_MAP.md` — vue d'ensemble métier/compétence/module.
3. `CROSS_KOR_COMPETENCY_MAP.md` — compétences qui se répondent d'une
   formation à l'autre (handoffs, tensions).
4. `PROFESSIONAL_PATHWAY_MAP.md` — parcours professionnels possibles à
   travers plusieurs formations.
5. `MASTER_SKILL_REGISTRY.md` — registre consolidé des 169 Skill IDs.
6. `MASTER_ASSESSMENT_ARCHITECTURE.md` — architecture N1/N2/A01
   consolidée.
7. `MASTER_EVIDENCE_MODEL.md` — typologie d'évidence consolidée.
8. `CERTIFICATION_ARCHITECTURE.md` — modèle de certification
   consolidé, distinctions de vocabulaire.
9. `PRODUCT_DEPENDENCY_MAP.md` — chaque dépendance produit KORA
   déclarée dans le corpus.
10. `CVLN_BOUNDARY_MAP.md` — toutes les tensions de frontière posées
    (KOR/KOR, KOR/KLT, KOR/autres pôles CVLN).
11. `CASE_UNIVERSE_MAP.md` — évolution du cas fil rouge L'Antenne
    Lanbi à travers les 15 formations.
12. `EXTERNAL_VALIDATION_REGISTER.md` — ce qui nécessite une
    validation externe (`NEEDS_EXPERT_REVIEW`).
13. `FIELD_VALIDATION_REGISTER.md` — ce qui reste à valider sur le
    terrain (aucune session réelle de candidats à ce jour).
14. `ACADEMY_INTEGRATION_MAP.md` — statut d'intégration au runtime
    Academy (aucun, par construction).
15. `QUALITY_GATES.md` — gates consolidées, formation par formation.
16. `MANIFEST.md` — inventaire exhaustif des fichiers du corpus.
17. `CHANGELOG.md` — historique de construction (commits).

## Ce que ce Master Package n'est pas

`NO_DUPLICATE_CURRICULUM` — aucun contenu pédagogique n'est recopié
ici. `NO_KORA_PRODUCT_UPGRADE` — ce package ne construit ni ne modifie
aucune fonctionnalité produit KORA. `NO_RUNTIME_BINDING`, `NO_DB_MUTATION`,
`NO_SEED_MUTATION` — aucun fichier de code, seed, ou runtime n'a été
touché pour produire ce corpus ou ce Master Package.
