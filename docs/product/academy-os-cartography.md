# CVLN Academy OS cartography

This document records the product doctrine that the repository must now preserve while it is recalibrated for the October 2026 opening.

## Source of truth

The existing `CVL-ACADEMY` repository remains the starting truth. It is treated as an intelligent legacy catalogue, not as a blank slate and not as a generic LMS.

## Core map

```text
META-CVLN
  ├── Entités
  ├── Savoirs / métiers CVLN
  └── Actifs
        ↓
CVLN Academy / Academy OS
  ├── INTERNAL — former pour CVLN
  ├── EXTERNAL — former le marché
  └── BRIDGE — marché → CVLN via accès, missions et contribution
        ↓
Compétences → Productions → Evidence / Proof → FREKCORE + Credential → Mission / Opportunity → Valeur
```

## Audience matrix

Every formation must be positioned across context and audience:

| Audience | Internal CVLN | External market | Bridge |
| --- | --- | --- | --- |
| Débutant | découverte CVLN | accessible public | découverte → CVLN |
| Intermédiaire | opérationnel CVLN | professionnalisation | compétence → mission |
| Avancé | expert / responsable | spécialiste | expert → écosystème |
| Professionnel | montée en compétence | B2B / entreprise | partenariat |
| Institutionnel | workforce CVLN | formation financée | programme territorial |

This prevents confusion between a formation that teaches CVLN itself and a formation that uses CVLN as an applied learning terrain.

## Job truth structure

Each métier should be reconstructed as a source-of-truth fiche with market name, CVLN name, external references, level, sectors, real missions, technical and behavioral skills, tools, deliverables, evidence, prerequisites, outcomes, market economics, market need, job evolution, internal version, external version, and bridge version.

## Formation reconstruction flow

```text
Market need → Job → Activities → Skills → Mastery level → Expected proof → Path → Modules → Experiences → Assessment → Duration / format / price / costs / funding
```

## Calibration sources

France Travail / ROME, France compétences, real market signals, existing training offers, financing mechanisms, and Qualiopi are calibration sources. They inform the structure and viability of external programmes but do not dictate the CVLN vision.

## Economic unit

Each formation must carry an economic model: public price, company price, funding options, pedagogical cost, instructors, production, studio or venue, tech, acquisition, administration, reinvestment, and margin. The Music Business example uses a provisional public price of 1,400 EUR so a 15-person cohort can be measured as a 21,000 EUR unit.
