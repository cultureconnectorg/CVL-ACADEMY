# WAL-19 — Evidence Model

## Chaîne de preuve

M1 system map annoté → M2 tableau des types → M3+M4 distinctions
écrites (CC/JCC, Academy/produit externe) → correcteur → (jury si
2.0–2.5) → `WAL19.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Le system map M1 vérifiable contre `wallet/models.py`,
`wallet/service.py`, `api/wallet.py` ; les distinctions M3/M4 écrites
noir sur blanc, jamais implicites.

## Ce qui NE compte PAS comme preuve

Une route/fonction inventée (crédit direct, transfert), ou une
affirmation confondant ce ledger avec le vrai produit externe.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne
Academy (`WAL19.SKILL.*`) est en jeu.
