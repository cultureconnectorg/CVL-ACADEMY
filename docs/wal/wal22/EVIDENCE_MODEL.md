# WAL-22 — Evidence Model

## Chaîne de preuve

M1 tableau de routes annoté → M2 note écrite (discipline de ledger) →
M3 note de frontière produit externe/Academy → correcteur → (jury si
2.0–2.5) → `WAL22.SKILL.*` (réservé, non lié au runtime).

## Ce qui compte comme preuve

Le tableau M1 vérifiable contre le repo-truth déjà établi de
`djsayd/CVLN-Wallet` ; la note M2 citant `ledger_post` ; la note M3
affirmant explicitement l'absence d'intégration entre les deux repos.

## Ce qui NE compte PAS comme preuve

Une affirmation d'accès opérationnel réel de cette Academy au produit
externe, ou une description d'un coffre comme source de valeur ex
nihilo.

`READY_FOR_FREK_PROOF = FALSE`. Seule une certification interne Academy
(`WAL22.SKILL.*`) est en jeu.

## Réservation Skill ID

`WAL22.SKILL.COFFRE_LIFECYCLE`, `WAL22.SKILL.LEDGER_DISCIPLINE`,
`WAL22.SKILL.PRODUCT_BOUNDARY` — réservés dans
`70_EVIDENCE/EVIDENCE_ARCHITECTURE.md`.
